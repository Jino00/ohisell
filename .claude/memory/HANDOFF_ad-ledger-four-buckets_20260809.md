## 3. 확정된 결정 (번복 금지 — 상세는 D-CPP-28)

### 광고 원장은 네 통으로 **남김없이** 갈린다
```
ad_option_total(Billboard)
 = 손익 귀속분 + ad_uncosted(판매O·손익밖) + ad_no_sales_days(팔린 옵션의 판매 없는 날)
              + ad_no_sales(판매행 없는 옵션)
```
- 이 **항등식이 계약**이다. 갈래마다 값을 못 박는 것보다 강하다 — 새 경로가 생겨 어느 통에도
  안 들어가면 합이 어긋나 테스트가 그 자리에서 죽는다.
- `basis='full'`이면 구멍2·3을 **둘 다** 세후 차감. **구멍1은 절대 차감하지 않는다**(금지선 —
  그 매출도 손익 밖이라 비용만 빼면 이익이 거꾸로 위조된다).
- `ad_no_sales_included`는 `is_full **and** has_pnl`이다. `is_full`은 «결손 0»이라 판매분석
  미수집 창에서도 참이 된다 — 사다리 없는 창에 「이미 반영됨」이라 말하면 안 된다.
- **하루짜리 창에서는 구멍2가 구조적으로 0**이다. 하루로 재보고 «없다»고 결론내지 말 것.

### 근거화면 A7의 성격이 바뀌었다
「결손이 있는가」(상시 fail) → **「원장이 남김없이 갈렸는가」**(pass). 결손 크기는 이제
`ad_unattributed`가 상시로 말한다. ★**pass는 «결손 없음»이 아니다.**
지금 A7이 fail이면 그건 **새로 생긴 다섯째 경로**라는 뜻이라 검사 자체를 의심할 것.

### `ignored`는 «결정»과 «매칭 실패»를 겸한다
prod 22건 **전부** `note='no suggestion or low score'` · `created_at`이 2026-06-17 23:2x에
초 단위. 즉 일괄 매핑이 후보를 못 찾은 것이다(ref 47 §2). 화면은 이제 **기록된 사유를
보여주기만** 하고 단정하지 않는다. ★**사유 문자열을 파싱해 화면이 판정하지는 않는다** —
그건 또 하나의 추측을 코드에 굳히는 것이다.

### ✅ prod nginx `index.html` 캐시 금지 — 적용 완료 (2026-08-10 08:5x, Jino 승인)
`sellc.ohitech.co.kr` nginx에 `index.html` 전용 `Cache-Control`이 없어, 프론트 배포 후에도
브라우저가 옛 `index.html`을 붙들어 **옛 번들을 계속 쓴다.** 2026-08-10 07:4x에 직접 당했다 —
서버는 새 번들을 정확히 내주는데 화면은 옛 문구였다.
★**배포를 눈으로 확인할 땐 서버가 실제로 무엇을 내주는지부터 봐라**:
```
ssh sellc.ohitech.co.kr "cat /home/ubuntu/ohisell/frontend/dist/.build-stamp;
  grep -o 'assets/[^\"]*\.js' /home/ubuntu/ohisell/frontend/dist/index.html"
```
그 다음 그 번들 파일을 `grep`해 새 문자열이 있는지 본다. 브라우저는 마지막에 본다.
**적용됨**: `location = /index.html`에 allowlist include + `no-store, no-cache, must-revalidate`
+ `Pragma: no-cache`. `assets/*`는 콘텐츠 해시라 안 건드렸다.
★★**같은 서버 `os.ohitech.co.kr` 블록을 그대로 복사하면 안 됐다** — 거기엔 allowlist가 없는데
sellc의 `location /`에는 있고, `try_files`의 `/index.html` 폴백은 **내부 리다이렉트라 location
매칭을 다시 한다.** allowlist를 빼면 모든 SPA 경로가 **IP 차단을 우회**한다(2026-07-17에 막은
공개 노출 재발). 교훈 #194.
**검증**: 차단 대상 127.0.0.1에서 `/` `/index.html` `/rocket-1p-revenue` `/assets/*.js`
`/api/health` **전부 403** · 헤더 한 줄 · **하드 리프레시 없이** 새 번들을 집었다.
**롤백**: `sudo cp /etc/nginx/sites-available/sellc.ohitech.co.kr.bak-20260809-235449 \
/etc/nginx/sites-available/sellc.ohitech.co.kr && sudo nginx -t && sudo systemctl reload nginx`
