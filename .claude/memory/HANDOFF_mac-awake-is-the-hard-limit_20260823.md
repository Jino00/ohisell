## 3. 확정된 결정사항 (번복 금지)

- ★**수집은 MacBook이 깨어 있을 때만 가능하다** — 뚜껑 열림 필수(외부 모니터 없어 클램셸 불성립). 소프트웨어 우회 없음. Jino 확인 20:01
- ★**「어디서든」은 «Jino가 어디 계시든»이지 «Mac이 어떤 상태든»이 아니다** — 목표 원문은 그 뜻으로 여전히 유효하다. 폰에서든 노트북에서든 누르면 되고, 조건은 Mac이 깨어 있을 것 하나
- **`caffeinate`는 유휴 수면만 막는다** — 뚜껑 닫힘 수면은 다른 경로라 못 막는다. `sudo pmset -c sleep 0`도 마찬가지
- **`sudo pmset -b disablesleep 1`(뚜껑 닫힘 수면 끄기)은 권하지 않는다** — 가방 속에서 계속 돌아 과열·배터리 위험
- **미승인 계약 초안은 파일로 남기지 않는다** — n=3의 `CONTRACT_collection_observability.md` 폐기와 같은 이유(다음 세션이 베낄 표면이 된다)
- **화면 판별(하트비트+4분기)의 값어치는 상한을 알게 된 순간 떨어졌다** — 되살릴 거면 «값이 왜 다시 생겼는지»부터 대야 한다
