- **손해는 0**(실쓰기 0·안전장치 정상) — 그러나 **값이 도는 층과 사람이 읽는 층이 갈렸다**(이 저장소의 반복 병).
- **누적 속도**: 시간당 8~9건 ⇒ 1주면 **약 1,400건**의 blocked 일기·죽은 approved 카드. **C7의 학습 재료를 희석할 수 있다** — 다음 세션이 harvest 결과를 볼 때 이 노이즈를 분리해야 한다.
- 이번 세션이 고치지 않은 이유: 코드 변경이고 점화 당일 스코프 밖이다. **다음 세션 1순위 후보.**
