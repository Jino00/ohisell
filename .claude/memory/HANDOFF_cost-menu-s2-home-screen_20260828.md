## 1. ★다음 세션이 첫 일로 할 것 — **prod 배포**

```bash

# 백엔드 (신규 엔드포인트 GET /cost-table-items — 마이그레이션 0건이라 --migrate 불필요)
```

배포하면 **§4 S2 합격 3항목이 «전부» 관측 가능해진다** — 지금 미달인 이유가 「코드가 없어서」가 아니라 「화면이 세상에 없어서」이기 때문이다.

**왜 이 세션이 안 했나(정직하게)**: 내가 「S2가 미완이니 배포는 완성 후」로 판단했다. **그 전제가 틀렸다** — 적대 리뷰가 `CostPage.tsx` 393줄 diff를 문자열 리터럴 단위로 대조해 **합격 ②(자백 문구 소실 0건)가 이미 충족**임을 확인했다(삭제 0건, `(빈 칸이지 0원이 아니다)` 하나가 `costHome.ts` 상수로 문자열 그대로 이동). 내가 「잔여」로 본 것은 설계 Q4가 예고한 **「컴포넌트째 드릴다운으로 내려가 코드 이동 0」**이었다. 그 사실을 안 뒤 Jino께 배포 여부를 여쭸고 **답을 받기 전에 세션이 닫혔다.**

## 3. 확정된 설계 결정 (번복하려면 근거를 대라)

1. **기본 탭을 `home`으로 전환한다** — 계약 §4 S2 ①의 「첫 화면」 요구. 기존 3탭은 **전부 살아 있고 직행도 된다**(설계 Q2: 익숙한 손이 깨지지 않는다). 조작 7가지 전부 생존, 최대 3클릭
2. **왕복 표 키 = `cost_material.id`** (이름 아님) — 개명이 「사라짐+신규」로 오독되면 S4 비활성 경로가 멀쩡한 종을 죽인다. 파일에서 id 빈 행 = 「신규 종 후보」
3. **수정 가능 열은 5개뿐**(이름·폼팩터·부품·단위·단가ex+발효일·비고). **VAT inc는 표시 전용** — ex·inc 동시 수정의 모순 심판 규칙이 곧 §3 「자동 병합 금지」 위반이다
4. **엑셀 시트 잠금을 근거로 삼지 않는다** — 사용자가 풀 수 있어 방어가 아니다. 방어는 S4 diff의 **「반영 불가」 묶음**이 한다(조용한 드롭은 자동 병합의 사촌)
5. **새 숫자를 계산하지 않는다** — 보드 스트립은 `/api/cost/board` payload를 그대로 읽는다. **분모의 뜻도 화면이 말한다**(「원가 있는 SKU」의 분모는 보드에 실린 SKU이지 `product_master` 963행이 아니다)
6. **인박스는 «사건» 단위다** — 묶음 기준이 원천 테이블이 아니라 「사람이 하는 일의 종류」(①고른다 ②넣는다 ③잇는다 ④확인한다). 레시피 45·97의 `price_conflict`가 두 테이블에 있어 원천대로 세우면 같은 사건이 두 줄에 선다
7. **순환 import를 의도적으로 택했다** — 어휘 사본을 두면 같은 종을 두 자리가 다르게 부른다. 리뷰가 안전을 실증했다
8. **§0-A‴의 축 질문에 답이 났다** — 표는 「종 = 행」을 유지하고, 축 늘리기는 **«구성이 어느 종을 가리키는가»(Q6)**에서 해결한다(Jino 2026-08-27 22:44 *"같은 부자재가 다른 값이 아니고, 다른 부자재인거지"*)
