## 6. ⓒ(보강)를 측정했더니 **원안이 반증됐다**

「이름 유사도로 오매칭을 거른다」는 이 데이터에서 **판별력이 없다**:
```
정답(사람이 픽) 14건이 토큰 유사도 0.00
  r40 「EZ툴 아이폰 풀커버 맥스 클리어 강화유리필름 2매」 ↔ 「오타오_투명 강화유리」  0.00
  r96 「Z플립&폴드 사생활보호 지문방지 저반사…」          ↔ 「사생활_외부2매」        0.00
오답 r81                                                              0.00
```
원가표 품목명은 «구성»을, 제품명은 «상품»을 말해 **어휘가 아예 다르다.** 이름으로 자르면
정답 14건이 같이 잘린다.

⇒ **바꾼 ⓒ: 막지 말고 «말하게» 한다** — 「⚠️ 이름이 한 글자도 안 겹친다 — 값만 같을 수 있다」
꼬리표. 게이트가 아니라 라벨이라 과적합이 무해하고, 오답이 쌓이면 게이트 승격 근거가 된다.
(r81만 유일하게 바이그램도 0.00이나 **오답 표본 n=1**이라 임계값을 판정에 쓰지 않는다.)
