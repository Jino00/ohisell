### 5-B. ★「가짜 성공」의 두 번째 얼굴 (**하네스 이월**)
백그라운드 `python -m pytest`가 `command not found`인데 **exit 0**으로 끝났다(`python`은 이 머신에 없다). n=49의 `safe_merge.sh`(`error connecting to api.github.com`인데 exit 0)와 **같은 얼굴**이다 — 이 저장소의 상습 실패 모드 「기록됐다 ≠ 실제로 됐다」.
★**위임문에 이 함정을 명시했더니 이후 에이전트 5기 전부 `python3`을 썼다.** 문서에 적는 것보다 **위임문에 싣는 것**이 실제로 작동했다 ⇒ 다음 세션은 **위임문 템플릿**에 넣어라.

### 5-C. ★`String(n)`은 SQLite에서 거짓말을 한다
16자를 `String(12)` 컬럼에 넣어도 로컬·CI 전부 초록이다(둘 다 SQLite). 이 프로젝트는 **SQLite → PostgreSQL** 이관 경로를 갖고 있어 이관 시점에 몰아서 터진다. 이번 PR 범위에선 적대 리뷰가 추가 발견 0건이었으나 **저장소 전역 `String(n)` 점검은 별건**이다.

### 5-D. ★적대 리뷰 산출물을 파일로 남겨라 (**하네스 이월**)
완료 QA가 리뷰 결과를 **원리적으로 검증할 수 없어 판정불능**으로 남겼다(PR에 GitHub 리뷰 0건, 파일 0건). 리뷰가 실제로 돌았어도 **기록이 없으면 없는 것과 같다.**

### 5-E. 북극성 본문에 D-NAO-249 각주가 없다 (**이월**)
§5-3 ★금지선 *"지혜의 출구는 «제안»까지다(자동 적용 절대 금지)"* 와 §6-b **M3 안 함** *"지혜의 자동 적용"* 이 **B군(승인=적용)과 문면상 부딪힌다.** D-NAO-249가 「트리거가 Jino의 승인 행위라 자동이 아니다」로 해석을 확정했으나 북극성 본문 미반영 ⇒ **안 달면 다음 세션·완료 QA가 B군을 금지선 위반으로 오독한다.** 소관: 이 트랙(ref 82).
