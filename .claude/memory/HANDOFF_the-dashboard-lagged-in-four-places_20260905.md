## 4. 스코프 밖 산출 (Jino 발의 — §10 자백)

> ↗️ **스코프 밖(기록만)**: 트랙 병렬분할 프롬프트 v2 + B1·B2 보강 블록 → 소관: 하네스(전역 `~/.claude/CLAUDE.md` · `archive-session`)

Jino 질문 *「너가 트랙을 이렇게 나눠준것처럼 다른 트랙들도 이렇게 나누려면 general하게 프롬프트를 어떻게 적어야해?」* → 이어 *「anthropic의 최신 권고에 맞게 적용해달라고 해야해서 너가 한번 조사해보고 prompt써줄 수 있어?」*

- 공식 문서 4곳 조사 후 v1 → **v2** 개정. **v1이 어긋나 있던 자리 넷**: 지시마다 «왜»가 없음 / 「안 함」만 많고 「할 것」이 뒤 / **예시 0개** / 불확실성 표현 허용 없음
- **새로 넣은 것 넷**(전부 공식 샘플 프롬프트 있는 항목): 되돌릴 수 있는 것과 없는 것 / 과설계 방지 / **테스트 통과가 목적이 아님** / 서브에이전트 판단 기준(★Opus 5는 위임 경향이 강하다고 문서가 명시)
- **일부러 안 따른 것 하나**: 「하지 마라 목록을 줄여라」 — 이 저장소는 계약 `안 함:`이 필수 요소고, 병렬 세션에선 **경계를 파일 이름으로 못 박는 게 clobber를 막는 유일한 수단**이다. 절충: 「할 것」을 먼저 두고 「안 함」마다 이유를 붙였다
- 파일: 스크래치패드 `트랙_병렬분할_프롬프트_v2.md` · `B1_B2_보강블록_20260905.md`. **⚠️ 저장소에 커밋 안 됐다** — 남기려면 다음 세션이 옮겨야 한다
- ★**자백이 두 턴 늦었다.** Jino 발의라 착수 자체는 §10상 정당하나 「↗️ 스코프 밖」을 먼저 출력했어야 했다
