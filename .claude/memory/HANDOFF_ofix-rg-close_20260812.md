## 3. ★다음 세션이 반드시 알아야 할 함정 5개

2. **원가 조인은 `channel_id IN (1,3)`이 아니다.** 엔진은 `Channel.platform='coupang'` 전체를 본다

3. **커버리지는 창을 밝혀야 한다**(교훈 #263). 「0%」만 말하면 거짓말이 된다.
4. **정산 `coupang_rg_settlement_fee`는 sentinel(`vendor_item_id=''`) 행만 센다.** 전부 SUM하면 이중계상.
5. **파생 master는 `memo LIKE '%D-CPP-41%'`로 찾는다.** `LIKE '%SET'`은 도어락 master 6건을 같이 잡는다.

정정 경로: 생성한 master 7 + 매핑 55(45+10)의 id 전량이 세션 scratchpad `rollback.json`에 있다.

- **#260** «없다»는 관찰에서 «전체를 뺀다»는 결론이 안 나온다 — 「3P가 비었다」로 계정 전체를
  자동수집에서 뺐는데, 같은 소스가 나르는 RG축이 63일 3,931만원이었다.
- **#261** 라벨이 실질을 뜻한다고 가정한 감시는 실질이 바뀌면 원리적으로 못 잡는다(D-16).
- **#262** 파생 원가는 «값»이 아니라 «식»으로 기록한다.
- **#263** 커버리지 «0%»는 창을 밝히지 않으면 거짓말이 된다(적대 리뷰 P1-2).
- **#264** 접근 차단은 «호스트 단위»가 아니라 «경로 단위»일 수 있다 — 한 경로로 호스트 전체를
  판정하지 말고 문제 파이프라인이 **실제로 쓰는 경로**를 재고 **클라이언트 로그를 직접 봐라**.
