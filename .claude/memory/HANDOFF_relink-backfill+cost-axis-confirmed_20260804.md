## 5. 알려진 이슈 / 주의사항

1. **광고 집행 중인데 BEP 행 자체가 없는 신상품 3옵션**(미조치): `13687558206/7/8`(오하이Z플립폴드 외부 사생활보호 필름), 소재 입찰 900·700·1,000원, 07-31~08-04 655,800원 판매. `calculate_bep()`가 활성 매핑을 순회하므로 매핑이 없으면 BEP 행 자체가 안 생긴다 — **BEP·목표ROAS 판정 밖에서 집행 중**이다. 네이버 BEP 713행 중 181행(25.4%)이 `has_cost=0`.
2. **자사몰 `raw_data`가 90일 565건 중 388건(69%)이 10,000자에서 잘려**(`MAX_RAW_DATA_SIZE`) JSON 파싱 불가. 트랙 밖 조사 중 발견, 미조치.
3. **일반배송(TODAY) 수수료 정산 잔차 +1,838원(0.148%)** — 여전히 미판정(직전 인계 §5-10과 동일, 변화 없음).
4. **codex 교차 리뷰 부채**(D-NAO-139·140·144·145·153·149, 한도 복구 08-09) — 이번 세션 커밋(`bd23a72`) 포함.
5. **매핑을 소급 연결해도 손익이 이미 마감된 과거 월의 표시 숫자는 이번 조회부터 반영된다** — 재계산 캐시 등은 없음(손익 엔진이 매 요청 실시간 계산이므로 캐시 무효화 이슈 자체가 없다, 확인만 함).
