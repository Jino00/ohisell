## 4. ★이 세션이 «측정»한 것 (이게 인계의 핵심)

### ① 쇼핑 검색어 제외는 **API가 읽지도 쓰지도 못한다** (설계를 바꾸는 실측)
- 콘솔엔 `01. 버디필름` 그룹에 제외 검색어가 **43건**(2024-12부터 누적). 그런데
  `GET /ncc/adgroups/{id}/restricted-keywords`는 **두 타입 모두 200 / 0건**을 돌려준다.
- 쓰기는 `EXP_SEARCH`·`KEYWORD_PLUS_RESTRICT` **둘 다 400/3728**. (400 에러가 enum 전체
  `[EXP_SEARCH, KEYWORD_PLUS_RESTRICT]`를 노출해 **처음으로 전수 시험이 가능해졌다** — 종전
  「쇼핑 불가」 기록은 타입 하나만 시험한 결과였다.)
- **뜻**: ⓐ자동 발견(`detect_new_exclusions`)은 **구조적으로 파워링크 전용** ⓑ쇼핑의 유일한
  입구는 **화면 수동 기록** ⓒ생존 감시는 쇼핑에서 「걸려 있나」를 못 본다 → `STATE_UNVERIFIABLE`
  신설. **안 갈랐으면 어제 자른 「골프」가 08:25부터 매일 「우리 조치가 사라졌다」로 떴다.**
- **효과 판정은 여전히 가능하다** — 성적표는 API가 아니라 **우리 검색어 비용**을 본다.
- 부수: 그 그룹의 제외 42건을 **우리 시스템은 하나도 모르고 있었다**(구조적으로 알 방법이 없었다).
