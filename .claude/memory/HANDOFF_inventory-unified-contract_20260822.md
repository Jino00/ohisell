## 4. 구조적 결론 (다음 세션이 다시 발명하지 말 것)

- **자사창고가 허브다.** 1P 재고는 납품 후 쿠팡 소유라 우리가 «운영»할 수 없다. 우리가 결정하는 것은 자사창고에서 나가는 네 갈래(1P 납품·2P 발송·3P 출고·스스 출고)뿐. ⇒ 「1P 재고 운영」 = 쿠팡 발주에 응할 자사창고 재고 확보 문제.
