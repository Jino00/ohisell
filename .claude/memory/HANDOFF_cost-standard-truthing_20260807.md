## 3. ★원가의 정본 — Jino 확정

## 4. ★★판정 규칙 (전부 이날 실측으로 얻음 — 하나라도 빠지면 조용히 틀린다)

1. **「사생활」·「프라이버시」 유무가 필름 성격의 유일한 판별자.** 저반사·무광·매트·빛반사·지문방지는
   **같은 기능의 다른 표현**이다 → [[film-privacy-vs-antifingerprint]] (병행 세션 확정, 34건 뒤집음).
   내가 「지문방지=무광」을 판별자로 넣었다가 후보1개 51→38로 나빠져 되돌린 것이 같은 이유였다.
2. **「유리코팅」·「강화유리코팅」은 강화유리가 아니라 PET.** 「코팅」을 「강화유리」보다 **먼저** 본다
   → [[glass-coating-means-pet-not-tempered-glass]]. 이 규칙 하나로 1P 매칭 확정분 발주수량이
   6,166 → 13,382로 두 배가 됐다.
3. **폰과 태블릿은 기종으로 가른다.** 제품군 이름(6H 강화유리코팅 등)이 양쪽에 쓰여, 이름만 보면
   아이폰16프로맥스가 태블릿 표로 간다(실제로 그랬다).
4. **BLC 표기가 없으면 무BLC**(Jino 확정).
5. **매수는 기준표의 「매입」 열이 정본.** 품목명은 갱신이 밀린다 — 1매 표의 품목명이 전부 「2매」였다.
6. **판정 불가는 판정 불가로 남긴다.** 억지 판정은 조용히 틀린 원가를 만들고 화면 어디에도 경보가 없다.
7. 필름 원가는 **플립/폴드/기타 사이즈 축**으로도 갈린다 → [[film-cost-splits-by-flip-fold-size]].

## 5. ★내가 저지른 오류와 그것을 잡은 방법 (교훈 후보)

**스크린샷을 눈으로 옮겨 적다가 BLC/무BLC를 뒤바꿔 읽었다.**
- 엑셀 실제: 지문방지 PET 2매 **무BLC** = 4,902.7 / 5,430.7 / 7,652.7,
  **BLC** = 4,352.7 / 4,352.7 / 5,892.7
- 내가 적용: 무BLC에 BLC 값(4,352.7 …) → **36개 상품이 550~1,760원씩 낮게**, 이익 과대
- 같은 이미지의 종이질감·6H코팅은 맞게 읽었다 — **부분적으로만 틀려서 더 안 보였다**

**잡은 것은 판정기다.** 엑셀을 **프로그램으로 파싱**해 DB와 대조하자 즉시 드러났다.
→ **원가표는 눈으로 옮기지 말고 파일을 파싱한다**(Jino에게 그렇게 하겠다고 말함).
