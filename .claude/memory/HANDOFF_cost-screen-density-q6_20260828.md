## 3. ★다음 세션이 알아야 할 사실 (실측)

### 3-1. 「상태」를 자유 텍스트에 적으면 반드시 거짓말이 된다

`recipes.py`가 새 종을 만들 때 `note`에 「…으로 생성 **— 단가는 아직 없다**」를 박는데 **나중에 단가가 들어와도 아무도 안 고친다.** prod 실측:

```
전체 종                    139
그 문구를 단 종             138
★그 문구 + 단가 실재(=거짓)    74
그 문구 + 단가 없음(=참)      64   ← 인박스 「단가 없음 64건」과 정확히 일치
```

**64가 인박스 숫자와 일치한다는 것이 요점**이다 — 살아 있는 판정은 이미 배지가 `latest_price_*`를 보고 라이브로 하고 있었고, note는 그 옆에서 굳은 값으로 우기고 있었다. ⇒ 출처만 남기고 상태 주장은 뗐다. **백필 후 138 → 0.**

### 3-2. Q6 — 길은 놓였고 **모순 2건은 Jino 몫이다**

레시피 **45**(SKU 5)·**97**(SKU 3)이 각 **196.9원 과대**. 산술 실측:

```
부착 안내문  55 → 30  (−25)   [종 48 → 18]
비닐        15 → 10  (−5)    [종 53 → 23]
패키지      320 → 171 (−149)  [종 54 → 24]
                    합 −179 ex × 1.1 = −196.90 inc
```

**막고 있던 것은 「저장소에 구성 라인의 종을 바꾸는 길이 하나도 없다」**였다(구성이 바뀌는 길은 업로드 통짜 재생성과 픽뿐, 둘 다 「이 한 줄만」을 못 한다). 이제 `PATCH /api/cost/recipes/{id}/lines/{line_id}/material`이 있다.

★**내가 안 눌렀다** — 계약 §2 「충돌·모순은 항상 사람이 고른다」. Jino가 할 것(레시피당):
1. 레시피 탭 → 해당 레시피 → **승인 해제**
2. 계산 내역에서 부자재 칸의 **「종 바꾸기」** → 위 표대로 3건
3. 45는 1,120.70 → **923.80**, 97은 4,020.30 → **3,823.40** 확인 후 **승인**

교체 내역은 그 줄에 KST 시각과 함께 남는다(`종 교체: 패키지 (fold) → 패키지 (flip)`).

별도 Sonnet·읽기 전용·prod 브라우저 직접 확인. **배포 직후 시점**의 판정이다(이후 5건이 더 들어갔다).

- **판정(계약 §4 S2): 부분달성** — *"②(자백 문구 이동·소실 0건)는 코드 리뷰 검증 + 라이브 관측으로 달성. ①·③은 구조적 전제(입구·표 존재)는 prod에 살아 있으나, 두 항목이 요구하는 「Jino가 실제 수행/확인한다」는 표면 사건이 이 세션에서 일어나지 않아 미관측 — **미달로 적는다(기준을 낮추지 않는다)**."*
- **판정(Jino 지시 원문 「복잡함→심플화」): 판정불능** — *"구조적으로 입구 수는 줄었으나 이 지시는 Jino 본인의 주관적 만족이고, 배포 후 Jino가 새 홈 화면을 아직 보지 않았다."*

★**그 뒤 「판정불능」이 사실상 해소됐다** — Jino가 화면을 보고 *"화면의 사용이 너무 비효율적인거 아니야?"*라고 했다. **부정적 반응이 왔고 그걸 고쳤다.** 다만 QA를 다시 안 돌렸으므로 **재판정은 다음 세션 몫**이다(내가 내 작업을 재판정하지 않는다).

## 7. 하니스 (다음 세션이 같은 데 안 빠지게)

- **빌드 검증에 파이프를 쓰지 마라** — 1차 `npm run build | tail`이 `tsc: command not found`인데도 **exit 0으로 보였다**. 새 워크트리는 `npm ci --prefix frontend` 선행 필요.
- **백엔드 테스트는 `cwd=backend/`를 전제한다** — 저장소 루트에서 돌리면 alembic·상대경로 테스트 **9건이 «실패»로 보이는데 환경 문제다**(올바른 cwd에선 전건 통과). 명령: `cd backend && PYTHONPATH=. ./backend/.venv/bin/python3 -m pytest tests/ -q`
- ⚠️**venv가 `backend/backend/.venv`에 있다** — 내가 상대경로를 잘못 줘 생겼다. `.gitignore`의 `.venv/`에 잡혀 커밋엔 무영향. 지우려면 `rm -rf <워크트리>/backend/backend`(내 권한으로는 거부됐다).
- **`safe_merge.sh`는 `MERGE_WAIT`를 넉넉히** — 이 저장소 backend CI는 **10분 30초**가 정상이다.
