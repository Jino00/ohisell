## §1. ★★인계가 지목한 작업이 이미 만들어져 있었다 — 결손은 «손»이었다

인계는 「ⓐ 재개방 유형별 dispatch」가 1순위 잔여라고 했다. **실측이 반증했다.**

| | 실측 (2026-08-31) |
|---|---|
| 유형별 dispatch (파워링크=id / 쇼핑=키워드) | **이미 있음** — D-NAO-271(PR #560, n=66) 머지 완료, 테스트 9곳 |
| 수동 재개방 엔드포인트 | **없음** |
| 화면 해제 버튼 | **없음** |
| `GET /search-term/exclusions` | **프론트 호출부 0건** — H1의 preflight와 같은 병 |
| 「재개방 대기」 배지 | 있으나 **지혜 후보**(`wisdom_candidates`)의 것이라 검색어 제외와 무관 |

그 dispatch는 **자동 레인 안에서만** 돌고, 레인은 `auto_operate=1`인 캠페인만 훑는다. 그래서 스위치가 꺼진 캠페인의 제외는 **재심사일이 지나도 아무도 못 열었다** — due 1건이 `next_review_at=2026-08-21`로 **10일째** 대기 중이었고 그 캠페인은 `auto_operate=0`이다.

★**교훈의 일반형**: 인계의 「남은 일」은 «무엇이 없나»가 아니라 «무엇이 안 돌아가나»로 적혀 있을 때가 있다. 그 둘은 다르고, 코드를 먼저 읽지 않으면 **이미 있는 것을 다시 만든다.**
