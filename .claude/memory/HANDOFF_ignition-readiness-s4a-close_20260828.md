- ⚠️★**무인 발화를 «가르는» 법**: `as_of`가 크론 슬롯과 **소수점까지** 일치하면 무인이다(예 `11:32:00.002320` ↔ `32 11 * * *`). 수동 트리거는 임의 시각이 찍힌다. **`last_run_at`만으로는 못 가른다** — n=61이 수동 트리거로 「발화했다」고 했다가 QA에서 걸린 자리
- ⚠️★**트랙 훅이 stale 공유 폴더를 읽는다** — `track-progress-sync.sh`가 공유 메인 폴더(619커밋 stale) 기준으로 트랙 파일을 읽어, 워크트리에 정상 누적한 `확인:` 줄을 못 본다. 이 세션에서 **9회 발동, 전부 오탐**. 공유 폴더에 대신 쓰면 남의 커밋에 쓸려 들어가므로 쓰지 않았다
- ⚠️**체인 등록부도 같은 사본이라** `[체인] ⛔ pao-논의 n=49` 훅 줄이 **오탐**이다(실제 head는 n=63). 생존 판정은 항상 `origin/main`으로
- ⚠️**계수 함정 3종** — 트랙 진행률 정본은 **TRACK-CONTRACT 블록 «안» + 줄머리(^) 앵커** 기준 **2/7**. 블록 밖 포함 14 · 줄머리 미앵커 16
- ⚠️**`is` 비교로 리터럴 복사를 못 잡는다** — CPython 작은 정수 캐싱 탓. `SPECS[k].default is judge._X`가 리터럴 `10`에도 True. AST로 「default 인자가 상수 리터럴인가」를 봐야 한다(이번에 전환)
- ⚠️**변이 원복은 `cp` 백업으로** — `git checkout --`는 미커밋 변경을 날린다(n=60 실사고)
- ⚠️**학습 재료 만료 `2026-10-28`** (D-61) — 옛 학습 재료 3,863건이 수확 창을 이탈한다

- ⚠️**프론트 빌드는 `npm run build`**여야 `dist/.build-stamp`가 생긴다
