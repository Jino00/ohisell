## ★3분할 항등식 검산 — 읽기 전용 1줄 (n=64 §4-5 수리분)

```bash
scp scripts/p2_readout/identity3.py sellc.ohitech.co.kr:/tmp/ && ssh sellc.ohitech.co.kr "python3 /tmp/identity3.py; echo EXIT=\$?"
```

창 안 한국 공휴일을 **SQL 리터럴로 열거**해 3분할하고 앱 세 칸과 대조한다. **합격 = `★앱 대조: 3/3 칸 일치` ∧ `EXIT=0`.**

⚠️ **「3칸 합 == TOTAL」 줄을 합격 근거로 쓰지 마라.** 완전 분할 위 합계 항등식은 어떤 분할에도 성립해 **판별력이 0이다**(음성 대조에서 틀린 공휴일을 넣어도 True로 남는 것을 실측했다). 판별력은 **오직 「리터럴 3분할 ↔ 앱 3칸」 대조**에서 나온다. n=64가 밟은 함정이 정확히 이 자리다.

⚠️ 창이 **고정 리터럴**이다(`WIN_FROM`/`WIN_TO`/`HOLIDAYS`). 다른 날 돌리려면 **셋 다** 갱신하라. 트레일링 창으로 바꾸면 공휴일 리터럴이 창을 벗어나 조용히 0건이 된다 — 사람이 달력으로 검증할 수 있다는 성질이 이 수리의 전부다.
