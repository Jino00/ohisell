## 3. ★Jino가 확정한 도메인 사실 (원문 — 다시 묻지 마라)

1. ***"수입가는 하나의 완성된 강화유리 제품이라니까"*** / ***"강화유리 2장이 들어간 하나의 완성된 제품이야"***
   ⇒ 원장 단가 = **완제품 1개** 값. 「1장당」이 아니다. **구성 수량은 항상 1**이다.
   ⇒ CI의 `2ea` 표기 유무는 무의미하다 — `Glass_`도 `Privacy Glass_ 2ea`도 둘 다 2장 완제품.
2. ***"Old version은 new 버전과 같은 구성인데, 강화유리를 cost down하기 전의 제품인거야"***
   ⇒ 원가표 강화유리 4항목 = **2개 물건 × 2개 시점**. 투명 18.85→**12.20**(−35.3%) ·
   사생활 28.15→**19.20**(−31.8%). **Old Ver.는 픽 대상이 아니다.**
3. ***"카메라 렌즈 강화유리는 지금 안들어오고 있어"*** ⇒ 원장에 렌즈 라인 **0건**. 붙일 원천 없음.
4. ***"이건 우리가 진짜 예전에 팔던 다른 구성의 제품이잖아"*** / ***"이건 glass가 1매만 들어간거구"***
   (아이폰XS맥스 1매) ⇒ 1매 완제품 단가가 원장에 없다. 붙이면 39% 과대.
5. 「먼지제로 원터치 지문인식」 = 원장 **`2.5D Clear Glass 2ea for Samsung`**(19.3 CNY). ***"같은 물건이야"***
6. ***"부자재 단가에 대해서는 내가 부자재 승인한 가격이 최신이야"***
   ⇒ 서열 확정: **승인가 > 엑셀 참고값**. 650→600을 11번, 98→171을 4번 고치신 건
   「상황마다 다른 판단」이 아니라 **엑셀이 낡은 것**이다.
7. 태블릿 크기 구간 ***"맞아, 3개로 구분하고 있어"*** — 기본 / 플러스·12.9형·13인치 / 울트라
8. ***"태블릿은 필름 종류, 크기에 따라서 가격이 달라져"*** — 축이 둘이다

## 4. ★다시 재지 마라 — 오늘 실측으로 닫은 것

- **기종별로는 원가가 안 갈린다. 로트별로만 갈린다.** 확정건 `Glass_` **84 라인 전부 12.2 CNY**.

  2,786.68 ~ 2,933.62(**약 5% 폭**) — 환율·물류비·관세 배부 차이다.
  ⇒ **종 하나에 라인 하나만 연결하면 26개 기종이 다 덮인다.**

- **`match_rule`이 이미 있다** — 토큰 전부 포함(대소문자·공백 무시). 그런데 **137종 중 1종만** 쓰고,
  **자동 갱신은 `match_rule`을 아예 안 본다**(`linked_item_name` 정확 일치만).
  ⇒ 같은 「매칭」인데 근거가 둘로 갈려 있다.
- **승인 123종 중 단가 행 보유 52종.** 나머지 **71종은 참고값만** 있고 **전부 「채택」 한 번이면
