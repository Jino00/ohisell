## 3. 이번에 구현한 것 — T3(S2-ⓒ) GAVE 성적표 축

**막고 있던 것은 계산이 아니라 «자리»였다.** 점수는 매일 계산돼 `naver_proposals.rationale` 118건에 `[GAVE사전: 기대점수 143327.5200…]`로 박혀 나오는데, prod 응답 키 24개·정렬 파라미터 6개 어디에도 `gave_score`가 없었다(09-07 07:29 KST 실측, 포트 8001).

- **rationale 파싱으로 정렬하지 않는다** — 같은 테이블 `target_bid`·`target_budget`이 이미 *「실행자는 이 컬럼만 읽는다(rationale 텍스트 파싱 금지)」*를 달고 있다.

- **`0.0000`과 NULL은 다른 상태** — 0은 무전환 방어 보드에서 실제로 나오는 점수다.
