## 5. ★다시 재지 마라 — 이 세션이 실측으로 닫은 것

### 5-1. 「패키지(bar)가 근거 없는 값에 밀려 있다」는 **틀린 예시였다**
`패키지(bar)`(id=8)의 두 행은 **둘 다 `source='manual'`**이다(id=9 98원 「엑셀 참고값 채택」, id=29 171원).
**「엑셀 참고값 채택」도 `manual`로 저장된다.** ⇒ 원장 vs 수동의 대결이 아니었고, 날짜 최신인 171원이
이기는 것이 규칙대로다. 계약 §0-1이 이 사례를 `ledger` 우선 규칙의 근거로 실은 것은 **예시 오류**다
(규칙 자체의 정당성은 그대로 — `ledger`는 K-GAAP 7.6을 3중 검산으로 관측한 값이다).

### 5-2. `ledger`·`manual` **혼재 종은 prod에 0건**이다
`ledger` 7행은 전부 `cleaning kit` 하나에 몰려 있고 `manual` 53행은 전부 다른 종이다.
`price_conflict=true`도 0건. ⇒ **합격 ⑦은 지금 관측할 대상이 없다.** 만들어서 통과시키지 않았다.

### 5-3. `cleaning kit` 로트는 2건이 아니라 **7건**이고 구간이 훨씬 넓다
| 통관일 | 단가 | | 통관일 | 단가 |
|---|---|---|---|---|
| 2/05 | **166.35** | | 6/15 | 181.56 |
| 3/19 | 172.72 | | 7/13 | 179.97 |
| 4/27 | 174.43 | | 7/23 | 178.78 |
| | | | 8/18 | **190.82** |

인계가 물려준 「178.78~190.82 = +6.7%」는 **2건만 보던 값**이다. 실제는 **166.35~190.82 = +14.7%**.
★**이게 사소하지 않다**: 재고 원장(C1)이 없어서 **우리가 못 고르는 폭이 두 배**다. C2 컷오버 때
그 폭이 그대로 원가에 실린다. 화면 배지는 라이브 재계산이라 처음부터 옳은 값을 그렸다 —
낡은 것은 문서 쪽이었다.

### 5-4. `standard_price_rule` 선언이 **장식이었다** (§0-A 개정 1)
`cost_setting`은 **2026-08-22 22:51부터 prod에 있었고** 화면 배지도 이미 떴다. 그런데
**계산 코드가 그 설정을 읽지 않았다** — 규칙이 `recipes._latest_price`·`materials.material_payload`
두 곳에 복제돼 있었고 `cost_standard.price_rule`에 박히던 값조차 상수의 사본이었다.
