## 6. 알려진 이슈
- **★분담금 판정자가 바뀌었다** — 테이블이 main에 들어오며 "테이블 존재" 가드가 무력화(빈 테이블 = "분담금 0"). 판정자를 **창에 걸친 프로모션의 할인액 유무**로 이동. 원인 = **두 브랜치를 각각 테스트하고 합친 뒤 재실행 안 함**
- **★CAS 매니페스트 구멍** — 직접 `cp` 후 install하면 "내용 동일"로 스킵하며 매니페스트를 갱신하지 않고 `--force`도 못 고친다("동일" 검사가 앞). "지금 도는 코드의 출처"가 거짓이 된다. 복구=파일 rm 후 재설치. **개선안: 내용이 같아도 blob/commit이 다르면 매니페스트만 갱신**
- **`safe_deploy.sh --frontend`가 빌드를 안 한다** — stale 번들이 실제로 배포됐다. **프론트 배포 전 `npm run build` 필수**
- **정찰 Chrome과 페처가 같은 프로필** — 정찰 세션이 열려 있으면 페처가 `chrome_profile_busy`로 **영구히 죽고 자가복구도 못 한다**
- **★`scripts/next_ids.sh`가 이 트랙의 D-N을 안 본다**(D-NAO·교훈만) — 그래서 병행 세션과 **D-19가 겹쳤다**. 내 것을 D-20으로 밀어 해소. 도구 보완 필요
- **판매분석 BETA 무료체험 2026-08-20 종료** — 15일 뒤. 끝나면 판매 축(sell-through)이 끊긴다
- codex 교차 리뷰 **7건 미실행**(한도 리셋 **08-09**)
