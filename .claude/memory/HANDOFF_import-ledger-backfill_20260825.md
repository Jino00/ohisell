## 5. ★★다음 세션의 본체 — 강화유리가 화면에 안 뜨는 «구조적» 이유

```
연결 화면이 보는 것 :  line_type = 'material'   (부자재 8줄)
강화유리            :  line_type = 'product'    (제품 150줄)
```
