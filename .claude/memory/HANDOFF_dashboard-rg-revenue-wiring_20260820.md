## 1. 계약 초안 (Jino 승인 대기)

**목표**: 대시보드가 쿠팡 3채널(3P·로켓그로스·로켓배송)을 **제 이름으로, 매출 빠짐 없이** 보여준다.

**하는 것**
1. 대시보드 손익 엔진이 **RG 매출**을 읽는다. 원료 `coupang_rg_order_item`, 계산식은
   `intelligence.py`의 것을 **재사용**한다(새로 만들지 않는다 — 만들면 세 번째 엔진이 생긴다).
2. 채널 라벨 분리: `쿠팡 로켓그로스·윙` → **`쿠팡 3P(판매자배송)`** / **`쿠팡 로켓그로스`** /
   `쿠팡 로켓배송(1P)`.
3. RG 행에 **원가 커버리지**를 표시한다(2026-08-20 D-22가 만든 「⚠️ 원가 미상 N%」 재사용).

**안 하는 것**: 종합 조망(command-center) 화면 · RG 수수료 계산 규칙 변경 · 로켓1P 매출 축 구조 ·
네이버/자사몰 · 새 데이터 수집(원료는 이미 있다) · 두 RG 원장의 12% 차이 해소(조사만, 별건)

**판단기준**
- 항상 **기존 계산식을 재사용**한다. 왜냐하면 이 결함 자체가 「같은 숫자를 두 엔진이 따로 낸다」이고,
  세 번째 엔진을 만들면 문제를 키운다.
- 항상 **종합 조망과 같은 값**을 낸다. 갈라지면 어느 화면을 믿을지 모르게 된다.
- 모르는 것은 0으로 채우지 않는다(원가 못 붙은 RG 매출은 커버리지로 자백).

**금지선**: RG 매출을 `orders`에 밀어 넣지 않는다(RG는 주문 원장이 없다 — 평행 엔진 구조 유지) ·
콘솔 GMV와 우리 원장을 **더하지 않는다**(이중계상) · 추정 원가 금지.

**합격기준 (라이브, 30일 창 2026-07-21~08-19 기준)**
- ⓐ 오픽스 로켓그로스 행이 **매출과 함께** 뜬다(현재 매출 178,200원 = 3P만)
- ⓑ 그 행 순이익이 더 이상 「매출 178,200 / 순이익 −4,782,379」가 아니다
- ⓒ 채널이 3줄로 분리돼 각자 이름으로 뜬다(3P / 로켓그로스 / 로켓배송)
- ⓓ 대시보드 RG 매출 == 종합 조망(`/api/overview/command-center`)의 `revenue_rg` (같은 창)
- ⓔ **오하이테크에는 로켓그로스 행이 안 뜬다** (Jino 확인: 판매 없음)
- ⓕ 네이버·자사몰·로켓1P 숫자는 **불변**(회귀 없음)

**예산**: 반나절. 적대 리뷰 1회 + 완료 QA 1회 포함.

## 2. 왜 이 일이 필요한가 (진단 — 이미 실측 끝냈다)

**대시보드와 종합 조망이 서로 다른 엔진을 쓴다.**

```
종합 조망  → services/coupang/intelligence.py     → RG 매출 O · 채널명 분리 O
대시보드   → services/profit_calculator.py        → orders 테이블만 읽음
```

`orders`에 RG·로켓1P는 **행이 없다**(실측). 그래서 대시보드는 그 매출을 못 본다.
**그런데 RG 정산 수수료는 차감한다** → 오픽스가 매출 17만원에 순이익 −478만원으로 보인다.

★**2026-08-20 오전 D-22에서 고친 것과 같은 형태다** — KPI 카드와 요약표가 다른 경로를 써서
갈라지던 것. 그때 두 화면을 한 경로(`_channel_rows`)로 모았고, 남은 것이 그 경로가 RG를
안 보는 것이다. 교훈 #339와 같은 계열.

### 3-3. ⚠️ RG 매출 원장이 둘이고 **12% 다르다**
| 원장 | 30일 오픽스 RG |

## 4. 오늘 내가 빠진 함정 두 개 — 같은 데 빠지지 마라

1. **두 원장을 나란히 놓고 모순이라 불렀다.** 대시보드 매출은 `orders` 기반이고
   `vendor_summary`는 쿠팡 콘솔 GMV다. 「오하이테크 1,022,000 vs 876,100 불일치」라고 했는데
   실제로는 `orders` 1,069,500 − 취소 57,500 + 배송비 = 1,022,000으로 설명된다. **정상이었다.**
2. **leaf 라벨에 속았다.** 「쿠팡 로켓그로스·윙」 한 줄이 WING+RG를 묶어 놓아서, RG가 없는
   오하이테크 행을 「오하이테크 RG 행」이라 불렀다. **Jino가 잡아줬다**(원문: *"오하이테크는
   RG 판매가 없어. 판매자배송 상품인 3P 매출만 있어."*). 이게 계약 §2(라벨 분리)의 직접 동기다.
