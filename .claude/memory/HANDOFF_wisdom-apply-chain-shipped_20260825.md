### 2-C. ★코디네이터가 잡은 결함 — 「승인 한 건이 남의 파라미터를 지운다」
`apply_params`가 PUT 계약대로 **전체 치환**인데 승인은 키 하나만 넘겨, 사람이 PUT으로 설정해 둔 다른 키가 **조용히 코드 기본값으로 복귀**했다.

## 4. 확정된 결정사항 (번복 금지)

- **`apply_params`의 `merge`**: PUT은 **전체 치환**(사람이 화면 전체를 보고 저장하는 맥락), 승인은 **`merge=True`**(제안 «한 건»의 맥락). 병합 기준은 **저장된 행의 원문**이지 실효값이 아니다.
- **적용 «값»의 크기는 사람이 정한다** — 프리필은 «현재값»이지 «제안이 권하는 값»이 아니다. 코드가 크기를 발명하면 그게 새 상수 발명이다.
- **B7 클램프는 fail-closed** — `scope`가 정확히 `"unconditional"`이 아니면(부재·오타 전부) 조건부, `param`이 SPECS 밖이면 미매핑. **격상 방향으로는 절대 안 흔들린다.**
- **B5는 지혜 성적표 표면에 싣는다** — 계약이 지목한 「D-NAO-247 C6 주간 보고」가 **아직 없다**(C6 미체크·D-NAO-247 미착수). 새 주간 보고를 신설하지 않는다(계약이 「신설 0」이라 한 것을 뒤집는 스코프 확장). D-NAO-247이 C6을 만들 때 이 계산값을 재사용하면 된다.
- **CI 린트 래칫(`--max-warnings 96`)은 새 코드가 넘기지 않는다** — 기존 36건은 해당 파일을 맡은 트랙의 부채.
