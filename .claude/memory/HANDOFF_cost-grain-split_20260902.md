## 4. ★적대 리뷰 — 1R FAIL(P1 2) → 2R PASS

**P1-1 — 내가 계약에 [미상]으로 적어 둔 자리를 폴백으로 덮었다.** §8 부기가 「태블릿 36건 전건에 크기 낱말이 있는가 = [미상], S2 미리보기 unassigned가 답한다」인데, 구현이 낱말이 안 걸려도 무조건 `"기본"`을 내 **unassigned가 원리적으로 0**이 됐다. 리뷰어 재현: `뉴패드X100`(낱말 0개) + 「기본」군과 같은 원가 → `safe_to_execute: true` · `unassigned: []` **완전 침묵**, note엔 **없는 근거**(「크기 낱말 「기본」」).

수리는 **막기가 아니라 말하기** — 라이브 21건 **전건**이 낱말 없이 기본에 들어(원가표가 그렇게 생겼다) 막으면 정상 21건이 전부 선다. `(등급, 출처)` 반환 · note가 「잔여 — 크기 낱말이 하나도 안 걸렸다」로 사실을 적음 · `residual_skus`/`residual_total`/화면 `(잔여 N)`으로 **센다**.

**P1-2 — 귀속 근거 표면을 아무도 안 지켰다.** `recipe-link-attribution`을 꺼도 프론트 144건 전건 초록. 픽스처에 note가 있었는데 **소비하는 테스트가 0**. 배선 테스트 2종 + note=null 링크 픽스처(동등 변이 방지) 추가.
