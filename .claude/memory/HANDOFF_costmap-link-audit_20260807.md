## 3. 확정된 결정사항 (번복 금지)

### D-CPP-25 — 원가 매핑은 «값»과 «링크 대상»이 다른 층이다. 링크는 두 렌즈로 판정한다
- **원가표 업로드는 링크를 고치지 않는다.** 같은 날 「SellC 원가표 업로드」 세션이 `product_master.cost_price`
  687행을 정본화하고 미연결 62건을 수기 매핑해 커버리지를 97%까지 올렸지만, **링크가 가리키는 대상이
  맞는지는 보지 않았다**(Jino 확인). ref 47 §8-2가 예고한 그대로다.
- ★**원가표가 정확해질수록 잘못된 링크의 오차는 커진다** — `OHI-0297`이 2,516→**1,800**(PET 정가)으로
  정확해지자, 거기에 잘못 연결된 **강화유리** 상품의 원가가 더 낮아졌다.
- **판정은 두 렌즈가 같은 답을 낼 때만**:
  ①**제품 성격**(소재 × 기능) 대조 — 브리지 유무와 무관, 전건에 걸린다
  ②**결정적 브리지**(`product_channel_mapping` ch5, `externalVendorSku` 코드 정확일치)
  → 둘 다 지지한 11건만 교체. 브리지 없음 3건·브리지도 어긋남 1건·상품명 없음 1건은 **판정불가로 남긴다**(원칙22)
- **manual은 불가침** — Jino 확인분을 브리지가 덮게 하지 않는다(실측상 manual 불일치는 1건 9,540원뿐)
