2. ★★**자기 변이 M13이 1차에서 생존했다** — 「수집 완주 로그 라인 제거」. 계약 S5-a가 **로그를 표면으로 지목**했는데 그 표면을 지키는 테스트가 **0건**이었다. 만드는 층(적재)은 20종이 지키고 **닿는 층(로그)은 아무도 안 지켰다** — 교훈 #362의 재현이고 n=57·n=58·n=59에 이은 **네 번째**다. 로그 표면 테스트 4종 추가·재주입 사살.
3. ★**「결정 즉시 저장」 위반이 채번 도구를 눈멀게 한다** — n=60이 트랙에 D-NAO-262를 안 적어서 `next_ids.sh`가 **이미 소비된 262를 「다음 가용」으로** 내놨다(스크립트가 트랙 파일만 grep한다). 이번 세션이 262를 소급 기록했다.
4. ★**테스트가 나를 두 번 먼저 잡았다** — ⓐ쓰기어댑터 인구조사가 *"import하지 않는다"*고 쓴 **내 주석**에 걸림 ⇒ 문자열 검사를 **AST import 검사**로 교체(주석을 코드로 오독하는 검사는 「단어를 지우면 통과한다」를 가르쳐 더 나쁘다) ⓑ스케줄러 로그 테스트에 늘 stub으로 떨어지는 죽은 분기(`__wrapped__`)를 넣었다가 단순화.
5. ★**로그 위치를 실측으로 배웠다** — 앱 로거는 **stderr → `-error.log`**. `out.log`만 grep했으면 「로그 라인 없음」으로 오판할 자리였다.
6. ★**폐기 결정은 «폐기했다»고 적힌 줄을 읽어야만 전달된다**(2-1 참조) — HANDOFF에 안 실린 결정은 다음 세션에 도달하지 않는다.
