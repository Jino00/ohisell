## §0 방향 고정 (변경 금지)

1. **2축 분리(D-NAO-81)**: A축(자르기, ROAS 판정)=기존 유지·무변경. B축(살리기, 흐름 유지)=이 스프린트. 서로의 판정을 덮어쓰지 않는다.
2. **충돌 방지 규칙(핵심)**: A축 확정 손실 개체는 B축 소생 **금지** — ①userLock=True(정지) 개체 ②스톱로스/터미널정지 이력 개체(change_log `set_user_lock` + `[shopping_pause_candidates]`/`[터미널정지]` 사유) ③무전환 확정(충분 표본에서 전환 0으로 A축이 자른 것). 소생 대상 = **과거 30일 전환 이력 ≥1 또는 판정 표본 미달**(클릭이 판정 최소치 미만) 개체만.
3. **새 권한 없음**: 복원 발사는 기존 개방 레버(그룹/키워드 입찰 UP)와 기존 봉투(BEP 천장·가드레일·킬스위치·쿨다운·캡·change_log) 그대로. 이 스프린트가 바꾸는 것은 **발동 시점(조기)과 발동 근거(궤적)**뿐.
4. **관찰→개입 최소화**: 경보는 브리핑에 전건 표면화. 개입은 봉투 안에서만.
