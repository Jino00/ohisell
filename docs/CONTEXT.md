## 기술 선택 근거

### Frontend: React + Vite + TypeScript + Tailwind
- Anthropic 실험에서 검증된 스택
- Claude의 학습 데이터가 풍부해 실수 적음
- Tailwind: 유틸리티 클래스 방식으로 디자인 일관성 유지 쉬움

### Backend: FastAPI (Python 3.11+)
- 자동 Swagger 문서, 타입 힌트 강제 → AI 실수 감소
- SQLite(개발) → PostgreSQL(프로덕션) 전환 용이

### 버전 전략
- 검증된 안정 버전 우선
- 업그레이드는 명시적으로 결정하고 기록
