## §0. 북극성 원문 (참조가 아니라 원문으로 싣는다)

### 트랙 최상위 목표 — Jino 원문 (D-NAO-59, 2026-07-19)

> *"무조건 이익스팟 순위에 있어서 매출 증가가 없는것보다 Roas는 떨어지지만 매출이 늘어서 총 이익이 늘어나는 경우, 구간도 분명히 있거든. 우리의 최종목표는 이거야. 이게 우리가 만든 MOP프로그램의 최종 목적이고 목표야."*

### M4의 합격 관측 — 북극성 §6 원문

> **M4** | L3 재개 — 소유권 분리 확정 → 카나리 `optimizer='ours'` 재가동 | L3 | **Jino 결정 2건**(§8-①②) — 이 문서는 시점을 촉구하지 않는다 | 카나리 캠페인에서 실집행 diary 행 생성 + 가드레일 위반 0 + 대행사 되돌림 0을 **1주 연속 관측**

### M4의 «안 함» — 북극성 §6-b 원문

> **M4 안 함**: 예산 변경 개방(스프린트 X부터 불변의 스코프 밖) · 개별 캠페인 하드코딩(전역 규칙만, D-NAO-65 ③) · 카나리 성적을 전 캠페인으로 즉시 일반화(카나리는 카나리 창의 숫자다).

### 그리고 §6 각주 (D-NAO-230, Jino 승인 2026-08-23)

> **카나리 1주 성적의 총이익과 M5의 「지혜→총이익 기여」는 §3 「총이익의 자」 행이 지정한 자로 재며, 자의 가정·창을 성적과 반드시 병기한다.** … M4 합격 관측에는 **총이익 항이 아예 없어서, 자가 부풀어 있어도 카나리가 그대로 통과하기 때문이다** … ★구간 자로 전환되면 이 각주의 실제 운용은 **「하한으로도 흑자인가」**가 된다.

```
[지금 병렬 가능]  ②소유권 분리 «협의» 시작(달력 시간)  ∥  M4-d·M4-k 선행 조사(읽기 전용)

        ↓

        ↓

        ↓
[판정]           북극성 §6 M4 합격 관측 + 위 4항목 → 트랙 M4 체크박스
```

## §5. 이 초안이 «안 하는 것»

- **시점을 촉구하지 않는다** — 북극성 §6 M4 열의 *"이 문서는 시점을 촉구하지 않는다"*를 승계한다.
- 예산 변경 개방 · 개별 캠페인 하드코딩 · 카나리 성적의 즉시 일반화 (북극성 §6-b M4 안 함 그대로)
- **새 마일스톤을 만들지 않는다** — 전부 M4 계약의 합격기준·선행 조사로 흡수 가능한 크기다(전역 §1 「게이트를 새로 세우지 않는다」).

## §6. [미상] — 이 초안이 못 채운 것

1. **카나리 후보의 구체 목록** — M4-f(상품BEP 230그룹) ∩ ref 94 §5(양끝 흑자 195건)의 교집합을 아직 안 뽑았다. Jino 결정 ① 이후에 뽑는 것이 맞다(그 전에 뽑으면 「묻기 위한 조사」다).
2. **관측 창 14일의 근거 강도** — D+1~7 정착에서 역산한 최소값이고, 외부 표준 6주와의 간극은 «우리 볼륨»을 이유로 좁혔다. 볼륨 근거는 아직 숫자로 안 댔다.
3. **M4-a의 비율 문턱 3.4:1** — 오늘 라이브 값(ref 94 §6)이지 «허용선»의 근거가 아니다. 문턱을 정하려면 「어느 비율에서 총이익이 꺾이나」를 봐야 하는데 그 곡선은 실집행이 재개돼야 그려진다 — **닭과 달걀이라 초판은 「나빠지지 않는다」(상대 조건)로 쓴다.**
