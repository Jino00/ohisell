## §2. 판단기준 ("항상 A, 왜냐하면")

1. **항상 ref 65 S2 원문이 합격의 정의다**, 왜냐하면 D-NAO-213·북극성 §6 M2 행이 재규정 금지를 못박았고, 몰래 고쳐 쓰기가 이 트랙의 반복 사고이기 때문이다. 원문에 없는 항목(ⓓ의 라이브 관측)은 **신설임을 명시**하고 단다 — 인용으로 착각하면 재규정 금지가 무너진다(M2-b2 전례).
2. **항상 판정층까지만 만들고 실행은 기존 잠김에 맡긴다**, 왜냐하면 M2의 정체성이 «쓰기 없는 배선»이고 잠김(`auto_operate` 전건 0, 승인원 비활성)이 살아 있는 것 자체가 라이브 증거이기 때문이다.
3. **항상 기존 숫자를 재사용하고 새 상수를 발명하지 않는다**(하한 15/주=[6] 벤더 하한 · 창=성숙 컷 D−8 하의 기존 정착창 계열 · 환경 층 2=ref 63 확정 축 · K=10), 왜냐하면 근거 없는 상수는 다음 감사가 들추는 부채이기 때문이다. 재사용이 불가능하면 멈추고 기록한다 — 값을 지어내지 않는다.
4. **항상 실측이 전제를 반증하면 §4-B ④를 따른다**, 왜냐하면 이 계약 자체가 발주 전제 1건(§10-① 미결)의 반증 위에서 작성됐고, 이 트랙의 전제 반증은 상습이기 때문이다(직전 계약에서만 「70/70 5개」→라이브 10, 「385그룹」→431그룹).
5. **항상 «0건»의 사유를 갈라 센다**, 왜냐하면 「게이트가 막았다」와 「레인이 안 돌았다」는 같은 0으로 보이고, 이 함정은 방금 끝난 계약이 라이브로 증명했기 때문이다(점화준비 S1-a: `auto_operate` 전건 0이라 사유별 카운터가 구조적 미도래 — «모름≠여유»).
6. **항상 총이익 값은 기존 자로 잰다** — `ad_profit = conv_amt/1.711 − cost`(ref 65 상수)와 총이익 델타 자(D-NAO-225), 구간 보정계수 [0.827, 점추정](D-NAO-234)을 소비하고 **새 자를 만들지 않는다**, 왜냐하면 자가 갈라지면 성적이 표면마다 다른 숫자가 되기 때문이다(자·창 병기 — D-NAO-230).

### 4-B. 자동 판단 규칙 — 갈림길마다 미리 내려 둔 답

**① 적대 리뷰가 P1을 내면**: diff 안에서 고칠 수 있으면 수정→2R(수정 diff만). 2R 새 P1 또는 슬라이스 경계 초과면 머지 없이 닫고(반착지) 부채 기록 후 다음 슬라이스로. P1=0만이 머지 조건.

**② 마이그레이션이 prod에서 실패하면**: 중단·롤백 금지(순서 규칙상 prod는 구스키마+구코드로 무결). 기록 후 마이그 없는 슬라이스로.

**③ 예산 소진 시**: 새 슬라이스 시작 금지. 진행분은 커밋→PR까지 착지. 반쯤 배포 상태로 세션 닫기만 금지.

**④ 실측이 계약의 전제를 반증하면**: ⓐ반증을 증거 좌표와 함께 먼저 기록 ⓑ슬라이스 목표가 유지되면 구현만 사실에 맞춰 조정(합격기준 원문은 안 고친다 — 무의미해진 항목은 「전제 반증 — 판정불능」) ⓒ슬라이스 존재 이유가 죽으면 건너뛰고 기록(T4가 후보 1호 — 라벨이 기설이면 «좌표 기록»으로 축소 종결) ⓓ계약 전체의 목적이 흔들리면 멈추고 Jino에게 남긴다.

## §6. 종료 조건

- **적대 리뷰**: 슬라이스마다 PR 경계 1회. 위임문에 이 계약 §3·§4-B 원문과 표면 변이 요구(4-C 공통)를 싣는다 — 서브에이전트는 이 문서를 못 본다.
- **완료 QA(항상)**: 슬라이스 착지마다 Sonnet high·읽기 전용·항목별 5값. 라이브 미도래 항목(X9 표본 0 등)은 «해당 없음»·판정불능이 정상 종결이다.

- **착수 규칙**: 착수 시점은 Jino가 정한다. 착수 세션은 이 계약 원문 + 앵커(목표이름 복사) + §0-3 재측정부터. **Jino에게 묻는 경우는 §4-B ④-ⓓ 하나뿐이다.**

## §7. 북극성 대조 (D-NAO-226 — 착수·종료 세션마다 갱신)

1. **M 귀속**: **M2 그 자체** — 이 계약이 닫히면 M2 체크박스가 처분된다(§6). 층은 L2(판단층) — 북극성 §2의 순서 원리(M0·M1 알기 → **M2·M3 판단·학습 준비** → M4 손 재개) 그대로다.
2. **5요소**: ②(논문·구조 — [1][6]·⑤·[8] 잔여·§5-c가 판정면에 실린다)와 ⑤의 전제(조치×환경 셀 = 후보 지혜의 모양)가 움직인다. **④자동화 운영은 이 계약으로도 0이 유지된다**(2026-08-28 기준 29세션째 — 그대로 적는다). 총이익 이동 0도 그대로 적는다 — L2 단계의 정상 격차다.
3. **§7 대칭 검사**: 실태 — 학습 가능 파라미터(SPECS) **7종 전부 브레이크 계열, 액셀 0**. 이 계약의 ⓑ는 브레이크 +1이지만 **층이 다르다**(ROAS 방어가 아니라 «약한 신호 위 자동화 방지» — [6]의 데이터 규율). 액셀 방향의 짝: ⓐ가 주말·공휴일(확정 음의 효과 −8.0M/−0.9M원)을 분리해 **평시 성과가 음수 효과에 눌려 과소평가되던 것을 걷어내고**, ⓔ가 「흑자였던 조치와 그 환경」을 표면화해 확장·재개방의 근거 재료를 만든다 — 브레이크만 늘리는 계약이 아니다. 단 정직하게: 이 계약은 실행이 없어 액셀·브레이크 어느 쪽도 «집행»은 못 움직인다 — 대칭은 판정면 층에서만 검사했고, 집행 층의 비대칭(D-NAO-85형)은 M4 계약의 검사 항목으로 남는다.
