## 2. 판단기준

- **항상 확인 1클릭 후에만 쓴다**, 왜냐하면 그 클릭이 곧 「Jino 승인」이라 기존 금지선(승인 없는 값 저장 금지)의 집행이기 때문이다.
- **정본은 항상 DB의 단가 원장이고 엑셀은 왕복 매체다**, 왜냐하면 파일은 이력·출처·승인을 싣지 못함이 §0-C(같은 품목 두 값)로 실증됐기 때문이다.
- **왕복 파일의 모양은 항상 화면의 표를 따른다**, 왜냐하면 Jino가 *"그 표를 다운받아서"*로 못 박았고, 포맷을 따로 발명하면 참의 정의가 둘로 갈라지기 때문이다.
- **충돌·모순은 항상 사람이 고른다**, 왜냐하면 시스템이 값을 고르는 순간 「추측 금지」 금지선을 넘기 때문이다.
- **업로드 경로는 항상 하나다**(초기화/수정분 = 같은 diff 화면의 선택 범위), 왜냐하면 두 경로는 두 벌의 버그이고 초기화 별도 경로는 삭제-재생성 결함을 부활시키기 때문이다.
- **자백 문구는 항상 옮기되 지우지 않는다**, 왜냐하면 각 문구가 실사고에서 태어났기 때문이다.
