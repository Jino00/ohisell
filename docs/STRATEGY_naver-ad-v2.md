# 우리 MOP 운영 전략 v2 — 시스템 전체 관점 (D-NAO-67)

> 확정 2026-07-20 (Jino). 단일 참조 문서 — 결정 원문·이력은 트랙(D-NAO-59/66/67), 실행 상세는 각 스프린트 계획서.
> v1과의 차이: 방어 체계(DL/B/UI) 완성 후, 무게중심을 **공격층(볼륨 확장) 완성**으로 이동. 순위 제한 폐지·장중 상향·순위 서보·in-out 생태계 신설.

## 0. 목적함수 (불변 — D-NAO-1/59)

**총이익(절대액) 극대화.** target ROAS(상품별 원가 기반 BEP × 공격성 배수)를 하한으로 매출을 최대한 키운다. ROAS 최대화·순위 달성·클릭 최대화는 목표가 아니다. 한계 ROAS = target인 지점이 운영 목표점.

## 1. 4대 운영 원리

### ① ROAS 단일 지배 (D-NAO-66)
모든 레버(그룹입찰·소재입찰·키워드입찰·검색어 제외/승격·예산)의 결정 기준은 단 하나 — **"이 변경이 target ROAS를 지키면서 매출을 늘리는가."** 순위·밴드·시간대·클릭수는 관찰 지표이자 탐침의 프라이어일 뿐 제한이 아니다. 1등이어도 ROAS ≥ target이면 유지, 3등이어도 깨지면 하향. (순위 기반 상한 전면 폐지 — 과열밴드 DOWN·learned band 천장 제거 = 스프린트 IU)

### ② 반응 속도: 행동은 시간 단위, 채점은 D+1~7
- 감지 = 1시간(네이버 허용 최속). 하향(방어) = 시간당(가동 중). **상향(공격) = 시간당**(IU — 장중 누적 tally: 직접전환 ≥2 ∧ 추정 ROAS ≥ target×1.2 ∧ 예산 여력 → 스텝 상향, 쿨다운 2h).
- 확정 채점 = D+1(간접전환 정착)~7일(만성 판정) — 행동을 기다리게 하는 게 아니라 **행동을 자동 교정**한다(맞으면 승자 관성, 틀리면 고삐 회수).
- 가짜 신호 브레이크(GATE P2 보강): 정산 거부권(정산이 명시적 target 미달이면 장중 추정만으로 상향 금지) + 정산 미확인 유닛은 일 1스텝. ccnt 귀속 라이브 캘리브레이션 후 완화 가능한 다이얼.

### ③ 순위 서보 — 제어 언어는 입찰%가 아니라 순위 (IU-R)
조절의 궁극 목적은 CPC가 아니라 순위다. 스텝의 단위를 "±15%"에서 **"한 순위 위로"**로 전환:
- **파워링크**: estimate API(순위별 필요입찰)로 목표 순위 입찰 직행 — 경제성 상한(기대CVR×객단가÷target ROAS)으로 캡, ±15% 면제(D-NAO-20 선례).
- **쇼핑검색**: 순위별 필요입찰 API 부재 + 경쟁 입찰 시변 = 사전 계산 불가 → **폐루프 서보**: 스텝 → 다음 시간 실측 avg_rank 확인 → 목표 1단 이동까지 반복(ROAS 게이트 통과하는 한), 유닛별 입찰→순위 반응 곡선을 이력으로 학습해 첫 스텝 크기를 정교화.

### ④ 개체군 순환 — in-out 생태계 (Jino 확정)
제외 = 사형이 아니라 상태 전이. 캠페인은 고정 명단이 아니라 순환하는 개체군:
```
[본대]  target 이상 — 서보로 볼륨 확장
  ↓ 성과 하락              ↑ 회복 승격 (살아나면 꾸준히 상향)
[저성과 그룹]  저입찰 강등 — 싼 가격에 실험 지속
  ↓ 지속 loss              ↑ 탐침 재심사·시장 변화 감지
[바닥/제외]  출혈 정지 (기억은 보존)
```
- 회전율(입장·강등·복귀 카운트) 자체가 건강 지표 — 회전 0 = 탐색 정지 병리.
- 층별 리듬: 입찰 in-out=시간 단위, 검색어/키워드 in-out=일~주(표본 한계). 재심사 비용은 탐색 예산 캡 안에서만(D-NAO-20·ref 33 learning-on-tails).
- 사람(대행사)은 영구 컷이 실무 타협 — 전 개체 기억·주기 재심사·자동 복귀는 기계만 가능 = 우리 차별점.

## 3. 레버 스택 × 로드맵

| 순서 | 스프린트 | 내용 | 상태 |
|---|---|---|---|
| 1 | **IU** | 장중 상향 개방 + 순위 제한 폐지 + 폭주 브레이크 | 구현·GATE PASS·P2 보강 중 → 즉시 배포 |
| 2 | **IU-R** | 순위 서보화(①파워링크 estimate 직행 ②쇼검 폐루프+반응 곡선 학습) | 다음 |

| 4 | **L2** | 예산 자동증액(ROAS 달성 ∧ 예산 병목, ref 33) — 누수 막은 뒤 물 붓기 | 대기 |
