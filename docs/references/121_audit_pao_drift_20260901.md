- prod 관측이 이 워크트리와 같은 배포 커밋에서 나온 것인지 대조하지 않았다(`ref 65` §1-1-b가 이미 남긴 미확인과 동일 성격).
- ②의 "실효 표본" 문지기가 실제로 얼마나 시급한지(=[9] 풀링 후 하한 재정의가 M6 진입을 얼마나 앞당기는지)는 이 세션 범위 밖 — 다음 M2/M6 설계 세션 몫.
