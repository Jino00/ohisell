## 1. 방법 — 렌즈 둘, 축 여섯

**렌즈 ①결정적 브리지**: `coupang_rocket_sales_daily.option_id` →
`product_channel_mapping(channel_id=5)` → `product_master`.
이 매핑은 쿠팡이 주는 `externalVendorSku`가 `internal_sku`와 **정확일치**할 때만 생성된다
(`product_sync.py:_maybe_upsert_mapping`) — 이름 유사도가 아니라 코드 일치다.
★**브리지는 시간 축이 없는 구조적 사실**이라 판매 창으로 자르지 않는다(§6 P1-1).

**렌즈 ②제품 성격**: 쿠팡 상품명과 내부 상품명을 축별로 대조.

| 축 | 종류 | 값 | 이 감사에서 실제로 판정을 만들었나 |
|---|---|---|---|
| `part` 부위 | hard | doorlock/case/lens/back/screen | **예** — replace 3건의 근거 |
| `count` 매수 | hard | 정수 | **예** — replace 4건 전부의 근거 |
| `model` 기종 | soft | 집합 | **예** — label_only 12건의 근거 |
| `material` 소재 | hard | pet/tempered/tpu | **아니오**(§4-②) |
| `privacy` 사생활 | hard | True/False/None | **아니오**(§4-②) |
| `magsafe` | hard | True/False/None | **아니오**(§4-②) |

**둘 다 값이 있고 다를 때만** 충돌이다. 한쪽이 없으면 «모름»이지 «다름»이 아니다.
`privacy`가 **유일한 판별자**이고 무광·매트·저반사·지문방지는 같은 기능의 다른 표현이라 축이 아니다.
`material`은 「유리코팅」/PET를 강화유리보다 **먼저** 본다(유리코팅은 PET이지 강화유리가 아니다).
★뒤의 세 축은 규칙은 맞지만 **이번 데이터에서는 한 건도 가르지 못했다** — §4-②에 실측을 적었다.

**판정**: `replace`(현재만 충돌) / `keep`(브리지만 충돌) / `label_only`(hard 전부 일치, 기종만 다름) /
`agree` / `undetermined:*`(브리지 없음 · 브리지 둘 · 이름 없음 · 둘 다 무충돌 · 둘 다 충돌).

## 4. 판정기가 실제로 잡은 자기 결함

**①고쳐서 결과가 바뀐 것 셋**
1. **매수 정규식이 기종을 매수로 읽었다** — `(\d+)\s*(매|p|P|…)`가 「아이폰17 **P**ro」를 매수 17로,
   「S26 **P**lus」를 26으로 잡았다. `p`/`P` 뒤에 영문자가 오면 단위가 아니도록 고쳤다.
2. **`privacy`가 「이름 없음」을 False로 승격시켰다** — False는 「사생활 제품이 아니다」라는 주장이고
   None은 「모른다」다. 3값 원칙 위반이라 고쳤다.
3. **요약 표가 새 판정값을 조용히 삼켰다** — `lens_tie`를 둘로 쪼갰더니 고정 순서 목록에 없는
   두 값 61건이 표에서 사라져 **합계가 172가 아니라 111로 보였다.** 「빠졌다」는 표시가 어디에도
   없었다. 데이터에 있는 값은 목록에 없어도 뒤에 붙이도록 바꾸고 **합계 행**을 넣었다 —
   잘림이 스스로 신고하게 만든 것이다.

**②판정을 만들지 않은 축 셋 (변이 주입으로 드러남)**
적대 리뷰가 hard 축 5개 중 `material`·`privacy`·`magsafe`를 **통째로 무력화해도 결과가 1비트도
안 바뀐다**는 것을 보였다. 이번 판정을 실제로 만든 것은 `part`·`count`·`model` 셋뿐이다.
규칙이 틀린 게 아니라 **이 데이터에 그 축이 가를 사례가 없다**. 특히 `material`은 이름 61건이
「강화유리**코팅**」이라 pet·tempered 마커를 동시에 갖는데 cp·현재·브리지가 같은 표현을 쓰므로
순서를 뒤집어도 양쪽이 같이 뒤집혀 **원리적으로 반증 불가**다.
→ 회귀 테스트 24건에 **합성 입력으로 이 축들을 못 박았다**(실측으로는 검증할 수 없으므로).
