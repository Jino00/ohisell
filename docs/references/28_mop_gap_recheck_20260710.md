## 2. 라이브 재실측이 바꾼 사실 (7/7 벤치마크 대비 ⭐신규)

1. **요금제는 3단계(Basic/Lite/Pro)** — ref 24는 2단계로 기술. Lite는 볼륨 상한만 완화(최적화 아이템 1→5, 그룹 30→100). **기능 언락(캠페인 생성·커머스 리포트·제외키워드)은 전부 Pro 전용.**
   → 전략적 함의: **MOP가 돈 받고 파는 최상위 기능 3개 중 하나(제외키워드)를 우리는 이미 자동화까지 끝냈고**(진단→제안→승인→실쓰기→E2 위임), 나머지 2개는 우리 §8 큐(G6)와 기존 손익 대시보드가 커버한다.
2. **⭐목표입찰**(소재 단위 목표 입찰, Basic cap 1) — ref 24/25에 전혀 없던 신규 메뉴. G5(소재 grain)의 시장 근거 강화 — MOP는 소재 단위를 입찰 대상으로 상품화하는 중.
3. **순위유지가 Basic 무료 티어에도 제공**(키워드 5개) — 순위유지는 시장에서 "기본기" 취급. §8의 G4 우선순위 상향 근거. 순위 모니터링 UI = 24시간×키워드 히트맵 테이블(구조 스크린샷 확보, `11b`).
4. **제외키워드에 "보수적/공격적 추천" 2단 강도 토글** — 우리 제안에는 없는 UX. 채택 비용 낮음(제안 필터 파라미터).
5. **이지모드 = 자동 다중목표 + 균형/성장 운영 라디오 + 예산 슬라이더**(7일평균↔공격적) — 우리 듀얼모드(D-NAO-22)와 동일 프레임 실측 확인. 우리가 3단 공격성×4모드로 더 세분화된 것도 확인.
6. **CPC 리부트 툴팁 전문 확보** — "입찰가 재학습 7일 부스트, 자동 종료". 탐색/활용(exploration) 개념의 상품화 — X2/X3 설계 시 참고(재학습 트리거 아이디어).
7. **UTM 이상감지 = GA4·에어브릿지·앱스플라이어 연동 시** — 전환툴 3종 확정. 우리 스코프(스마트스토어 단일 랜딩)에선 URL/UTM 오류 위험 자체가 낮음 → **의도적 미채택 후보**로 분류(아래 §5).
8. **유닛 40개 캡 = "ML모델 40개" 실측 일치** — 유닛=학습 grain 가설 확정. 우리 D-NAO-24(게이트 통과 엔티티 전부 개별 모델, 수 무제한)의 구조적 우위 근거가 더 단단해짐.
9. **관찰 계정은 현재 100% 미최적화 상태**(최적화 가능 6,328,756원 vs 최적화중 0원, 두 세트 모두 "종료") — **카나리 전환 시 MOP 충돌 리스크 없음 재확인**(X0-2 실측과 일치).
10. **커버리지 공백(정직 기록)**: ref 24 §3의 "4단 엔진 가동 카드"(러닝·플래닝·플라이트 타임스탬프)가 **현 사이드바 어디에도 없음** — 세트가 전부 종료 상태라 미노출이거나 UI 개편 가능성. 이번 실측에서 재관찰 실패. 엔진 상태 UI를 복제하려면 ref 24 서술 기반 자체 디자인 필요.

## 3. 우리가 MOP보다 우수한 점 (라이브 실측으로 확정)

| # | 항목 | 근거 (우리 코드 / MOP 실측) |
|---|---|---|
| 1 | **BEP-ROAS 수치 타겟** | `bep_calculator`(판매가÷공헌이익×공격성) vs MOP은 방향 택1·수치 지정 불가(이지모드는 아예 자동 다중목표) |
| 2 | **변경 이력 투명성** | `naver_change_log` before/after 실측+D+7/14 채점 vs MOP은 26개 화면 전수 스윕에도 **입찰 이력/로그 화면 자체가 없음**(ref 24 §10-1 재확인) |
| 3 | **LLM 전문가 검토(Ava)+E2 위임** | `expert_desk` 크론 08:05 prod 가동, 평결 44행 실측 vs MOP에 해당 개념 없음 |
| 4 | **제외키워드 자동화 깊이** | 진단(`exclusion_candidates`)→제안→승인→실쓰기(`naver_sa_writer`)→위임 자동실행(`delegation_gate`) 전 파이프라인 vs MOP은 Pro 전용+수동 등록(추천 리스트 제공 수준) |
| 5 | **예측 grain 무제한** | 계정→캠페인→그룹→키워드 사다리에서 게이트 통과 엔티티 전부 개별 모델(D-NAO-24) vs MOP 유닛 40개 캡 실측 |
| 6 | **성과 급변 이상감지** | `anomaly_feed`(급증2배/급감0.5배+절대액 floor)+`trigger_watch` 매시 가동 vs MOP 이상감지는 설정오류(품절/URL/UTM) 계열만 |
| 7 | **예측 성적표 공개** | `forecast_scorer` MAPE 채점→자동강등을 콘솔에 노출 vs MOP 모델 품질 비공개 |
| 8 | **손익(정산) 통합** | 네이버 정산·BEP·실주문 대조(`actual_revenue`)까지 한 시스템 vs MOP 커머스 리포트는 Pro 전용이며 광고 성과 중심 |
