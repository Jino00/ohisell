## 3부 — 요약

1. **측정된 축 5 / 전체 23축(중복 없이 헤아린 것)** — 캠페인유형(층화)·S1(제한적)·S5·S6·달력요인만 등급(band1~4)과 실제로 교차 산출됐다. 나머지는 「원료 있음·미교차」 12축, 「원료 없음」 5축, 「미상」 2축이다. ref63 §13-b 자체 판정("실질 1.5단계")과 정합한다.

2. **가장 큰 공백**: ①**등급을 가장 직접 흔드는 두 축(순위·연령성별)이 정작 등급과 안 엮여 있다** — 순위는 「이진 band1 비중」한 칸만 있고 정작 그 순위구간 자체의 정적 목표는 「미지지·홀드아웃 8/8 미재현」이라 등급 예측에 못 쓴다(ref64). 연령·성별(S3)은 1년 소급이 라이브로 실증까지 됐는데 **DB에 저장하는 테이블이 아예 없어서** 등급 교차를 계산할 도리가 없다. ②**band3(적자) 판정 자체가 계정 블렌디드 BEP 위에 서 있다** — 상품 BEP로 재판정하면 48그룹이 등급을 옮기고, 미확보 624그룹(전체의 73%)은 여전히 미판정이다. ③**신규그룹 램프업(X9)이 baseline 잔차법의 사각**이라 아직 등급 미배정 그룹이 43개(§13 목록) 있다.

3. **공백을 여는 데 필요한 것**: **순위**는 이미 API 콜 0으로 열려 있었다 — 남은 건 「정적 밴드 대신 무엇으로 등급을 예측할지」의 재설계(교차 분석 성격, Jino 결정 사안). **연령·성별·시간대·지역·매체**는 D-NAO-186(이미 승인)의 적재 개통이 선행 — 그다음이 교차 분석. **상품 BEP 커버리지 확대**는 원가 확보 작업([[cost-values-need-jino-approval]] 규율)이라 별도 트랙. **확장소재·ADVoost·GFA**는 관측 경로 자체가 없거나(전자는 API 생성 불가 다수) 원리적으로 닫혀 있어(후자는 파트너 자격) 교차 분석 이전에 접근 여부부터 Jino 결정이 필요하다(§10-②).
