## 0. ⭐ 최대 신규 발견 — 3단계 요금제 (Basic / Lite / Pro)

ref 24는 "Basic vs Pro" 2단계로만 기술했으나, 라이브 `설정 > 구독/결제` 화면(`22_settings_subscription.png`)에서 **Basic / Lite / Pro 3단계**가 명확히 확인됨. 관찰 계정은 Basic(무료), 2025.06.30부터 이용 중.

플랜 카드 3장, 가로 배열, 각 카드에 배지:
- **Basic** — 배지 "Free", 검정 배경(`rgb(0,0,0)`)+흰 글자, 라운드 4px. 설명: "누구나 간편하게, MOP의 주요기능을 무료로 경험하세요."
- **Lite** — 배지 "Event", 인디고 배경(`rgb(79,70,229)`)+흰 글자. 파란 테두리로 카드 강조(추천 포지션). 설명: "필수 기능 중심으로 실속 있는 업그레이드, 성장하는 마케터를 위한 알고리즘 서비스"
- **Pro** — 배지 "Best", 빨강 배경(`rgb(220,38,38)`)+흰 글자. 빨간 테두리로 카드 강조. 설명: "알고리즘 성능 고도화를 통한 극한의 퍼포먼스, 마케팅 전문가를 위한 가장 강력한 최적화 솔루션"

**Basic → Lite 델타표(실측, 쇼핑검색광고 기준)**:
| 항목 | Basic | Lite |
|---|---|---|
| 입찰최적화 최적화 아이템 수 | 0/1개 | 5개 |
| 최적화 등록 가능 그룹 | 0/30개 | 100개 |
| 목표 기반 소재 입찰(SPA) | 0/1개 | 20개 |
| 캠페인 생성 | 미제공 | 미제공(Lite도 안 됨 — **Pro 전용**) |
| 커머스 리포트 | 미제공 | 미제공(**Pro 전용**) |
| 제외 키워드 | 미제공 | 미제공(**Pro 전용**) |
| (검색광고도 동일 구조) 최적화 아이템 수 | 0/1개 | 5개 |
| 검색광고 최적화 등록 가능 그룹 | 0/30개 | 100개 |
| 순위 유지 목표 키워드 입찰(SA) | 0/5개 | 20개 |
| 일별 실적 리포트 | 전일 실적까지 | 전일 실적까지(동일) |
| 조회 가능 기간 | 최근 60일 | 최근 60일(동일) |

**중요 정정**: ref 24는 "쇼핑 제외키워드 Basic=없음/Pro=최대70개"라 했는데, 실측상 **제외키워드·캠페인생성·커머스리포트는 Lite에서도 "미제공"** — 즉 Basic/Lite 공통 잠김, Pro에서만 열림. Lite는 볼륨 상한만 올려주는 플랜이고, 신기능 언락은 Pro부터.

또한 **"Lite" 배지가 붙은 개별 기능들**(품절 이상감지, URL 이상감지, UTM 이상감지)은 구독/결제 비교표엔 없지만 각 기능 페이지의 잠금 모달에 "Lite 플랜 알아보기" 버튼으로 별도 노출 — 이상감지 계열은 Lite에서 열리는 것으로 추정(모달 문구 근거, 비교표엔 미기재 — "문서에서 확인 안 됨" 수준).

## 5. ref 24 대비 종합 변화 (5줄 요약은 최종 보고에 포함, 여기 상세)

## 6. 미탐색 항목 (이유)

- **전문가 모드 실제 폼**: Basic 티어에서 라디오 disabled(pointer-events 차단)로 진입 불가 — 문서(ref24 §4 "고급설정 Pro 6종")로만 확인, 라이브 실측 불가.
- **대량 등록 모드**: 동일 사유로 미탐색.
- **커머스 리포트/예산민감도/경쟁심화도/예산최적화/소재효율성의 "기능 자세히 보기" 서브페이지**: Pro 업셀 모달의 세부 안내 페이지는 클릭 시 별도 페이지 이동 가능성 있으나, 계정 전환/구매 유도 플로우로 이어질 리스크가 있어 진입 안 함(허용 범위 "선택 금지" 원칙 적용).
- **애드써클 전환**(Google Ads/오하이 카카오로 실제 전환): 계정 전환은 관찰 스코프(네이버 SA)를 벗어나고 광고주 데이터 컨텍스트가 바뀌므로 드롭다운만 열람, 실제 클릭 안 함.
- **구독/결제 "비교 플랜 Pro" 컬럼**: 드롭다운에서 Pro 선택 시도했으나 선택자 충돌로 실패, 재시도 없이 종료(Basic vs Lite는 확보, Basic vs Pro는 ref24 문서 기반으로 대체 가능).
- **캠페인 생성 실제 폼**: Pro 잠금이라 진입 시 업셀 모달만 노출, 실제 폼 미확인.
- **개인 프로필(`/profile`) 필드 상세**: PII(전화번호/회사명 등) 노출 우려로 얕게만 기록, 스크린샷 미보관.
