## ★결론: 최적 조건 = 평균순위 2.5~4 (3등 밴드) + ROAS≥BEP
- **쇼핑: 3등 밴드가 매출·ROAS·CVR·이익 전부 1위(완전 지배)** — 절충 불필요. 순위가 이보다 오르면(1~2등) CPC 프리미엄이 전환을 압도해 ROAS 급락(1등 61%), 내려가면(6등+) ROAS는 지켜도 볼륨이 1/15로 굶음.
- **파워링크: 1등=매출최대 but ROAS 151%<BEP 170%(계정 기본 1.697)** → (매출-비용) 양수처럼 보여도 원가 차감하면 실질 미달. **D-NAO-1 제약 하 최적 = 역시 3등 밴드**(186%).
- ★"매출-비용" 열은 원가 미차감 — 진짜 이익 판정은 ROAS vs BEP-ROAS로 할 것.
- **성장 기회 정량화**: 쇼핑 6등+ 밴드에 그룹-일 표본 771개(ROAS 218%로 건강) — 이들을 3등 밴드로 끌어올리면 밴드 경제학상 매출 ~15배 밀도. 이게 우리 성장 보드의 최우선 타깃 풀.

- **이익 금액 기준으로도 3등 밴드가 최대**(+3,269원/그룹-일). 2등 밴드는 노출이 2.4배(628 vs 266)인데도 ROAS 160%가 진짜 BEP 147.6%에 너무 근접 → 단위마진이 얇아져(+1,720/1k vs +12,297/1k) **볼륨 증가가 마진 압축을 못 이김**(1,081 < 3,269).
- 원칙 공식화: **볼륨 확장은 한계 ROAS ≥ BEP(1.48)인 동안만 이익 증가.** 평균 ROAS가 ~160%까지 떨어지는 확장은 이미 초과(이익 감소 구간). 이익 극대 스팟 = ROAS ~200%+ 유지되는 3등 밴드.
