## MOP 시작하기 > MOP 도입하기

URL: https://support.mop.co.kr/introduce

MOP 도입하기

MOP는 광고 성과를 극대화하는 AI 광고 최적화 솔루션으로, MOP Basic, MOP Pro, MOP API Center 세 가지 버전으로 구성되어 있습니다.
아래 절차에 따라 도입을 진행해주세요.

- MOP Basic: 누구나 실속 있게 무료로 시작할 수 있으며, 회원가입 후 바로 사용 가능합니다.
- MOP Lite (6월 중 업데이트 예정)
- MOP Pro: 더 막강한 성능을 원한다면, MOP Pro를 구독하세요. Pro 최적화 알고리즘으로 더 정밀하게, 강력하게 작동합니다.
- MOP API Center: 고객사의 데이터와 시스템이 MOP API Center로 연결됩니다. API Center로 MOP를 200% 더 똑똑하게 사용하세요.

### 1. MOP Basic 도입 안내
MOP Basic은 별도의 도입 절차 없이 회원가입만으로 즉시 이용할 수 있어요.
- 회원가입 후, 로그인하여 바로 MOP Basic을 시작해보세요.
- 비즈니스 유형(광고주/대행사)만 간단히 입력하면 가입이 완료됩니다.
- MOP 온보딩 지원 또는 MOP 서비스 이해를 위한 데모가 필요하신 경우, 도입 사전 설문을 작성해주세요.
- 별도의 데모 계정은 존재하지 않습니다.
(버튼: MOP 회원가입하기)

### 2. MOP Lite / Pro / API Center 도입 안내
MOP Lite/Pro 또는 API Center를 이용하시려면 먼저 간단한 도입 사전 설문을 작성해주세요.
- 연동하고자 하는 캠페인이나 시스템 정보를 간단히 입력해주시면, 전문 컨설턴트가 맞춤 온보딩을 도와드립니다.
- MOP Lite/Pro 및 MOP API Center 는 월 단위로 구독하는 서비스입니다. (가격 안내)
- MOP 이용 중 API Center 도입을 희망하시는 경우, 담당 컨설턴트에게 별도로 문의해주세요.
(버튼: MOP 도입 사전 설문하기)

### 3. 로그인 후 시작 단계
MOP 로그인 후에는 역할에 따라 아래 단계를 진행해주세요.

**관리자(Administrator)**
직접 데이터 연동 및 애드써클 생성을 진행 후, MOP 이용을 시작하세요! 동료를 애드써클의 운영자(Operator), 보기 사용자(Viewer)로 초대해주세요.
단계:
1. 데이터 연동하기
2. 애드써클 생성하기
3. 권한 부여하기
4. 데이터 확인하기 (캠페인 리포트 확인하기 / 대시보드 확인하기)
5. 최적화 설정하기 (검색광고 최적화 세팅하기 / 쇼핑검색광고 최적화 세팅하기 / 광고 예산 최적화 세팅하기)

**운영자(Operator), 보기 사용자(Viewer)**
애드써클 초대를 수락하고, MOP 이용을 시작하세요! 아직 초대받은 애드써클이 없다면, 관리자(Administrator)에게 애드써클 초대를 요청하세요.
단계:
1. 애드써클 초대 수락하기
2. 데이터 확인하기 (대시보드 확인하기 / 캠페인 리포트 확인하기)
3. 최적화 설정하기 (검색광고 최적화 세팅하기 / 쇼핑검색광고 최적화 세팅하기 / 통합 예산 최적화 세팅하기)

📢 데이터 연동 및 애드써클 생성에 도움이 필요한 경우, mop_support@lgcns.com으로 연락 부탁드립니다.

## MOP 시작하기 > 원플로우로 시작하기

URL: https://support.mop.co.kr/one-flow

One-Flow

원플로우 연동 프로세스(One-Flow)란?

📍메뉴 위치: MOP 로그인> 대시보드> 애드써클 만들기

애드써클 생성부터 데이터 연동, 유닛 설정, 그리고 플랜 설정까지 한 번에! 통합된 프로세스로 진행할 수 있는 기능입니다.

📢 데이터 연동 제한 사항 안내
- 원플로우 프로세스를 통한 데이터 연동은 현재 네이버 매체 연동만 지원합니다.
- 네이버 외 매체나 전환툴에 대한 데이터 연동 및 유닛 설정을 희망하는 경우, 애드써클 생성/데이터 연동/유닛 설정을 각각 개별적으로 진행 부탁드립니다.

### 1. 원플로우로 MOP 쉽고 빠르게 시작하기
1. '대시보드'> '애드써클 만들기'를 클릭해주세요.
   ※ MOP 신규 회원의 경우, 로그인 후 뜨는 화면에서 '데이터를 연동하고 싶어요'를 선택하여 바로 시작할 수 있습니다.
2. 애드써클명을 입력한 후 다음을 클릭해주세요.
3. '연동하기'를 클릭해주세요.
4. 네이버 데이터 연동을 위한 계정 정보(계정명, 계정 ID, 액세스 라이선스, 비밀키)와 유닛 전환값을 입력한 후 '연동하기'를 클릭해주세요.
   📢 연동된 캠페인에 대하여 선택한 전환값으로 MOP 유닛이 자동 등록됩니다. 유닛 검수 완료 후 MOP의 각종 기능을 바로 활용할 수 있습니다. (참고: 유닛 설정하기(Unit) 문서)
   - 전환값 수정을 희망하는 경우, 자동 등록된 유닛을 삭제한 후 다시 등록해주셔야 합니다.
5. 데이터 연동이 완료된 후 '다음'을 클릭해주세요.
   ✔️ 데이터 연동에 문제가 발생한 경우 mop_support@lgcns.com으로 문의 바랍니다.
6. 원하는 플랜을 선택한 후 '선택'을 클릭해주세요.
7. 결제 정보 등록을 진행해주세요.
8. 결제 정보가 정상적으로 등록된 경우 구독이 정상적으로 완료됩니다.
9. 애드써클 생성이 완료되어 대시보드에서 바로 확인 가능합니다.
   ✔️ 생성한 애드써클에 설정한 유닛에 대한 검수가 자동으로 진행됩니다.
   ✔️ 데이터 수집 및 머신러닝 모델 생성 및 예측이 정상적으로 완료되면(평균 2~3일 소요), MOP의 최적화를 포함한 모든 기능을 바로 이용할 수 있습니다.

(하단 네비게이션: ← Previous: MOP 도입하기 | Next →: 데이터 연동하기)

## MOP 시작하기 > 데이터 연동하기

URL: https://support.mop.co.kr/data-connect

데이터 연동하기

📍메뉴 위치: MOP 로그인> 우측 상단 설정> 계정 관리> 데이터 연동

MOP 기능 사용을 위해 가장 먼저 해야 할 일은 광고 매체, 전환툴에 대한 데이터 연동입니다.
연동하고자 하는 플랫폼의 API 키 값을 입력하거나 플랫폼 로그인 연동을 통해 간편하게 진행하실 수 있습니다. 데이터 연동이 되면, MOP 운영을 위한 애드써클 생성 및 유닛 설정을 진행합니다.

🚀 MOP Pro 업그레이드 및 MOP API Center 도입하고 다양한 전환툴을 연동하세요!
- MOP Pro로 업그레이드하고 에어브릿지, 앱스플라이어, 네이버 커머스 데이터를 연동하세요.
- MOP API Center를 도입하고 고객 내부적으로 관리하는 맞춤 전환 데이터를 연동하세요.
- API 센터 소개(링크): API-IN 서비스로 맞춤 전환 데이터, 맞춤 광고 실적 데이터 연동 (TOSS, 당근 등)
- 고객 사례(링크): 더 정교한 데이터로 강력한 최적화 달성
- API 센터 도입문의(링크): 전담 컨설턴트가 1:1로 도입 상담 진행

### 1. 데이터 연동 대상
MOP는 연동된 광고 매체에 대해 예산 최적화 (Budget Opt) 기능과 입찰 최적화 (Bid Opt) 기능을 제공하고 있습니다. 또한 전환 목표 기반의 운영을 위한 다양한 전환툴(성과 분석 툴) 연동도 지원하고 있습니다.
📢 MOP는 별도의 스크립트 삽입이나 구축 작업이 필요하지 않습니다.

[표: 매체별 지원 여부]
| 구분 | 통합 예산 최적화 (Budget Opt) | 입찰 최적화 (Bid Opt) |
|---|---|---|
| 네이버 파워링크 | 대상 | 대상 |
| 네이버 쇼핑검색광고 | 대상 | 대상 (쇼핑몰 상품형, 제품 카탈로그형) |
| 카카오 프리미엄 링크 | 대상 | 대상 |
| 구글애즈 | 대상 | 비대상 |
| 메타 | 대상 | 비대상 |
| 크리테오 | 대상 | 비대상 |

**통합 예산 최적화 (Budget Opt) 대상 매체**: MOP와 연동된 광고 매체에 대해, 각 캠페인 단위 예산을 통합 최적화 할 수 있습니다. 대상 광고 매체는 네이버, 카카오, 구글, 메타 (Facebook, Instagram), 크리테오 입니다.
🚫 예산 최적화 비대상 매체/상품: 네이버 NOSP, GFA는 지원하지 않습니다. / 카카오 메시지 광고, 쇼핑광고, 리워드 광고는 지원하지 않습니다. / GMP (SA360, DV360) 상품은 지원하지 않습니다.

**입찰 최적화 (Bid Opt) 대상 매체**: 네이버 및 카카오 검색광고 대상 입찰 최적화를 할 수 있습니다. 대상 매체는 네이버 파워링크, 네이버 쇼핑검색(쇼핑몰 상품형, 제품 카탈로그형), 카카오 프리미엄 링크 입니다.
🚫 입찰 최적화 비대상 매체/상품: 네이버 브랜드검색, 플레이스 광고, 파워컨텐츠, 신제품검색은 지원하지 않습니다. / 네이버 NOSP 브랜드검색,신제품검색,서칭뷰,지역소상공인 광고는 지원하지 않습니다. / 네이버 쇼핑검색 브랜드형은 지원하지 않습니다. / 카카오 브랜드검색은 지원하지 않습니다. / 구글 검색광고는 지원하지 않습니다.

**연동 가능한 전환툴**: 각 매체의 전환툴 뿐만 아니라 추가 전환툴 연동이 가능합니다.
- 매체: 네이버 프리미엄 로그, 카카오 픽셀, 구글, 메타, 크리테오
- 전환툴: GA4
⚠️ GA4 데이터 연동은 Lite, Pro 플랜에서만 지원됩니다. Basic 플랜은 데이터 연동만 가능하며, 애드써클 유닛 설정을 제공되지 않습니다.

### 2. 데이터 연동 전 사전 점검
MOP 입찰최적화 운영 전 적용하고자 하는 광고 및 캠페인에 대한 사전 점검을 해보세요. 아래 조건을 충족하지 않을 경우, 데이터 연동 이후에 MOP 입찰최적화 운영 알고리즘이 원활하게 작동하지 않을 수 있습니다.
📢 MOP 운영을 위한 사전 체크 리스트 (필독)
- 최근 14일 중 광고 실적 존재 일수가 80% 이상의 데이터가 있다. (직전 2주간 운영되었던 캠페인/애드그룹 기준으로 입찰 최적화가 가능. 신규 도입 시 최소 2주 이상 수동 운영 필요)
- 하루 소진 예산이 1만원 이상(VAT 별도) 이다. (1만원 미만 시 알고리즘 미작동. 월 예산 100만원 이상 집행 광고 추천)
- Always-on(24시간) 운영되는 광고이다. (시간/요일/지역 타겟팅 시 제약 발생 가능, 주말 타겟팅은 가능. 일 20시간 이상 운영 필요, 미만 시 미작동)
- (네이버의 경우) Master Report 수가 90개 이하이다.

### 3. 데이터 연동하기

4. 데이터 연동 메뉴에서 '신규연동+' 버튼을 클릭하고, 광고 매체 / 전환툴을 선택하여 연동을 진행합니다.

4. MOP에서 활용하게 될 전환값(이벤트명)을 설정. (GA4는 한글 이벤트명 수집 불가 — 영문/숫자/언더바(_)만 사용. 최초 1회만 설정, 기본값 외 최대 10개 추가 가능)

6. 규칙명과 UTM 규칙 적용 예시 URL 입력 후 등록. (예시 URL 등록 시 UTM 파라미터별 색상 구분 자동 매칭. 좌측 'UTM 설정 값' 블록을 우측 영역으로 드래그. UTM 설정 2가지 방법: (A안) 파라미터값에 키워드ID/소재ID 포함 / (B안) 키워드명·소재명 + 캠페인명·ID·애드그룹명·ID 중 1가지 추가 필요)
7. UTM-SOURCE 규칙 설정 (예: 'instagram_da' = [매체유형]+[_]+[플랫폼유형]). 매체유형 드래그 → 팝업에서 기본 NAVER/KAKAO/GOOGLE/META/CRITEO 외 커스텀 추가 가능(+추가, 최대 5개). 특수문자('_') 드래그(기본 '-','_' 외 직접입력 가능). 플랫폼유형 드래그(기본 SA/DA/VA 외 커스텀 추가 가능). 검증 영역에 ✅정상 표시 확인.
8. UTM-MEDIUM 규칙 설정 (관련없으면 'Any').
9. UTM-CAMPAIGN 규칙 설정 (캠페인명 또는 캠페인ID).
10. UTM-CONTENT 규칙 설정 (애드그룹명 또는 애드그룹ID).
11. UTM-TERM 규칙 설정 (키워드/소재명 또는 키워드ID/소재ID).
12. 모든 파라미터 ✅정상 확인 후 설정 버튼 클릭 → UTM 규칙 등록 완료.
13. 연동 토글 ON.

📍메뉴 위치: MOP 로그인> 우측 상단 설정> 계정 관리> 애드써클 설정

**애드써클(Ad Circle)이란?**
MOP 로그인 후 첫 화면에 보이는 원형의 표가 '애드써클' 입니다. 애드써클은 MOP 운영의 기본이 되는 개념으로 데이터 연동 이후 애드써클 생성 및 유닛 설정을 하셔야 MOP의 모든 기능을 이용하실 수 있습니다. 애드써클은 운영하는 여러 유닛들을 모아서 생성하기에 보통 1개의 애드써클을 1개의 광고주로 구분하고 있습니다.

💡 MOP 세팅하기 요약
1. 데이터 연동 (광고 매체&전환툴 데이터를 MOP로 불러오기)
2. 애드써클 생성 (광고주 또는 브랜드 이름 입력)
3. 유닛 설정 (MOP 운영을 위한 데이터 맵핑 작업. [캠페인+전환툴+전환값]을 설정)
4. 운영 권한 부여 (데이터 연동 관리자 계정을 통한 업체 내 운영 권한 자체 부여)
5. 설정 완료. 정상적으로 데이터 적재 확인까지 완료되면 MOP 운영 가능 (*적재 및 ML 생성에 3~5일 소요)

### 1. 애드써클 생성 전 사전 점검
하기 MOP 애드써클 및 유닛 운영 정책을 확인해 주세요.
- 애드써클은 광고주(사업자등록증)기준으로 1개만 생성 가능합니다. (예: A 광고주는 A 애드써클 1개만 생성 가능. A 광고주가 애드써클 "A","B" 2개 운영 = 불가)
- 동일한 광고주의 매체 계정을 여러 개 운영할 경우 각 매체 당 1개의 계정만 유닛 설정이 가능합니다.
  - 네이버 계정A → 애드써클A: 가능 / 네이버 계정A → 애드써클A,B 중복: 불가 / 네이버 계정A+메타 계정A → 애드써클A: 가능 / 네이버 계정A,B(2개) → 애드써클A: 불가

📢 MOP Pro 플랜으로 업그레이드하고 더 많은 계정에 대한 유닛을 설정하세요.
[표: 유닛 설정 가능한 매체 계정 수]
| 구분 | MOP Basic | MOP Lite | MOP Pro |
|---|---|---|---|
| 유닛 설정 가능한 매체 계정 수 | 매체 별 1개 | 매체 별 1개 | 무제한 |

### 2. 애드써클 생성하기
'데이터 연동' 작업이 완료된 이후 생성이 가능합니다. [우측 상단 설정 > 애드써클 설정] 메뉴에서 '신규생성'을 클릭해주세요.
1. 로그인 후 우측 상단의 [설정]을 클릭합니다.
   📢 애드써클 생성부터 데이터 연동, 유닛 설정, 요금제 선택까지 한 번에 진행하고 싶은 경우 대시보드에서 [애드써클 만들기]를 클릭해 원플로우 연동 프로세스를 진행해주세요.
2. '계정 관리 > 애드써클 설정' 메뉴에서 '신규생성+' 버튼을 클릭해 주세요.
3. 애드써클명을 입력 후 SAVE 버튼을 클릭합니다. 필요에 따라 통화 설정도 가능합니다. (원화, 달러 중 선택 가능)
4. 애드써클 생성이 완료되면 리스트에 입력한 애드써클이 노출됩니다. 생성된 애드써클은 대시보드에서도 노출됩니다.
5. 애드써클 생성이 완료되면 상태 창에 '유닛설정 필요'가 노출됩니다. '유닛 설정하기' 버튼을 클릭하여 운영을 위한 유닛을 설정해주세요. (→ 유닛 설정하기 문서 참조)
6. '유닛 설정하기'를 클릭하면 '신규 유닛 설정'을 하게 됩니다. '유닛 설정'이란 '데이터 연동' 단계에서 연결해둔 매체, 전환툴, 전환값 데이터를 활용하여 실제 MOP 광고를 운영하기 위한 데이터 맵핑 작업을 의미합니다.
   - ① 매체/계정: MOP운영을 위한 매체/계정을 선택. 데이터 연동을 완료한 매체/계정 리스트가 노출됩니다.
   - ② 캠페인 선택: 최적화 설정에 필요한 광고 캠페인을 선택. 연동된 매체/계정의 전체 캠페인이 노출됩니다.
   - ③ 전환툴/전환값 선택: 유닛의 기준이 될 전환툴 및 전환 값을 선택. '전환툴'은 광고 매체의 전환툴 또는 GA4·에어브릿지·앱스플라이어 같은 별도 전환툴 설정 가능. '전환값'은 선택한 전환툴에서 설정할 수 있는 전환값 중 1개 선택.
   💡 실제 최적화의 KPI로 설정할 전환값을 선택해 주세요. (유닛 당 1개만 선택 가능)
7. 유닛 설정 완료 후 '애드써클 설정' 메뉴로 돌아오면, 유닛란에 매체별로 생성된 유닛 개수가 표시됩니다. 아이콘 클릭 시 유닛 추가 생성 가능.
   유닛을 생성하면 좌측 상태 메뉴가 '검수중'으로 업데이트됩니다. 데이터 적재 및 머신러닝 모델을 생성 중이며, 검수완료까지 약 3~5일 소요.

📌 애드써클 상태 별 상세 내용
- 유닛 설정 필요: 애드써클에 유닛 설정이 필요한 상태.
- 검수중: 설정한 유닛에 대해 데이터 적재 및 머신러닝 모델을 생성하는 중. 약 3~5일 소요. '검수중' 상태가 5일 이상 지속되면 mop_support@lgcns.com으로 연락.
- 검수완료: 데이터 적재 및 머신러닝 모델 생성 완료, MOP의 모든 기능 이용 가능. 단 '비고' 영역에 입찰 최적화 불가로 노출되는 경우 '입찰최적화' 메뉴 외 다른 기능만 사용 가능하며, 매주 ML 학습이 진행되므로 조건 충족 시 최적화 가능 여부도 자동 업데이트됨.
- 검수실패: 데이터 적재 및 머신러닝 모델 생성에 실패. MOP 운영 컨설턴트나 mop_support@lgcns.com 으로 연락.

8. '검수완료' 상태가 되었다면, 최적화를 포함한 MOP의 모든 기능을 사용할 수 있습니다. 최초로 데이터 연동 및 애드써클을 생성한 계정에 자동으로 '관리자' 역할이 부여되며, 관리자 계정은 다른 유저에게 운영자 또는 보기사용자 권한을 부여할 수 있습니다. (→ 운영 권한 설정하기 문서 참조)

📌 MOP에서 여러 애드써클을 운영하고 있는 대행사의 경우
각 애드써클 별로 다양한 권한을 가질 수 있습니다. 하나의 애드써클에 대해서는 관리자 권한을 가지고 있으나 다른 애드써클에 대해서는 운영자 권한을, 또 다른 애드써클에 대해서는 보기 사용자 권한을 가지고 있을 수 있습니다.
💡 [예시] MOP 유저 계정 mop_support@lgcns.com: 애드써클 "가"=관리자, "나"=운영자, "다"=운영자, "라"=보기 사용자.
어떠한 권한이든 권한을 보유한 애드써클에 대해서는 MOP 로그인 시 대시보드를 통해 해당 애드써클을 확인할 수 있고, 권한 별 사용 가능 수준에 따라 이용할 수 있습니다.
📢 권한에 관한 좀 더 자세한 내용은 '운영 권한 설정하기'에서 확인 바랍니다.

## MOP 시작하기 > 유닛 설정하기

URL: https://support.mop.co.kr/unit

유닛 설정하기 (Unit)

📍메뉴 위치: MOP 로그인> Menu> 설정> 유닛

### 1. 유닛(Unit)이란?
MOP에서는 데이터 연동 후 실제 운영을 위해 적용하고자 하는 광고 건에 대하여 각 광고 매체의 캠페인 단위로 전환툴 및 전환값을 맵핑하여 구성 후 동작됩니다. 각 광고 캠페인 단위로 연결된 전환 툴과 전환값을 기준으로 최적화하기 위함입니다. MOP에서는 이러한 각 캠페인과 성과 분석 툴 및 전환값이 맵핑된 단위를 유닛(Unit) 이라고 부르고 있습니다.

**MOP에서 유닛의 역할**: 유닛 설정이 되어야 MOP가 작동합니다. 유닛은 MOP에서 운영되는 기본 단위로 광고 매체 및 전환툴의 데이터 연동(불러오기)만으로는 MOP의 최적화 운영이 진행되지 않습니다. 운영하고자 하는 광고 캠페인과 전환툴, 전환값 데이터를 하나의 유닛으로 묶어 설정해주셔야 데이터 적재 및 ML(머신러닝) 모델이 생성됩니다.
- 설정한 유닛 기준 MOP에 데이터를 적재하고 ML 모델이 생성됩니다.
- 설정한 유닛 기준 최적화(Optimization)가 진행됩니다.
- 설정한 유닛 기준 리포트가 생성됩니다.
📍 MOP에서 유닛(Unit)이란, 최적화를 적용하기 위해 묶어 부르는 운영 단위 (캠페인 & 전환툴 & 전환값)로 유닛 설정이 되어야 MOP의 최적화 운영이 작동합니다.

### 2. 유닛(Unit) 설정하기
애드써클 생성 후, MENU>'설정'>'유닛'에서 운영하고자 하는 캠페인 단위로 유닛을 설정해주시면 됩니다.
🚀 MOP Lite/Pro 플랜으로 업그레이드하고 더 많은 계정에 대한 유닛을 설정하세요.
[표: 유닛 설정 가능한 매체 계정 수] MOP Basic=매체 별 1개 / MOP Lite=매체 별 1개 / MOP Pro=무제한

**유닛 설정이 처음인 경우**
우측 상단의 '설정'>'계정 관리'>'애드써클 설정'에서 생성된 애드써클의 목록을 확인할 수 있습니다. 유닛 설정을 진행하지 않은 경우, 좌측 '상태'란에 '유닛설정 필요'라는 문구가 노출됩니다. '유닛 설정하기' 버튼을 클릭하면 '신규 유닛 설정' 화면으로 바로 이동.
※ 특정 애드써클을 선택하여 MENU에 진입한 경우, '설정> 유닛'에서 동일하게 진행 가능. 좌측 상단 '유닛추가' 버튼 클릭.

**유닛 설정을 추가할 경우**
'설정'>'계정 관리'>'애드써클 설정'에서 애드써클별 유닛 설정 현황 확인 가능. 유닛을 신규로 생성하고 싶은 애드써클의 유닛 정보 뱃지를 클릭 → 선택한 애드써클의 MENU>'설정'>'유닛'으로 이동 → 좌측 상단 '유닛추가 +' 버튼 클릭 → '신규 유닛 생성' 화면 이동.
🔔 특정 애드써클을 선택하여 MENU에 진입한 경우, '설정> 유닛'으로 바로 접근 가능.
유닛 삭제가 필요한 경우 우측 [-] 버튼으로 삭제. 데이터 연동 및 입찰에서 활용 중일 경우 해당 기능을 모두 Off처리 후 진행.

**신규 유닛 설정**
1. 매체/계정 선택: 유닛을 설정할 광고 매체 선택. 데이터 연동을 진행한 매체와 계정ID가 노출. 네이버는 광고 상품 유형(SA, SPA) 구분하여 선택.
2. 캠페인 선택: 불러온 매체 정보에서 MOP 운영에 활용할 캠페인 선택. 클릭 시 푸른색 표시.
3. 전환값 선택: 유닛의 기준이 될 전환툴과 전환값 선택. '전환툴'은 광고 매체의 전환툴 또는 GA4·에어브릿지·앱스플라이어 같은 별도 전환툴 설정 가능. '전환값'은 1개 선택.
현 단계에서 설정한 유닛 기준으로 MOP의 최적화 운영이 가능해집니다.
🚨 유닛의 전환툴 및 전환값 수정 시, 데이터 적재 및 머신러닝 모델 생성이 재시작됩니다. 최소 3영업일 이상 소요.
4. '유닛추가' 버튼 클릭 후 설정 내용 확인 → '추가' 버튼 클릭.
5. 정상 추가 시 유닛 리스트에서 확인 가능. '유닛추가' 버튼으로 다른 매체/캠페인에 대한 추가 유닛 생성 가능.

📌 유닛 상태 별 상세 내용
- 검수중: 유닛 설정 후 데이터 적재 및 머신러닝 모델을 생성하는 중 (3~5일 소요)
- 검수완료: 데이터 적재 및 머신러닝 모델 생성 완료. MOP의 주요 기능 사용 가능. '비고'에 입찰 최적화 불가 표시 시 해당 기능 외 다른 기능만 사용 가능.
- 검수실패: 데이터 적재 및 머신러닝 모델 생성 실패. mop_support@lgcns.com 연락.
- 업로드 필요: 전환툴이 앱스플라이어인 경우, 유닛 설정 후 직전 60일치 데이터를 MOP에 직접 업로드해야 함. '업로드 필요' 문구 클릭하여 가이드에 따라 리포트 업로드.
- 삭제된 캠페인: 유닛 설정 후 매체에서 캠페인이 삭제된 경우. 리포트만 확인 가능.
- 수집 요청 필요: 전환툴이 에어브릿지인 경우, 수집 수 제한으로 담당자 간 논의 후 데이터 적재 시작. MOP 운영 컨설턴트 또는 mop_support@lgcns.com 연락.

우측 상단 '설정'>'계정 관리'>'애드써클 설정' 메뉴로 돌아와, 유닛 뱃지에 매체별 생성된 유닛 개수 표시 내역 확인 가능.
※ 유닛을 생성하면 좌측 상태 메뉴가 '검수중'으로 변경. 검수완료까지 영업일 기준 3~5일 소요.

[펼친 토글] 애드써클 상태별 상세 내용: (애드써클 생성하기 문서의 "애드써클 상태 별 상세 내용"과 동일한 4단계 — 유닛 설정 필요/검수중/검수완료/검수실패)
- 유닛 설정 필요: 애드써클에 유닛 설정이 필요한 상태. 유닛 설정을 진행해 주세요.
- 검수중: 데이터 적재 및 머신러닝 모델 생성 중. 약 3~5일 소요, 5일 이상 지속되면 mop_support@lgcns.com 연락.
- 검수완료: 데이터 적재 및 머신러닝 모델 생성 완료, MOP 모든 기능 이용 가능. '비고'에 입찰 최적화 불가 시 해당 기능 외 사용 가능, 매주 ML 학습으로 조건 충족 시 자동 업데이트.
- 검수실패: 데이터 적재 및 머신러닝 모델 생성 실패. MOP 운영 컨설턴트나 mop_support@lgcns.com 연락.

'검수완료'가 되었다면, 최적화를 포함한 MOP의 모든 기능이 이용 가능합니다.
🚨 유닛(Unit) 수정 시, 데이터 적재 및 ML 모델 생성이 재시작되므로 초기 유닛 설정은 신중하게 진행해주세요.

**TIP. 캠페인 목표에 따른 개별 유닛 설정하기**
유닛은 캠페인 단위로 설정할 수 있으므로, 각각의 캠페인이 가진 목표가 상이하다면 각각 다른 전환 값을 설정하여 운영할 수 있습니다. (네이버 파워링크 기준 예시)

[표: 예시 — 캠페인별 유닛 매핑]
| 캠페인 명 | 성과 분석 툴 | 전환 값 | 유닛(Unit) |
|---|---|---|---|
| 01. 브랜드 키워드 | 네이버 프리미엄 로그 | 간접전환 | 유닛 01 |
| 02. 가입 유도 키워드 | 네이버 프리미엄 로그 | 직접전환 | 유닛 02 |
| 03. 구매 유도 키워드 | GA 360 | 전자상거래(전환) | 유닛 03 |
| 04. 프로모션 키워드 | 네이버 프리미엄 로그 | 직접전환 + 간접전환 | 유닛 04 |

아래의 경우 총 4개의 유닛(Unit)이 생성되며, 유닛의 수는 MOP에 연동하는 총 캠페인 수와 동일합니다.

## MOP 시작하기 > 운영 권한 설정하기

URL: https://support.mop.co.kr/account

계정별 운영 권한 설정하기 (Account)

📍메뉴 위치: MOP 로그인> MENU> 설정> 권한 설정

### 1. MOP 계정의 개념
MOP는 발급된 계정별로 관리 및 운영 등 MOP 플랫폼에 대한 운영 권한을 가집니다. 단, 관리자 계정을 통해 부여되는 권한에 의해 각 유저 별로 연결된 애드써클에 대해 각기 다른 권한을 가질 수 있습니다. 별도 데모 계정은 존재하지 않습니다.
📢 MOP 유저는 최소 1개 이상의 애드써클과 연결되어야 하며, 연결된 애드써클에 대해 각기 다른 권한을 보유할 수 있습니다.

### 2. MOP 계정 별 권한 안내
MOP 계정 권한은 3가지로 구분됩니다: 관리자(Administrator), 운영자(Operator), 보기 사용자(Viewer). 기본적으로 애드써클 당 관리자 권한은 유저 1명만 가능하며, 운영자와 보기 사용자는 합하여 최대 2명까지 부여 가능합니다.
🚀 Pro로 업그레이드하고 더 많은 계정으로 관리하세요!
[표: 플랜별 계정 수]
| 구분 | MOP Basic | MOP Lite | MOP Pro |
|---|---|---|---|
| 관리자 | 1명 | 1명 | 1명 |
| 운영자 + 보기 사용자 | 2명 | 2명 | 9명 |
| 총 계정 수 | 3명 | 3명 | 10명 |

**권한 별 정의**
- 관리자: 하나의 애드써클에 대한 슈퍼 관리자로, 써클 당 유저 1명만 가능 (최초 데이터 연동, 유닛 생성자에게 자동 부여)
- 운영자: 관리자로부터 운영 권한을 부여 받아 셋팅 기능 외 전체 기능을 이용할 수 있는 유저
- 보기 사용자: 관리자로부터 보기 권한을 부여 받아 전체 기능을 오직 조회만 할 수 있는 유저

**권한 별 접근 권한**
[표]
| 구분 | 관리자 | 운영자 | 보기 사용자 |
|---|---|---|---|
| 데이터 연동 정보 관리 | 사용 가능 | 사용 불가 | 사용 불가 |
| 연동 정보 관리 | 사용 가능 | 사용 불가 | 사용 불가 |
| 유저 권한 관리 | 사용 가능 | 사용 불가 | 사용 불가 |
| MOP 운영 | 사용 가능 | 사용 가능 | 사용 불가 |
| MOP 조회 | 사용 가능 | 사용 가능 | 사용 가능 |
💡 "MOP 운영"은 MOP 로그인 후 셋팅(Setting)을 포함한 전체 기능을 의미합니다.

### 3. MOP 계정 운영 권한 부여하기
데이터 연동, 애드써클 및 유닛을 모두 생성하였다면, 실제 운영에 앞서 각 운영 담당자 별 권한 부여가 필요합니다. 관리자 외 계정에 대해서 권한 부여 전까지는 MOP의 애드써클 접근, 운영 기능을 이용할 수 없습니다.
1. MENU>'설정 > 권한 설정' 메뉴에서 상단의 '멤버 초대하기' 버튼을 클릭합니다. (애드써클을 생성하고 데이터 연동을 진행한 '관리자' 계정에서만 확인 가능)
2. '운영자' 또는 '보기사용자' 중 원하는 권한을 체크한 뒤 발급된 MOP 계정 ID(이메일)를 입력합니다. '초대하기' 클릭 시 해당 이메일로 수락 요청 메일 발송. 메일을 통한 수락이 되어야 최종 등록 완료. 1주일 간 미수락 시 만료.
3. 권한 등록이 완료되면 권한 설정 목록에 추가됩니다.
4. 권한 수정(추가/변경/삭제)도 가능합니다.

**TIP. 여러 애드써클을 운영하는 유저라면?**
각 애드써클 별로 다양한 권한을 가질 수 있습니다. 하나의 애드써클에 대해서는 관리자 권한을 가지고 있으나 다른 애드써클에 대해서는 운영자 권한을, 또 다른 애드써클에 대해서는 보기 사용자 권한을 가지고 있을 수 있습니다.
💡 [예시] MOP 유저 계정 mop_support@lgcns.com: 애드써클 "가"=관리자, "나"=운영자, "다"=운영자, "라"=보기 사용자.
어떠한 권한이든 권한을 보유한 애드써클에 대해서는 MOP 로그인 시 대시보드를 통해 해당 애드써클을 확인할 수 있고, 권한 별 사용 가능 수준에 따라 이용할 수 있습니다.

[펼친 토글] 📢 다수의 애드써클에 대한 운영 권한 현황을 관리하고 싶다면, 아래 절차를 따라 진행해주세요.:
1. 우측 상단의 '설정'>'계정 관리'>'애드써클 설정'으로 이동합니다. 애드써클별 운영 권한 부여 현황을 확인할 수 있습니다.
2. 운영 권한 설정의 상세 내역 조회 및 수정을 희망하는 애드써클의 권한 뱃지를 클릭합니다.
3. 선택한 애드써클의 '권한 설정' 메뉴로 이동하여 멤버 초대/권한 변경/권한 삭제 가능합니다. ('관리자' 계정인 경우에 한함)

### 4. MOP 초대 수락하기
📍메뉴 위치: MOP 로그인> 우측 상단 설정> 계정 관리> 애드써클 설정
1. 우측 상단의 '설정'>'계정 관리'>'애드써클 설정'에 접속하면 권한이 있는 애드써클 전체 목록과 함께 초대 받은 내역을 확인할 수 있습니다.
2. [초대 수락하기]를 눌러 권한을 부여 받은 애드써클 리스트를 확인한 후, [수락하기]를 클릭하면 해당 애드써클이 목록에 추가되며, 접속 가능합니다.
3. 초대 날짜로부터 1주일이 지나 기간이 만료되기 전에 초대를 수락해야 합니다. 기간에 만료되면 관리자가 다시 초대해야 합니다.

### 구독/결제 방법
**구독 방식**: 월 구독 vs 연 구독 선택
- 📅 연 구독: 플랜 비용의 12개월 치를 한번에 결제. 월 구독 대비 17% 할인. 연단위 갱신.
- 📅 월 구독: 매월 구독일마다 플랜 기본 비용이 결제.

**플랜 구독하기** (📍메뉴 위치: MOP 로그인> MENU> 설정 > 구독/결제)

[펼친 토글] 구독 방법:
1. MENU> 설정>구독/결제로 이동합니다.
📢 다수의 애드써클에 대한 구독을 관리하고 싶다면: 로그인 후 우측 상단 '설정'>'계정 관리'>'애드써클 설정'으로 이동 → 애드써클별 구독 현황 확인 가능.
2. 구독을 시작할 애드써클의 구독하기 버튼을 클릭합니다.
3. 플랜 구독하기 > 원하는 플랜을 선택 > 평가판 시작을 클릭합니다.
4. 결제방식 선택 후 평가판을 시작합니다. 결제 방식 등록 후 평가판 시작 버튼 클릭.
5. 결제가 정상적으로 완료되면 관리자로 등록된 이메일로 인보이스와 영수증이 발송됩니다.
6. 결제 실패 시, 관리자/운영자 이메일로 [결제 정보 업데이트] 메일이 발송됩니다.
💡 참고사항: 결제일을 기준으로 평가판이 시작되며, 결제는 평가판 종료 시점부터 매월/매년 등록하신 결제수단으로 자동 진행. 첫번째 결제일 전까지는 언제든지 취소 가능. 결제 실패/카드 만료 시 결제 요청 이메일 재발송.

**내 플랜 확인하기** (📍메뉴 위치: MOP 로그인> Menu > 설정 > 구독/결제)
유료 플랜을 구독하셨다면, [설정] - [구독/결제] 메뉴에서 구독 갱신 여부, 결제일 등 확인 가능.
📢 무료 체험 기간 종료 3일 전 알림 이메일이 발송됩니다.

[펼친 토글] 내 플랜 확인 방법:
1. MENU> 설정 > 구독/결제를 클릭합니다.
2. 평가판 종료일, 다음결제일, 구독 종료 예정일을 확인할 수 있습니다.
3. 결제 수단, 결제 정보, 송장내역을 확인할 수 있습니다.

## 쇼핑검색 광고 최적화 > 캠페인 생성

캠페인 생성 (Campaign Creation) 이란?

📍메뉴 위치: MOP 로그인> Menu > 쇼핑검색광고 > 캠페인 생성

네이버 커머스에서 연동된 상품을 선택해 MOP 내에서 바로 네이버 쇼핑검색광고(쇼핑몰 상품형) 캠페인을 생성할 수 있는 기능입니다.
✔ MOP에서 광고할 상품을 고른 후 캠페인 정보를 입력하면 네이버 광고 시스템에 광고 캠페인, 애드그룹, 소재가 자동으로 생성됩니다.
✔ 생성된 캠페인은 별도의 절차 없이 MOP 유닛으로 자동 등록되어 검수 완료 후 MOP의 각종 기능을 바로 활용할 수 있습니다.

🚀 MOP 플랜을 업그레이드하고 캠페인 생성부터 광고 시작까지 한 번에 해결하세요!
[표: 플랜별 캠페인 생성 기능]
| 구분 | MOP Basic | MOP Lite | MOP Pro |
|---|---|---|---|
| 캠페인 생성 기능 | 미제공 | 미제공 | 제공 |

### 1. 쇼핑검색광고(쇼핑몰 상품형) 캠페인 생성하기
✔ 네이버 광고와 네이버 커머스 계정이 모두 연동 완료된 후 캠페인 생성 기능을 사용할 수 있습니다. (→ 네이버 커머스 데이터 연동하기 문서 참조)
✔ 상품별 매출, 재고 현황 등의 커머스 정보가 함께 제공되어 전략적으로 상품을 선택해 광고를 시작할 수 있습니다.
1. 신규생성+ 버튼을 클릭하고, 계정을 선택합니다.
2. 쇼핑몰(비즈니스 채널)을 선택합니다.
3. 캠페인 생성을 희망하는 상품을 선택합니다. 📢 각 상품의 매출, 재고 현황 등 주요 커머스 정보를 참고하여, 광고 캠페인을 생성할 상품을 선택할 수 있습니다.

[펼친 토글] 조회 가능한 커머스 정보 (※ 업데이트 주기: 매일): 상품 이미지 / 상품 ID / 카테고리 / 상품명 / 가격 / 재고 / 광고 매출(최근 4주 기준 광고 매출 합계) / 총 매출(최근 4주 기준 총 매출 합계) / 상품 상태 / 광고 검수 상태 / 광고 상태
📢 카테고리, 상품명, 가격, 상품 상태, 광고 상태별 필터링 기능을 통해 필요한 상품을 쉽고 빠르게 확인할 수 있습니다.

4. 생성할 캠페인의 이름을 입력합니다.
5. 캠페인의 하루 예산을 설정합니다. '제한없음' 선택 또는 '직접 입력'. ⚠️ 하루 예산은 50원 이상 ~ 1,000,000,000원 이하, 10원 단위 입력 가능(부가세 별도).
6. 디바이스(PC/Mobile/전체)를 선택합니다. 전체 선택 시 PC 애드그룹, Mobile 애드그룹이 각각 하나씩 생성.
7. 캠페인 생성하기를 클릭 → 선택 상품/캠페인 정보 최종 확인 → [확인] 클릭 시 네이버 광고 시스템에 광고 캠페인, 애드그룹, 소재가 자동으로 등록됩니다.

💡 MOP에서 생성된 쇼핑검색광고 캠페인의 운영 구조 안내: 하나의 캠페인 아래 각 상품, 각 디바이스별로 애드그룹과 소재가 하나씩 생성됩니다. (예: 5개 상품 × 전체 디바이스(PC,Mobile) 선택 시 → 1개 캠페인 아래 총 10개의 {애드그룹-소재} 생성)

2. 상품을 추가하거나 캠페인명/캠페인 하루예산을 원하는 내용으로 수정합니다.

[펼친 토글] ✅ 수정 가능 항목: 상품 추가 / 캠페인명 / 캠페인 하루예산

### 0. 쇼핑검색광고 최적화 사전 점검

- 자동으로 소재에 등록된 검색어(키워드)를 제외하지 않습니다.
- 매체에서 설정된 캠페인에 대해 본 최적화 기능을 이용하여 소재 단위 입찰을 자동 관리할 수 있습니다.

MOP의 입찰 최적화 기능은 [이지 모드], [전문가 모드] 두 가지 버전으로 제공됩니다.
⚠️ 전문가 모드는 LITE/PRO 플랜 대상으로만 제공됩니다.

### 2. 최적화 아이템 생성하기
MOP를 적용할 대상 캠페인/애드그룹을 등록하고, 필요한 정보를 입력합니다. 등록 후 최적화 가능 여부에 대한 검수를 진행하며, 완료 시 설정된 입찰 기간 동안 광고 입찰가를 자동 최적화합니다.

📌 최적화 아이템 생성 방법 (쇼핑검색광고)
1. 신규생성+ 버튼을 클릭하고, 원하는 광고 상품 유형을 선택합니다. [쇼핑몰 상품형]과 [제품 카탈로그 형]에 대해서만 최적화 입찰을 지원합니다.
2. 대상으로 할 캠페인/애드그룹과 입찰 기간을 설정합니다. 입찰 시작일은 익일부터 선택 가능하며 종료일은 설정하거나 미설정할 수 있습니다. 종료일 미설정 시 지속 운영됩니다.
3. 최적화명, 하루 예산, 최적화 목표, 입찰 제외 소재(선택사항)를 설정합니다.
   ⚠️ 입찰 제외 소재는 1,000개 이상 등록은 권장드리지 않습니다. 1,000개 이상 등록이 필요하신 경우, mop_support@lgcns.com으로 문의.
4. Save 버튼을 클릭하고, 최적화 가능 여부 검수가 완료 되었는지를 확인합니다. 최적화 검수는 보통 1시간 이내로 완료됩니다.
5. 생성된 최적화 아이템의 상태가 "검수완료"가 된 후, 자동입찰 토글을 클릭하여 On 으로 변경해 주시면 설정된 입찰기간 동안 입찰 및 최적화가 진행됩니다.
⚠️ 자동입찰을 ON으로 변경해도 준비중에서 입찰중으로 변경되지 않는 경우 ⇒ 자동 입찰 최적화를 준비 중으로, 대시보드 > Flight > Bidding 내 Next bidding에서 입찰 시간 확인 가능.

[펼친 토글] 최적화 아이템 수정/삭제 방법:
최적화 입찰이 시작되기 전에는 전체 항목에 대해 수정이 가능하지만, 입찰이 시작된 후에는 수정이 불가능한 항목들이 있습니다.
- 자동 입찰 시작 후 수정 가능 항목: 입찰 종료일, 최적화명, 하루 예산, 입찰 제외 키워드, 입찰가 고급 설정, 알고리즘 고급 설정
- 자동 입찰 시작 후 수정 불가능 항목: 캠페인/애드그룹 리스트, 입찰 시작일, 최적화 목표
- 수정은 자동 입찰이 OFF상태인 경우에만 가능합니다. 최적화 아이템을 OFF 한 후 수정하고, 다시 자동 입찰을 ON 합니다.
- 수정 불가능 항목에 대해 조정이 필요한 경우, 기존 최적화 아이템을 삭제 또는 종료 후 다시 세팅이 필요합니다.

[펼친 토글] 운영 키워드(검색어) 제외도 가능한가요?:
PRO 플랜을 사용하실 경우 가능합니다. (※ BASIC, LITE 미제공)
세팅한 소재 단위로 노출을 원하지 않는 검색어를 제외 설정하여 광고 효율을 개선할 수 있습니다. MOP에서 제외 키워드로 설정 시, 네이버 광고 플랫폼에도 자동 반영됩니다.
⚙️ 제외 키워드 설정하기:
- 각 최적화 아이템 리스트의 우측에 위치한 '제외 키워드' 아이콘을 클릭하여 소재 단위로 노출을 원하지 않는 키워드를 제외할 수 있습니다.
- 각 키워드 효율성 분석 결과 및 Efficiency(효율성 지수) 컬럼을 확인하여 광고 노출을 제한하고 싶은 키워드를 제외 설정할 수 있습니다. 최근 2주간 실적을 바탕으로 매일 업데이트됩니다.
- 최적화 아이템이 검수중/검수에러 상태인 경우에는 제외키워드 설정이 불가능합니다.
- 소재 단위로 설정된 키워드 기준으로 추가/제외가 가능하며, 설정 시 자동으로 매체에 연동됩니다.
⚠️ MOP의 제외키워드는 소재 단위로 설정하기 때문에, 최대 70개까지 설정 가능합니다. 광고그룹 기준으로 제외키워드를 설정하고자 할 경우 매체에서 진행.

[펼친 토글] 키워드 효율성 분석이란?:
쇼핑검색 운영 키워드 제외를 위해 MOP에서 제공하는 분석 기능으로, 키워드별 효율을 DEA 모형(자료포락분석)을 활용하여 광고 전 지표에 대한 소재 별 키워드 간 상대적 효율 수치를 분석, 0부터 1까지의 값으로 제공합니다. 메뉴 내 Efficiency(효율성 지수) 컬럼에 해당 값이 제공됩니다.
즉, 0에 가까울수록 효율성이 낮은 키워드며, 광고 실적을 함께 고려해 제외키워드로 설정할 수 있습니다. 효율이 좋은 키워드보다 효율이 낮은 키워드를 발굴하는데 좋은 분석 방법이므로, 효율이 떨어지는 키워드를 찾아 제외 처리하시는 것을 권장합니다.
※최근 2주간 실적이 충분하지 않은 키워드는 효율성 분석이 수행되지 않을 수 있습니다.

⚠️ 세팅 사전 참고 사항
- 운영기간이 최근 14일 내 80% 이상이며 최근 3일 운영 실적이 있는 캠페인/애드그룹 대상 Bid opt가 가능합니다.
- Pro 플랜 사용자의 경우 캠페인/애드그룹이 운영 2주 미만이거나 실적이 부족한 경우, 네이버 추천 입찰가를 기반으로 자동 운영됩니다. 이후 실적이 충분히 누적되면 최적화 알고리즘으로 전환되어 운영됩니다.
- 목표입찰에 설정된 소재가 추천 입찰 대상이 아닌 경우, 입찰최적화 대상에서 자동으로 제외됩니다.
- MOP에 노출되는 캠페인/애드그룹은 매체에 셋팅된 정보이며, MOP에 연동한 유닛에 대해서만 노출됩니다.
💡 쇼핑검색광고 운영에 자주 쓰이는 '제외 키워드 추가'를 이용하실 때, MOP의 '키워드 효율성' 데이터를 참고하여 손쉽게 저효율 키워드를 발굴 및 제외하며 성과를 개선해 보세요.

### 3. 최적화 대상 선택하기 (캠페인/애드그룹)
한 개의 예산 하에서 관리할 캠페인 또는 애드그룹을 선택합니다.

[펼친 토글] 캠페인/애드그룹 선택하기:
- 쇼핑몰 상품형과 제품 카탈로그형을 구분하여 캠페인/애드그룹을 선택합니다.
- 매체에 설정되어 있는 캠페인/애드그룹 리스트만 확인 가능하며, MOP에서 캠페인/애드그룹을 셋팅하는 기능은 지원하지 않습니다.
- MOP 연동 이후에 신규 캠페인이 생성되었다면 리스트에서 확인되지 않을 수 있습니다. 이 경우 유닛 추가 등록.

[펼친 토글] 캠페인/애드그룹이 선택되지 않는다면? (회색 텍스트로 뜰 경우):
회색 텍스트로 보여지는 캠페인/애드그룹은 이미 다른 최적화 아이템에 설정된 항목으로, 신규 최적화 아이템의 시작일을 기존 최적화 아이템의 종료일 이후로 설정하면 해당 캠페인/애드그룹을 선택할 수 있습니다. 익일부터 신규 셋팅이 필요할 경우, 기존 최적화 아이템의 종료일을 오늘로 변경하고 내일부터 시작하는 최적화 아이템을 신규 생성합니다.

[펼친 토글] 캠페인/애드그룹이 빨간색 텍스트로 보인다면?:
아직 최적화가 완료되지 않았다면 텍스트가 빨간색으로 노출됩니다. (운영한 지 2주 미만이거나, 최근 3일 내 노출/클릭 실적이 충분하지 않은 경우) 이 경우, 최적화 아이템 설정 시 해당 캠페인/애드그룹 선택은 가능하지만, 조건이 충족된 후에 최적화 입찰이 진행됩니다. Pro 플랜 사용자의 경우 실적 조건과 상관없이, 네이버 추천 입찰가를 기반으로 자동 운영.

⚠️ 캠페인/애드그룹 선택 시 참고 사항
- 광고 효율에 따라 각 애드그룹들에 속해 있는 키워드 간 예산이 자동 배분되기 때문에 매체에 하루 예산 Cap을 설정하는 것은 권장하지 않습니다.
- 일 예산 Limit이 있는 경우에는 매체 상에서 캠페인에 Cap을 설정해 주는 것이 좋습니다. (애드그룹의 Cap은 설정하지 않는 것을 권장)
- 매체에서 캠페인/애드그룹을 추가 또는 수정했는데 MOP에 반영되지 않을 경우: MOP 광고 정보 갱신은 매일 오전에 진행되며 빠른 반영이 필요하면 mop_support@lgcns.com 문의.

### 4. 최적화 목표 설정 방법 (KPI)
최적화 아이템 당 "클릭 최적화", "전환 최적화", "ROAS 최적화", "다중목표 최적화" 중 1개 목표를 설정하여 운영합니다.

[펼친 토글] 최적화 아이템 목표 설정하기:
- 클릭 최적화: 예산 내 가장 많은 클릭 확보를 목표로 소재 입찰 계획을 도출하며, 잠재 클릭 확보를 위해 노출과 클릭을 동시에 최적화. 신제품 런칭, 프로모션 등 사이트로의 유입 확대가 필요한 경우 선택. 쇼핑몰 상품형과 제품 카탈로그형 모두 설정 가능.
- 전환 최적화: 예산 내 가장 많은 전환 확보를 목표로, 클릭과 전환을 동시에 최적화. 성수기, 경쟁 심화 시기 등 최대한 많은 전환을 확보하고자 하는 경우 선택. 쇼핑몰 상품형 광고만 설정 가능.
- ROAS 최적화: 예산 내 가장 많은 매출 확보를 목표로, 클릭과 매출을 동시에 최적화. 비수기 혹은 상시 운영 기간과 같이 일정 수준의 볼륨을 형성하면서 최대한의 ROAS 효율을 유지하고자 하는 경우 선택. 쇼핑몰 상품형 광고만 설정 가능.
- 다중 목표 최적화: 여러 광고 지표(노출, 클릭, 전환, 매출 중 선택)를 동시에 최적화하기 위한 목표. "사이트 유입+전환 확대" 등 여러 목표를 동시에 달성해야 하는 경우 선택. Average CPC, Average CPA를 설정하여 비용 효율 관리도 가능(너무 적은 금액 설정 시 광고비 소진 원활하지 않을 수 있음). 쇼핑몰 상품형과 제품 카탈로그형 모두 설정 가능하지만, 제품 카탈로그형은 '전환'과 '매출' 지표는 선택 불가능.

[펼친 토글] 최적화 아이템 목표를 변경하고 싶어요.:
입찰이 시작된 이후 최적화 목표 변경은 불가능합니다. 목표 변경이 필요할 경우, 최적화 아이템을 신규로 생성해주세요.

💡 최소 하루에 1건 이상의 전환이 발생해야 머신러닝이 원활하게 진행됩니다. 전환량이 적은 경우에도 최적화 목표 설정은 가능하지만, '클릭 최적화' 목표와 유사하게 운영됩니다.
💡 ROAS 개선을 원하는 경우, 다중목표 최적화에서 Click, Revenue를 설정하고 하루 예산을 축소하여 운영합니다. (예산 과다 알림이 뜨지 않도록 하루 예산 조정)

### 5. 최적화 예산 설정 방법 (하루 예산)
MOP의 최적화 알고리즘은 설정된 하루 예산 내에서 충분한 예산이 있다면 정량을 최대한 확보하는 방향으로 운영됩니다. 예산이 충분하지 않다면 비용 효율을 최대한 확보하는 방향으로 작동. 하루 예산은 주간 평균 소진 가능 비용을 입력하는 것 권장.

[펼친 토글] 하루 예산 설정하기:
- 하루 예산은 VAT(부가세)를 제외한 금액으로 입력해 주세요.
- 하루 동안 집행할 최대 비용이 아닌, 주간 평균 소진 비용을 입력해 주세요. 선택한 캠페인/애드그룹의 과거 일 평균 광고비를 참고하여 1주 간 평균 하루 예산을 입력하는 것을 추천.
- 요일 별 실적을 고려하여 하루 예산을 집행하므로, 세팅한 예산보다 더 소진되거나 덜 소진될 수 있습니다.
- 단, 매체에서 예산 Cap을 설정해 두었다면, 그 이상으로 소진하지는 않습니다.
- 머신러닝 효과 극대화를 위해 매체 예산 Cap 설정은 권장하지 않으나, 일 예산 Limit이 있는 경우에는 매체 내 캠페인에서 Cap을 설정하는 것이 좋습니다. (애드그룹의 Cap은 설정하지 않는 것을 권장)

💡 하루 예산 설정 TIP!
- 하루 예산 수정 시, 한 번에 주간 평균 소진 비용보다 20~25% 이상 높이지 않는 것을 추천합니다. (예산 소진이 불규칙해질 수 있음)
- 단기간 내 반복적인 예산 수정은 추천하지 않습니다. 예산 수정 후 적어도 1주일은 광고 실적 변화를 모니터링하며 변경하는 것을 추천.
- 예산을 높이면 공격적으로 입찰하며, 줄이면 보수적으로 입찰합니다. 유입/전환량 극대화 시기에는 예산 확대(예산 과다 수준), 비용 효율 확보 시기에는 예산 축소(예산 부족 수준) 전략 권장.

### 6. 대량 등록하기
대량 등록은 입찰최적화 아이템을 엑셀 파일로 여러 아이템을 한 번에 대량 등록할 수 있는 기능입니다.
📌 최적화 아이템 대량 등록 방법
1. 신규생성+ 버튼을 클릭하고, 대량 등록을 선택합니다.
2. 양식 다운로드를 클릭하여 양식 파일을 실행하고 최적화 명을 포함한 (필수) 항목을 모두 기입한 후 저장합니다.
3. 저장한 양식 파일을 업로드 하신 후 양식 파일 내 등록한 최적화 아이템이 모두 정상적으로 업로드가 완료되었는지 확인한 후 [최적화 등록하기]를 클릭하여 최적화 아이템 대량 등록을 완료합니다.

## 쇼핑검색 광고 최적화 > 목표입찰

URL: https://support.mop.co.kr/target-bidding

목표 입찰 (Target-bidding) 이란?

📍메뉴 위치: MOP 로그인> Menu > 쇼핑검색광고 > 목표입찰

쇼핑검색광고의 소재 단위로 입찰 목표를 설정해 별도로 관리하고 싶을 때 활용하는 기능입니다. 1) 소재 별 검색어를 지정하여 입찰 목표를 rank/tROAS/tCPA 중 하나로 선택해서 입찰하고, 2) 각 목표별 원하는 목표 수준을 설정할 수 있습니다.

🚀 MOP 플랜을 업그레이드하고 소재 단위로 특정 검색어 기반 순위를 타겟팅하세요!
[표: 목표 입찰 소재 개수 플랜별 제한]
| 구분 | MOP Basic | MOP Lite | MOP Pro |
|---|---|---|---|
| 목표 입찰 소재 개수 | 최대 1개 | 최대 20개 | 최대 50개 |

### ✅ 쇼핑검색광고 목표 입찰 설정하기
1. 신규생성+ 버튼을 클릭하고, 원하는 소재ID를 입력합니다.
2. 입찰 기준 키워드를 설정합니다. ⚠️ 소재ID 별 입찰 기준 키워드는 1개만 설정 가능하며, ALL 선택 시 전체 키워드 통합 실적을 기준으로 계산됩니다. 📢 소재ID 기준 지난 2주 키워드 별 실적을 참고 가능.
3. 입찰 목표(Avg.Rank, ROAS, CPA)를 설정합니다.
   💡 설정된 입찰 목표(Avg Rank, ROAS, CPA)와 최근 7일 평균 실적을 비교하여 입찰가 조정이 진행됩니다. (입찰 기준 키워드 설정 시, 해당 서치키워드 기준의 최근 7일 평균 실적 기준으로 작동)
   - Avg.Rank 설정 시: 입찰 목표 대비 순위가 낮을 경우 → 키워드 비딩가 증액 / 입찰 목표 대비 순위가 높을 경우 → 키워드 비딩가 감액
   - ROAS, CPA 설정 시: 입찰 목표 대비 실적 저조 → 키워드 비딩가 감액 / 입찰 목표 대비 실적 높음 → 키워드 비딩가 증액
4. 최대 입찰가, 입찰가 변동폭을 설정합니다. 최대 입찰가는 10원 단위 입력 가능. 입찰가 변동폭은 10원 이상~최대 입찰가 이하로 입력 가능.
   ⚠️ Max CPC 이상 입찰을 진행하지 않으므로 Max CPC에 도달한 경우 목표 순위를 유지하지 못할 수 있습니다.

🚨 입찰가 조정폭을 설정하지 않을 경우, 아래 조건을 충족하는 경우에만 입찰가 조정이 진행됩니다.
- 최근 14일 중 광고 실적 존재 일수가 80% 이상의 데이터 존재
- 일 20시간 이상 운영/요일 타겟팅 미설정 (주말 타겟팅 가능)
⇒ 해당 소재가 속한 캠페인이 상기 조건을 충족한 "입찰최적화 가능" 상태일 경우 입찰 알고리즘이 작동

5. 설정 완료 후 목표 입찰 목록에서 자동입찰 토글을 On 하면, 일단위로 입찰가를 관리합니다.
⚠️ 목표 입찰 설정이 완료된 시점을 기준으로 설정 다음날 오후 2시부터 최초 입찰이 시작됩니다.

💡 목표 입찰 운영 Tip.
- 입찰가 변동폭을 설정하지 않을 경우 알고리즘 예측 결과에 따라서 입찰가가 자동 증감됩니다.
- 입찰 목표 달성 여부에 따라 입찰가 변동폭을 조정하여 운영해주세요.
- 입찰 목표 설정 시 소수점 적용은 어렵습니다.
- 목표입찰로 설정된 소재는 추천 입찰 대상이 아닌 경우, 입찰최적화 대상에서 자동으로 제외됩니다.

✅ URL 이상 감지 종류
[표]
| 종류 | 코드 |
|---|---|
| URL / 서버 오류 | HTTP_ERROR |
| 접속 지연 오류 | REQUEST_TIMEOUT |
| HTML 오류 | TOO_MANY_REDIRECTS |
| UNKNOWN 오류 | UNKNOWN_ERROR |

💡 MOP에서의 URL 이상감지는 연동된 사이트에서 발생하는 오류 유형을 받아 노출하는 방식으로, 표준화된 코드(예: 404 Error 등)를 받아 노출하고 있습니다. ※ 접속 지연 오류의 경우, 20초 이상 지연 시 이상감지로 분류됩니다.

광고 입찰 최적화(Bid Opt) 연동된 검색광고, 쇼핑검색광고 최적화 아이템을 대상으로 광고 실적을 분석하여, 운영 목표 별 광고 예산 적절성에 대한 예측 데이터와 향후 예산 증감에 대한 인사이트를 제공하는 기능입니다.

### 1. 예산 민감도 화면 설명
- [조회 매체]: 검색광고, 쇼핑검색광고 최적화 아이템 단위로 확인 가능합니다.
- [조회 필터]: 자동입찰 설정 여부부터 최적화명까지 필터링하여 예산 민감도 데이터를 확인할 수 있습니다.
- [예산 민감도 그래프]: 설정된 최적화 아이템 별로 예산 적절성에 대한 그래프를 제공합니다. 좌측은 최적화 세팅 내역, 우측 그래프는 세팅 내역을 기반으로 한 예산 민감도 분석 그래프입니다.
- [최적화 ID]: '입찰 최적화'에서 생성한 최적화 아이템의 ID. 우측 [Go Opt] 버튼 클릭 시 입찰최적화 설정 페이지로 이동.
- [지표]: 그래프에 표시하고자 하는 광고 지표를 선택할 수 있습니다. 선택한 지표의 예측 데이터가 없을 경우 그래프가 노출되지 않습니다.

### 2. 예산 민감도 그래프 해석하기
각 최적화 아이템에 대한 예산 적절성을 확인할 수 있습니다. 가로 축 100(%)에 표시된 붉은색 점선은 현재의 예산 수준을 의미합니다.
- 현재 예산 수준을 기준으로 '클릭', '전환', '매출' 지표는 우상향 그래프 형태 — 예산을 늘렸을 때 각 지표도 정비례한다는 예측으로 해석.
- '노출' 지표는 기울기가 0에 가까운 형태 — 예산 임계치에 도달하여 성과 개선 가능성이 한계에 온 것을 의미.

💡 예산 민감도 운영 Tips.
- 예산 민감도 그래프 좌측 [더보기] 버튼을 누르면 하단에 최근 7일 간의 예산 민감도 분석 그래프를 함께 제공합니다.
- 기본 민감도 그래프와 비교해보며 예산 트렌드를 파악, 최적의 예산 운영을 찾아보세요.

[펼친 토글] [더보기] 그래프 예시: [이미지만 포함, 텍스트 콘텐츠 없음 — 최근 7일 민감도 그래프 예시 스크린샷으로 추정]

경쟁 심화도 (Competition) 란?

### 1. 경쟁 현황 탐지 화면 설명
- [조회 매체]: 광고 유형(검색광고, 쇼핑검색광고) 별로 확인 가능합니다.
- [조회 필터]: 자동입찰 설정 여부부터 캠페인/최적화명까지 필터링하여 광고 실적과 경쟁 심화도 데이터를 확인할 수 있습니다.
- [경쟁 현황 탐지 그래프]: 캠페인 또는 최적화 아이템 별 경쟁 현황에 대한 그래프. 좌측은 설정 내역, 우측은 설정 내역에 대한 분석 그래프.
- [더보기 (리포트)]: 클릭 시 조회한 기간의 일별 광고 실적과 경쟁 현황 분석 결과를 리포트 형태로 확인. 각 지표 클릭으로 정렬 가능, 우측 상단 다운로드 아이콘으로 CSV 다운로드 가능.

### 2. CPC 효율성 (CPC Efficiency)
MOP에서 제공하는 분석 기능으로, 키워드 또는 소재 별 효율을 DEA 모형(자료포락분석)을 활용하여 광고 전 지표에 대한 상대적 효율 수치를 분석하여, 0부터 1까지의 값으로 제공합니다.
- 0에 가까울수록 효율성이 낮은 키워드/소재이며, 쇼핑검색광고의 경우 효율성이 낮은 소재에 대해 '제외 키워드'를 설정하면 효율 개선에 도움이 될 수 있습니다.
- 효율이 좋은 키워드/소재보다 효율이 낮은 키워드/소재를 발굴하는 데 좋은 분석 방법이므로, 효율이 떨어지는 것을 찾아 관리할 것을 권장합니다.

**경쟁 현황 탐지 그래프 및 CPC 효율성 화면 설명**
- [경쟁 현황 탐지 그래프]: 선택한 최적화 아이템의 CPC efficiency(CPC 효율성)와 CTR 데이터를 기준으로, 효율 변화 폭이 컸던 시기에 대해 'High' 또는 'Low'로 구간을 표시. High/Low 뒤 숫자는 변화가 몇 번 발생했는지 의미. (예: Low1 = 광고 경쟁이 적었던 기간 내 첫 번째 구간. 조회 기간 내 여러 차례 표시될 수 있음)
- [경쟁 현황 탐지 알림]: 'High'는 CPC 효율성 지수와 CTR 효율이 감소한 시기(경쟁이 매우 치열했던 시기, 주황색 표시). 'Low'는 효율이 개선된 시기(경쟁이 완화된 시기, 초록색 표시).
- 표시된 경쟁 현황 탐지 영역을 클릭하면 (1) 경쟁 현황이 어느 정도 지속되었는지, (2) 해당 기간에 효율이 낮았던 TOP3 키워드/소재 정보(키워드/소재 ID 및 CPC 효율성 지수)를 제공. 저효율 키워드/소재 정보로 효율 개선 방향 제안.

**TIP. CPC 효율성 기능을 통해 라이브 중인 키워드의 OFF도 가능한가요?**
쇼핑검색광고만 가능합니다. 입찰 최적화 메뉴에서 제외 키워드 설정을 통해 제외. 검색광고의 경우, 순위 타겟팅을 통한 하향 조정은 가능하지만 운영 캠페인에서의 제외(OFF)가 필요하면 매체 플랫폼을 통해 직접 변경 필요.

💡 CPC 효율성 지수 잘 활용하기
CPC 효율성 지수는 실제 발생한 CPC, 이전 기간 대비 운영 순위 달성 비용, 이전 기간 대비 성과 변화 등을 지수화하여 수치가 높을수록 CPC 효율성이 좋은 것으로 판단. 반대로 0에 가까운 낮은 수치는 경쟁이 매우 치열한 상황을 의미. 경쟁 현황 탐지 그래프에서 High, Low에 관계없이 '저효율 키워드 TOP3' 정보를 제공하여 경쟁 현황에 무관하게 저효율 키워드를 이후 운영 제외를 통해 보다 나은 성과를 달성하도록(지수를 개선하도록) 돕는 인사이트.
즉, CPC 효율성을 바탕으로 효율 개선을 하려면 검색광고는 해당 키워드에 대한 순위 하향 및 일시 제외, 쇼핑검색광고는 제외 키워드 설정 등을 통해 시도 가능합니다.

### 1. Average CPC / CPA — LITE, PRO 전용
📍메뉴 위치: 입찰 최적화 > 최적화 설정 > 고급 설정 > 입찰가 고급 설정
입찰 최적화 진행 시 전체 실적에 대한 평균 CPC, CPA를 제한할 수 있는 기능입니다. ※ 당일 예측한 실적을 기준으로 운영하므로, 설정 값보다 작거나 클 수 있습니다.
📌 적용 방법: 고급 설정 > 입찰가 고급 설정 영역 내 [Average CPC] or [Average CPA]에 값 기재 → [SAVE] 클릭 → 검수 통과 완료되면 이후 최적화 진행 시 반영.
⚠️ Average CPC / CPA 제한 값이 초과되는 경우: 이 설정은 개별 키워드/소재 단위 값이 아니라 전체 실적에 대한 평균 CPC/CPA를 설정 값 이하로 달성하도록 운영하는 옵션이므로, 개별 키워드/소재 단위 값은 설정 값보다 작거나 클 수 있습니다.

### 2. 최대 CPC(MAX CPC) — LITE, PRO 전용
📍메뉴 위치: 입찰 최적화 > 최적화 설정 > 고급 설정 > 입찰가 고급 설정
입찰 최적화 수행 시 키워드/소재 개별 단위에 대한 최대 입찰가를 설정하여 알고리즘에 반영. 설정 시, 알고리즘은 각 키워드 별 입찰가를 설정된 최대 CPC 아래 범위 내에서 조정.
📌 적용 방법: [최대 CPC]에 원하는 입찰가 기재(10원 단위, 매체 별 최소/최대 입찰가 범위 내) → [SAVE] 클릭 → 검수 통과 후 반영. ※ 최대 CPC 적용 완료 이후 입찰이 진행되는 시점에 일괄 적용 및 반영됩니다.

### 3. 상위 노출량 증대(Top Rank Impression Boosting) — LITE, PRO 전용
📍메뉴 위치: 입찰 최적화 > 최적화 설정 > 고급 설정 > 알고리즘 고급 설정
선택한 최적화 목표에 더해, 최적화에 포함된 키워드들이 더 많이 상순위(1~3위)에 노출될 수 있도록 알고리즘이 작동. 사용 시 설정한 하루 예산을 초과하여 광고비가 집행될 수 있습니다.
📌 적용 방법: [상위 노출량 증대] 영역 ON/OFF 버튼 클릭 → [SAVE] 클릭 → 검수 통과 후 반영.

### 4. 순위 부스팅(Rank Boosting) — LITE, PRO 전용
📍메뉴 위치: 입찰 최적화 > 최적화 설정 > 고급 설정 > 알고리즘 고급 설정
최적화 알고리즘이 광고비를 점진적으로 확대할 수 있도록 설정. 광고 실적/성과를 현재 수준과 비슷하게 유지하면서, 일 평균 광고비를 지속적으로 늘려 더 많은 광고비를 집행하고 싶은 경우 적합.
📌 적용 방법: [순위 부스팅] 영역 ON/OFF 버튼 클릭 → [SAVE] 클릭 → 검수 통과 후 반영.
⚠️ 세팅 사전 참고 사항: 순위 부스팅 기능 적용 시, 최적화 설정 시 세팅된 일 예산보다 더 많은 예산의 소진이 이루어질 수 있습니다.

### 5. 예산 부스팅(Budget Boosting) — PRO 전용
📍메뉴 위치: 입찰 최적화 > 최적화 설정 > 고급 설정 > 알고리즘 고급 설정
최적화 알고리즘이 키워드 별 입찰 패턴을 유지하면서, 입찰가를 단기간 내 빠르게 상향 조정할 수 있도록 돕습니다. 신제품 출시나 프로모션 진행처럼 단기간 내 마케팅 비용을 공격적으로 확장하려는 상황에 최적화된 설정.
📌 적용 방법: [예산 부스팅] 영역 우측의 단계 설정 바를 통해 적용. 맨 좌측 '기본 입찰' 상태가 비활성화 상태이며, 버튼을 우측으로 이동할수록 공격적인 입찰로 설정.
[펼친 토글 시도] 적용 예시: [이미지만 포함, 텍스트 콘텐츠 없음 — 단계별 설정 바 스크린샷으로 추정]
→ [SAVE] 클릭 → 검수 통과 후 반영.
⚠️ 세팅 사전 참고 사항: 예산 부스팅 기능 적용 시, 세팅된 일 예산보다 더 많은 예산 소진 가능. 3일 이상 사용 시 과도한 소진 발생 가능.

💡 순위 부스팅(Rank Boosting) / 예산 부스팅(Budget Boosting) 기능은 다음과 같은 상황에서 효과적:
1. 단기간 예산 확장이 필요한 경우 (성수기 시즌/프로모션 시 일 예산을 빠르게 확대)
2. 신제품 출시로 인한 공격적인 운영이 필요한 경우 (단기간 내 높은 노출과 성과 목표)
3. 특정 상품 군의 별도 관리가 필요한 경우 (브랜드 내 상품 별 운영 전략에 따라 집중 관리)

### 6. CPC 리부트(CPC Reboot) — PRO 전용
📍메뉴 위치: 입찰 최적화 > 최적화 설정 > 고급 설정 > 알고리즘 고급 설정
최신 트렌드를 반영하여 입찰가를 다시 학습시키고, 광고 성과를 높일 수 있는 새로운 가능성을 탐색. PRO 알고리즘이 설정된 하루예산을 기준으로 1주일간 다이내믹하게 입찰 테스트 진행.
📌 적용 방법: [CPC 리부트] 영역 토글 ON 후 저장.
[펼친 토글 시도] 적용 예시: [이미지만 포함, 텍스트 콘텐츠 없음]
검수 완료 후 다음 입찰시 반영. CPC Reboot 기간은 1주일 이후 자동 종료, 이전 종료 희망 시 토글 OFF로 종료 가능.
⚠️ 세팅 참고 사항: 최신 트렌드 반영 재학습을 위해 Average CPC 또는 CPA 기능과 동시 사용 제한. 최대 CPC(Max CPC) 기능은 동시 사용 가능. 세팅된 하루예산보다 더 많은 예산 소진 가능.
💡 언제 사용하나요?
1. 예산 과다 상태가 장기간 지속되는 경우 (설정 하루예산 대비 실제 소진이 적은 '예산 과다' 상태 장기 지속, 특정 순위/입찰가 범위 내 입찰 지속 판단 시)
2. 새로운 입찰 전략 탐색이 필요한 경우 (신제품 출시 등으로 기존 학습 데이터에 기반하지 않고 전체 키워드&소재에 대한 새로운 입찰 전략 탐색 필요 시)

| 2 | 자동 토글 (ON/OFF) | 토글로 제외 키워드 설정 방식(자동/수동) 선택. 자동 ON 시 알고리즘 추천 결과가 매주 업데이트되어 자동 등록·운영. 자동 OFF 시 추천 목록 확인 후 직접 등록. |
| 3 | 제외이력보기 | 선택한 최적화 아이템의 제외 키워드 추가 및 삭제 이력을 확인합니다. |
| 4 | 제외 키워드 추천 유형 선택 (보수적 추천/공격적 추천) | 보수적 추천: 광고비 낭비가 매우 확실한 소수의 저효율 키워드만 선별 추천. 공격적 추천: 즉각적인 광고 효율 개선을 목표로 효율이 낮다고 판단되는 키워드를 폭넓게 선별 추천. |
| 5 | 추천 일괄 선택 | 선택된 추천 유형에 따라 해당 최적화 아이템 내 추천된 제외 키워드가 모두 추가 대상으로 선택됩니다. |
| 6 | 추천 제외 키워드 수 Count | 각 소재별로 추천된 제외 키워드의 수를 의미합니다. |
| 7 | 소재별 분석 대상 키워드 목록 | 소재별 토글 확장 후 [키워드] 탭에서 분석 대상 키워드 목록 확인. 최근 2주 실적이 충분하지 않으면 분석 대상 제외. 🅰️ 추천 일괄 선택 / 🅱️ '추천' 뱃지가 붙은 키워드는 제외 키워드로 추천된 키워드임을 의미. |
| 8 | 소재별 제외 키워드 목록 | 소재별 토글 확장 후 [제외키워드] 탭에서 현재 설정된 제외 키워드 목록 확인. 해제하고 싶은 키워드 선택 시 삭제 진행 가능. |
| 9 | 제외 키워드 추가/삭제 목록 | 🅰️ 제외키워드 추가: 추가할 키워드 목록 확인. 🅱️ 제외키워드 삭제: 삭제할 키워드 목록 확인. |

### 1. 제외 키워드 추가하기
1. 제외 키워드를 설정하고 싶은 최적화 아이템을 선택합니다.
2. 제외 키워드 설정 방식(자동/수동)을 선택합니다.
   📢 자동 토글을 ON할 경우, 알고리즘의 추천 결과가 매주 업데이트되어 제외 키워드로 자동 등록 및 운영됩니다.
3. 자동으로 반영할 알고리즘의 제외 키워드 추천 유형으로 '보수적 추천'/'공격적 추천' 중 하나를 선택합니다.
   📢 자동 토글을 OFF할 경우, 알고리즘의 추천 제외 키워드 목록을 확인한 후 직접 등록할 수 있습니다.
4. 제외 키워드 추천 유형으로 '보수적 추천'/'공격적 추천' 중 하나를 선택합니다.
5. 추천 제외 키워드를 조회하고 싶은 소재를 소재명/캠페인/애드그룹으로 필터링하여 조회 가능합니다.
6. 토글을 확장하면 [키워드]탭에서 해당 소재의 분석 대상 키워드 목록을 확인할 수 있습니다. (최근 2주 실적이 충분하지 않은 경우 분석 대상에 포함되지 않음)
7. 우측에 [추천] 뱃지가 붙은 키워드는 제외 키워드로 추천된 키워드임을 의미합니다.
   💡 제외 키워드 활용 Tip.: 각 소재 단위로 분석 대상 키워드별 지난 한 달 광고 실적을 조회 가능. 테이블 우측 상단의 더보기 버튼으로 원하는 지표 추가 조회 가능. 키워드별 광고 실적은 매주 1회 업데이트.
8. 제외 키워드로 설정하고 싶은 키워드를 선택합니다. 우측 [제외키워드 추가] 탭에서 선택된 키워드를 확인 가능.
   ※ 소재별 '추천 일괄 선택' 시, 선택된 추천 유형에 따라 해당 소재에 추천된 제외 키워드가 모두 선택됩니다.
   ※ 최적화 아이템별 '추천 일괄 선택' 시, 선택된 추천 유형에 따라 해당 최적화 아이템 내 소재별로 추천된 제외 키워드가 모두 선택됩니다.
9. 적용 버튼을 클릭합니다.
10. 추가할 제외 키워드의 목록을 최종 확인한 후 적용을 클릭합니다.
11. 제외 키워드로 추가 등록된 키워드는 네이버 광고 플랫폼에 자동으로 즉시 반영됩니다.

### 2. 제외 키워드 삭제하기
1. 제외 키워드를 관리하고 싶은 최적화 아이템을 선택합니다.
2. 제외 키워드 목록을 조회하고 싶은 소재를 소재명/캠페인/애드그룹으로 필터링하여 조회 가능합니다.
3. 토글을 확장한 후 [제외 키워드] 탭을 클릭합니다. 소재 단위로 현재 설정된 제외 키워드 목록을 확인할 수 있습니다.
4. 제외 키워드 중 제외 설정을 해제하고 싶은 키워드를 선택합니다. 우측 [제외키워드 삭제] 탭에서 선택된 키워드를 확인 가능.
5. 적용 버튼을 클릭합니다.
6. 제외 설정을 해제할 키워드의 목록을 최종 확인한 후 적용을 클릭합니다.
7. 제외 키워드로 삭제 적용된 키워드는 네이버 광고 플랫폼에 자동으로 즉시 반영됩니다.

### 3. 제외 키워드 이력 관리하기
1. 제외 키워드 설정 이력을 조회하고 싶은 최적화 아이템을 선택합니다.
2. [제외이력보기] 버튼을 클릭합니다.
3. 제외 키워드 '추가'(수동/자동)와 '삭제' 이력을 확인할 수 있습니다. ※ 좌측 목록에서 이력 항목을 선택하면, 우측에서 실제로 추가 또는 삭제된 키워드 목록을 소재별로 조회할 수 있습니다.
4. 가장 최근에 변경된 이력에 한하여, [복구] 버튼을 클릭하면 변경 사항을 이전 상태로 되돌릴 수 있습니다.
   **복구 기능 안내**: 제외 키워드 추가 이력의 경우, 복구 시 해당 키워드가 제외 키워드 목록에서 삭제됩니다. 제외 키워드 삭제 이력의 경우, 복구 시 해당 키워드가 다시 제외 키워드로 등록됩니다.

- 자동으로 키워드를 추가하거나 삭제하지 않습니다. 매체 등록 키워드 기준으로 입찰 최적화를 진행합니다.
- 매체에서 설정된 캠페인에 대해 본 최적화 기능을 이용하여 키워드 단위까지 입찰을 자동 관리할 수 있습니다.
📢 적용 대상: 네이버 검색광고(파워링크), 카카오 검색광고(프리미엄링크). ※구글 검색광고는 해당 기능을 이용할 수 없으며, 연동 시 Bid Opt 외 기능은 모두 이용할 수 있습니다.

### 1. 운영 모드 선택하기
MOP의 입찰 최적화 기능은 [이지 모드], [전문가 모드] 두 가지 버전으로 제공됩니다.
⚠️ 전문가 모드는 LITE/PRO 플랜 대상으로만 제공됩니다.

### 2. 최적화 아이템 생성하기
MOP를 적용할 대상 캠페인/애드그룹을 등록하고, 필요한 정보를 입력합니다. 등록 후 최적화 가능 여부에 대한 검수를 진행하며, 검수 완료 시 설정된 입찰 기간 동안 광고 입찰가를 자동 최적화합니다.

📌 최적화 아이템 생성 방법 (검색광고)
1. 신규생성+ 버튼을 클릭하고, 최적화 입찰을 적용할 매체를 선택합니다. MOP에 유닛으로 등록된 캠페인/애드그룹 리스트를 확인할 수 있습니다.
2. 대상으로 할 매체의 캠페인/애드그룹과 입찰 기간을 설정합니다. 입찰 시작일은 익일부터 선택 가능하며 종료일은 설정하거나 미설정할 수 있습니다.
3. 최적화명, 하루 예산, 최적화 목표, 입찰 제외 키워드(선택사항)를 설정합니다. ⚠️ 입찰 제외 키워드는 1,000개 이상 등록은 권장드리지 않습니다.
4. Save 버튼을 클릭하고, 최적화 가능 여부 검수 완료를 확인합니다. (보통 1시간 이내)
5. "검수완료" 상태 후, 자동입찰 토글을 On으로 변경하면 입찰 및 최적화가 진행됩니다.
⚠️ 자동입찰을 ON으로 변경해도 준비중에서 입찰중으로 변경되지 않는 경우 ⇒ 대시보드 > Flight > Bidding 내 Next bidding에서 입찰 시간 확인 가능.

(쇼핑검색광고 최적화 문서와 동일 내용) 자동 입찰 시작 후 수정 가능 항목: 입찰 종료일, 최적화명, 하루 예산, 입찰 제외 키워드, 입찰가 고급 설정, 알고리즘 고급 설정. 수정 불가능 항목: 캠페인/애드그룹 리스트, 입찰 시작일, 최적화 목표. 수정은 자동 입찰 OFF 상태에서만 가능. 수정 불가능 항목 조정 필요 시 기존 아이템 삭제/종료 후 재세팅 필요.

### 3. 최적화 대상 선택하기 (캠페인/애드그룹)
한 개의 예산 하에서 관리할 캠페인 또는 애드그룹을 선택합니다.

선택한 캠페인/애드그룹 규모의 제한은 없으나, **최근 30일 내 클릭이 1건 이상 발생한 키워드 수가 1만개 이하로 설정하기를 권장**. 매체에 설정되어 있는 캠페인/애드그룹 리스트만 확인 가능하며, MOP에서 캠페인/애드그룹을 셋팅하는 기능은 지원하지 않습니다. MOP 연동 이후 신규 캠페인이 생성되었다면 리스트에서 확인되지 않을 수 있음(유닛 추가 등록 필요).

[펼친 토글] 캠페인/애드그룹이 선택되지 않는다면? (회색 텍스트로 뜰 경우): (쇼핑검색광고와 동일) 회색 텍스트는 이미 다른 최적화 아이템에 설정된 항목. 신규 시작일을 기존 종료일 이후로 설정 시 선택 가능.

[펼친 토글] 캠페인/애드그룹이 빨간색 텍스트로 보인다면?: (쇼핑검색광고와 동일) 최적화 미완료 시 빨간색 노출(운영 2주 미만 또는 최근 3일 실적 부족). Pro 플랜은 실적 조건 무관하게 네이버 추천 입찰가로 자동 운영.

⚠️ 캠페인/애드그룹 선택 시 참고 사항: 매체 하루 예산 Cap 설정 비권장(자동 배분 방해). 일 예산 Limit 있는 경우 캠페인에만 Cap 설정 권장(애드그룹 Cap은 비권장). 매체 변경사항 미반영 시 MOP 갱신은 매일 오전(빠른 반영 필요 시 mop_support@lgcns.com).

### 4. 최적화 아이템 목표 설정하기 (KPI)
최적화 아이템 당 "클릭 최적화", "전환 최적화", "ROAS 최적화", "다중목표 최적화" 중 1개 목표를 설정하여 운영합니다.

[펼친 토글] 최적화 아이템 목표 설정하기:
- 클릭 최적화: 예산 내 가장 많은 클릭 확보 목표, 노출과 클릭 동시 최적화. 신제품 런칭/프로모션 등 유입 확대 필요 시 선택.
- 전환 최적화: 예산 내 가장 많은 전환 확보 목표, 클릭과 전환 동시 최적화. 성수기/경쟁 심화 시기 선택.
- ROAS 최적화: 예산 내 가장 많은 매출 확보 목표, 클릭과 매출 동시 최적화. 비수기/상시 운영 기간 선택.
- 다중 목표 최적화: 여러 지표(노출, 클릭, 전환, 매출) 동시 최적화. Average CPC/CPA로 비용 효율 관리 가능(너무 적은 금액 설정 시 소진 불량 가능).
(※ 검색광고는 쇼핑검색광고와 달리 상품 유형 구분에 따른 목표 선택 제약이 없음 — 전 목표 모두 선택 가능)

[펼친 토글] 최적화 아이템 목표를 변경하고 싶어요.: 입찰 시작 후 목표 변경 불가. 변경 필요 시 신규 생성.

💡 최소 하루 1건 이상 전환 필요(머신러닝 원활 진행). 전환량 적어도 설정 가능하나 '클릭 최적화'와 유사 운영.
💡 ROAS 개선 원할 시 다중목표 최적화에서 Click, Revenue 설정 + 하루 예산 축소.

### 5. 최적화 예산 설정하기 (하루 예산)
MOP의 최적화 알고리즘은 설정된 하루 예산 내에서 충분한 예산이 있다면 정량을 최대한 확보, 부족하면 비용 효율을 최대한 확보하는 방향으로 작동. 주간 평균 소진 가능 비용 입력 권장.

[펼친 토글] 하루 예산 설정하기: (쇼핑검색광고와 동일) VAT 제외 금액 입력. 주간 평균 소진 비용 입력 권장. 요일별 실적 고려로 예산보다 더/덜 소진 가능. 매체 예산 Cap 설정 시 그 이상 소진 안함.

💡 하루 예산 설정 TIP! 한 번에 20~25% 이상 상향 비권장. 반복적 단기 수정 비권장(1주일 모니터링 권장). 예산 확대=공격적 입찰, 축소=보수적 입찰.

### 6. 대량 등록하기
대량 등록은 입찰최적화 아이템을 엑셀 파일로 여러 아이템을 한 번에 대량 등록할 수 있는 기능입니다.
📌 방법: 1.신규생성+ → 대량 등록 선택 2.양식 다운로드 → 필수 항목 기입 후 저장 3.양식 파일 업로드 → 업로드 완료 확인 후 [최적화 등록하기] 클릭.

### 1. 검색광고 순위 타겟팅 (Search Ad Rank Target) 이란?

📍메뉴 위치: MOP 로그인> Menu > 검색광고 > 순위유지

검색광고 운영 시, 최적화 알고리즘을 통한 자동 입찰 관리 대신 사용자가 특정 키워드의 순위를 별도로 관리하고 싶을 때 활용하는 기능입니다.

🚀 MOP 플랜을 업그레이드하고 더 많은 키워드의 순위를 타겟팅하세요!
[표: 플랜별 순위유지/경쟁사 모니터링 개수]
| 구분 | MOP Basic | MOP Lite | MOP Pro |
|---|---|---|---|
| 순위유지 키워드 개수 | 최대 5개 | 최대 20개 | 최대 50개 |
| 경쟁사 모니터링 개수 | 최대 3개 | 최대 5개 | 최대 10개 |

✅ 검색광고 순위 타겟팅 설정하기
1. 신규생성+ 버튼을 클릭하고, 원하는 매체와 디바이스, 특정 순위를 유지하고 싶은 키워드 ID를 입력합니다.
   ⚠️ 세팅 과정에서 Rank Target에 입력한 디바이스와 실제 매체에 세팅된 디바이스가 다른 경우, Max CPC까지 입찰가 상승하여 광고비가 낭비될 수 있으므로, 반드시 동일하게 입력해주세요!
2. 지역/입찰가 변동폭을 설정합니다. 입찰가 변동폭은 10원 단위로 설정 가능. 📢 입찰가 변동폭 토글 OFF하는 경우 알고리즘에 따라 입찰이 이루어집니다.
3. 노출을 원하는 순위/최대 입찰가를 선택 후 [CREATE] 버튼을 눌러 생성. ⚠️ Max CPC 이상 입찰을 진행하지 않으므로 Max CPC에 도달한 경우 목표 순위를 유지하지 못할 수 있습니다.
4. 노출을 원하는 요일/시간 영역을 드래그하여 선택 가능.
5. 설정 완료 후 Rank Target 목록에서 자동입찰 토글을 On 하면, 입찰주기에 따라 입찰가를 관리합니다. ⚠️ 네이버 시스템 변경 및 서버 상태에 따라 입찰 주기는 최소 5분~최대 20분 단위까지 조정될 수 있습니다.

🚨
1. 네이버 플랫폼 내 하기 설정이 적용된 키워드의 경우, 순위유지 기능 활용이 어렵습니다. ⚠️ 현재 순위 데이터가 수집되지 않아서 Max CPC까지 입찰될 수 있습니다.
   - 성별, 연령 타겟팅 적용 및 제외 설정한 경우('알수없음'도 포함)
   - 파워링크 노출 지면에서 '더보기' 영역 제외 설정한 경우
2. 순위유지 설정된 키워드는 추천 입찰 대상이 아닌 경우, 입찰최적화 대상에서 자동으로 제외됩니다.

### 2. 쇼핑검색광고 순위 타겟팅 (Shopping Ad Rank Target) 이란?

### 3. 키워드 순위 모니터링 (Keyword Rank Monitoring) 이란?
모니터링을 ON하면 등록한 키워드의 광고 노출 현황을 1시간 단위로 모니터링합니다.
- [모니터링 항목]: 자사 키워드 노출 순위, 입찰 CPC, 동일 키워드를 사용하는 경쟁사 키워드 노출 순위 (Pro: 최대 10개, Basic: 최대 3개)
- 키워드 별로 MEDIA, DEVICE, KEYWORD, PERIOD를 설정하여 모니터링 결과를 확인할 수 있습니다.
- VIEW 방식에 따라 표 또는 그래프로 확인 가능합니다.
- 현재순위, 목표순위, 입찰가를 선택하여 볼 수 있습니다.
- [Competitor ON/OFF]: Setting 아이콘을 클릭하여 경쟁사를 지정할 수 있습니다. 모니터링된 리스트 중 경쟁사를 선택하고 이름을 지정할 수 있습니다. 지정된 이름으로 표시되며, 이름을 선택하여 시간 별 경쟁사 순위를 확인할 수 있습니다.

💡 순위 타겟팅 운영 Tip.
- Rank Target 생성 후 모니터링을 ON 하면, 설정한 키워드에 대해 각 순위에 노출되는 광고를 시간대별로 모니터링할 수 있습니다.
- 순위유지 설정된 키워드는 추천 입찰 대상이 아닌 경우, 입찰최적화 대상에서 자동으로 제외됩니다.
- 리포트 아이콘을 클릭하면 기간 내 모니터링한 내역을 그래프로 확인할 수 있습니다.
- 우측 상단 Setting 아이콘을 클릭하면 경쟁사 선택 가능하며, 설정 시 해당 경쟁사의 운영 현황도 함께 모니터링 가능합니다.
- 경쟁사가 10순위 내에 노출된 경우에만 순위 확인이 가능하며, 경쟁사의 입찰가는 확인할 수 없습니다.
- 성별, 연령 타겟팅 적용 및 제외('알수없음'도 포함)하거나, 파워링크 노출 지면에서 '더보기' 영역 제외 시 현재 순위 확인이 어렵습니다.

## 광고 예산 최적화 > 예산 추세

URL: https://support.mop.co.kr/spend-pacing
(참고: 사이드바 표기에 오타 있음 — "에산 추세"로 표시됨. 정상 표기는 "예산 추세")

예산 추세 대시보드

📍메뉴 위치: MOP 로그인> 광고 예산 > 예산 추세

예산 추세 메뉴에서는 MOP에 연동된 광고 유형 및 매체별 광고비 비중과, 실적 개선을 위한 매체/캠페인 별 추천 예산, 그리고 입찰 최적화 아이템 별 광고비 현황을 한번에 확인할 수 있습니다.

### 광고 유형 및 매체별 광고비 비중
- MOP에 연동된 광고 유형(SA, SPA, DVA) 및 매체(네이버, 카카오, 구글, 메타, 크리테오) 별 광고비 비중을 확인할 수 있습니다.
- 조회한 날짜를 기준으로, 광고 유형 및 매체별 광고비 비중과 실제 소진 금액을 확인할 수 있습니다.
- 그래프 위로 마우스오버 하면 계정 별 상세 데이터를 확인할 수 있습니다.

### 예산 변경 추천
매체/캠페인 예산 재배분 최적화를 수행한 결과로, 실적 개선을 위해 MOP에서 추천하는 예산을 보여줍니다. 노출, 클릭, 조회, 전환, 매출 지표를 모두 고려한 성과 영향도 예측 데이터로, 영향도에 따라 3단계로 표시합니다.

[펼친 토글] 성과 영향도 예측 단계:
1. 예산 변경 영향 발생: 예산 변동 시 성과가 증가할 것으로 예측, 최적화 결과를 지속 확인하기를 추천.
2. 예산 변경 추천: 예산 변동 시 성과가 증가할 것으로 예측, 최적화 결과에 따라 예산 변동할 것을 추천.
3. 예산 변경 적극 추천: 예산 변동 시 성과가 크게 증가할 것으로 예측, 최적화 결과에 따라 예산 변동을 적극 추천. (원문 절삭됨 — "따라 예산" 이후 텍스트 미노출)

상단 "추천 예산 확인하기" 버튼을 클릭하면 매체/캠페인 단위의 상세 분석 결과를 조회할 수 있습니다. 예산 최적화 메뉴에서 다양한 시나리오 별 추천 예산을 확인해 보세요.

### 최적화 아이템 별 광고비 현황
검색광고, 쇼핑검색광고 입찰 최적화 아이템 별 광고비 현황을 확인할 수 있습니다. 최적화 설정 여부에 따른 광고비 비중과 소진 금액을 확인할 수 있습니다.

[펼친 토글] 최적화 설정 여부:
- 입찰 최적화 중 (SA): 네이버/카카오 검색광고 최적화 입찰이 적용된 캠페인/애드그룹으로, '오늘'이 최적화 기간 내에 포함되어 있는 경우.
- 입찰 최적화 중 (SPA): 네이버 쇼핑검색광고 최적화 입찰이 적용된 캠페인/애드그룹으로, '오늘'이 최적화 기간 내에 포함되어 있는 경우.
- 입찰 최적화 가능: 검색/쇼핑검색광고 최적화 입찰이 적용되지 않은 캠페인/애드그룹.
- 기타: 최적화가 불가능한 캠페인/애드그룹 유형 (파워컨텐츠, 플레이스 등).

최적화 아이템 별 예산 소진 현황도 확인 가능합니다.
- 최적화 별 하루 예산 대비, '오늘', '이번주', '이번달'의 소진 현황을 확인할 수 있습니다.
- '오늘'에 해당하는 광고비는 테이블 우측 상단에 표시된 시간에 매체에서 조회한 금액으로 실시간으로 소진되는 금액과는 차이가 발생할 수 있습니다.

예산 소진 관련하여 최적화 운영 TIP이 필요하면 담당 컨설턴트 또는 mop_support@lgcns.com으로 연락주세요.

## 광고 예산 최적화 > 예산최적화

URL: https://support.mop.co.kr/budget-opt

예산 최적화 (Budget Opt) 란?

📍메뉴 위치: MOP 로그인> 광고 예산 > 예산최적화

예산 최적화는 광고 목표를 극대화할 수 있도록 각 매체의 캠페인 단위 최적 예산을 추천하는 기능입니다.

### 0. 광고 예산 최적화 사전 점검
- 연동된 매체와 등록된 유닛에 대해 해당 기능을 사용할 수 있습니다.
- 매체의 예산을 자동 변경하는 기능은 지원하지 않습니다. (추후 지원 예정)
- 유저는 다양한 시나리오(다양한 옵션 설정)의 최적화 아이템을 등록하고, "현재와 동일한 비중으로 광고가 집행되었을 때 예측되는 실적" vs "예산 변경 시 예측되는 실적"을 검토하여 더 높은 목표를 달성하기 위한 캠페인 별 예산 배분을 손쉽게 할 수 있습니다.
📢 MOP의 Budget Opt 알고리즘은 각 캠페인 별 광고 집행 비용을 일 단위로 검토하고, 한정된 예산 하에서 각 캠페인 단위 예산 변경(Re-allocation)에 따른 상향 가능성이 발생했을 때 최적 예산과 예측되는 실적을 제시합니다.

### 1. 최적화 아이템 생성하기
운영 매체/캠페인과 예산 결정을 위한 옵션 설정을 통해 다양한 시나리오의 최적화 아이템을 등록할 수 있습니다.

📌 최적화 아이템 생성 방법 (통합 예산 최적화)
1. 신규생성+ 버튼을 클릭하고, 원하는 최적화명을 입력합니다. 새로운 최적화 아이템이 생성되며 최적화 ID가 부여됩니다.
2. 생성된 최적화 아이템을 클릭하고, 셋팅을 시작합니다.
   - Step 1. 대상 매체/캠페인 선택
   - Step 2. 최적화 설정: 최적화 목표, 캠페인 단위 예산 변동 폭, 기여도 반영 여부(선택)를 선택합니다.
   - Step 3. 최적화 결과: 선택한 설정 값에 따라 Budget opt를 수행한 결과를 보여줍니다.
3. 생성된 최적화 아이템은 매일 Budget opt를 수행하고 성과 영향도를 제공합니다. 최적화 아이템 목록에서 최적화 기준일을 확인하고 예측된 성과 영향도를 확인.

[펼친 토글] 최적화 아이템 수정/삭제 방법:
최적화 아이템 수정 및 삭제는 최적화 아이템 목록에서 모두 가능합니다.
- 최적화 아이템 목록에서, 각 아이템별로 수정 버튼을 클릭하여 수정하거나 삭제할 수 있습니다.
- 생성된 최적화 아이템의 최적화명을 클릭하고 설정된 내용을 변경하여 수정할 수 있습니다.
- 대상 매체/캠페인 및 최적화 설정 전체를 수정할 수 있습니다.

[펼친 토글] 최적화 아이템 생성 시, 꼭 알아두세요!:
- 최적화 목표는 복수 metric을 선택할 수 있으며 최소 1개 이상 선택합니다.
- 매체 단위 예산 비중 고정 옵션 선택 시, 기존에 운영하던 각 매체별 예산 비중을 유지하면서 Budget opt를 수행합니다.
- 기여도 반영 옵션은 GA4 또는 에어브릿지를 성과 전환 분석 툴로 선택한 경우에만 사용 가능합니다.

⚠️ 세팅 사전 참고 사항
- 오늘로부터 최근 3일 간 운영 실적이 있으며, 활성화(상태값 on) 캠페인을 2개 이상 선택하여야 Budget opt가 가능합니다.
- 선택한 매체/캠페인의 광고 집행이 종료된 후 3일이 경과하는 경우 더 이상 Budget Opt가 수행되지 않습니다.
- 연동된 유닛 대상 설정이 가능하며, 등록되지 않은 유닛은 매체/캠페인 선택 시 리스트에서 확인되지 않습니다.

### 2. 최적화 결과 확인하기
최적화 설정 완료 후 결과를 확인할 수 있으며, 최적화 아이템 목록에서 매일 업데이트되는 성과 영향도를 확인할 수 있습니다.

**성과 영향도 예측하기**
- 예산 변경 적극 추천 (Highly Recommend): 예산 변동 대비 성과가 크게 증가할 것으로 예측되므로 최적화 결과에 따라 예산을 변동할 것을 적극 추천.
- 예산 변경 추천 (Recommend): 예산 변동 대비 성과가 증가할 것으로 예측되므로 예산을 변동할 것을 추천.
- 예산 변경 영향 발생 (Go over): 예산 변동 시 성과가 증가 영향이 발생할 것으로 예측되며, 최적화 결과 확인을 추천.

**최적화 결과 확인하기**
매체의 각 캠페인 단위 예산 재배분 비중과 예상 실적, 재배분 시 발생할 수 있는 성과 영향도를 제시합니다.
- '평균 성과 영향도'는 최적화 목표로 설정한 Metric에 대해, 기존과 동일하게(예산 비중을 변경하지 않고) 광고를 집행했을 때 대비 변경 시 예측되는 실적의 상향 효과를 계산한 값. 여러 개 목표 선택 시 평균값 산출.
- 하단 캠페인 별 실적 테이블에서, 지난 2주 기준 각 캠페인별 주간(Weekly) 예산 비중과 MOP가 제시하는 예산 비중을 확인할 수 있습니다. '성과 영향도 예측' 컬럼에서 변경 시 예측되는 주간 실적 확인 가능.
- 증감률 표시 버튼을 클릭하여 각 Metric 별 변동폭을 손쉽게 확인할 수 있습니다.

💡 광고 예산 최적화 결과 해석 Tips
- 20% 이상의 예산 변동 폭을 셋팅한 경우, 성과 영향도 예측 결과의 정확도가 낮아질 수 있습니다.
- 예측된 성과 영향도 정량 수치보다는 각 캠페인별 변동폭을 주의 깊게 확인하는 것을 권고합니다.
- 검색광고, 쇼핑검색광고가 선택되어 있는 경우, [인사이트 > 예산민감도] 메뉴를 함께 확인할 것을 권고합니다.

## 광고 예산 최적화 > 기여도

URL: https://support.mop.co.kr/attribution

광고 기여도 분석 (Attribution) 이란?

📍메뉴 위치: MOP 로그인> 광고 예산 > 기여도

연동된 성과 분석 툴 기반 운영된 다양한 광고 매체의 전환 기여도를 분석하여 데이터를 제공합니다. 기여도 트렌드와 함께 채널별, 매체별 기여도 비중도 제공합니다.

**기여도 제공 항목**
- 기여도 트렌드: 특정 기간 동안 설정된 목표에 기여한 채널 및 매체의 기여 비중에 대한 트렌드 차트.
- 채널별 기여도: 최근 6개월의 기여도 분석을 바탕으로 전일자 기준 전환에 기여한 전체 채널별 비중.
- 매체별 기여도: 최근 6개월의 기여도 분석을 바탕으로 전일자 기준 전환에 기여한 전체 광고 매체별 비중.
- 상세 결과: 연동 데이터 기준 애드그룹 단위까지 세밀한 기여도 분석 및 비중.

### 1. 기여도 화면 설명
기능 위치: MENU > 인사이트 > 기여도
- [목표 구분]: 유닛 설정된 성과 분석 툴의 전환값 유형(구매/구매 외/전체)을 선택. 지정한 목표에 따른 기여도 트렌드 차트 제공.
- [기여도 트렌드]: 특정 기간 동안 설정된 목표에 기여한 채널 및 매체의 기여 비중에 대한 트렌드 차트.
- [기간 및 조회 단위]: 데이터 기간 및 조회 단위 변경 가능.
- [다운로드]: 차트로 제공된 데이터를 csv 파일로 다운로드 가능.
- [범례 선택]: 제외할 범례를 클릭하면 차트에서 제외됩니다. 특정 채널/매체 비중이 너무 높아 트렌드 파악이 어려운 경우 사용.
- [채널별 기여도]: 최근 6개월 기여도 분석 바탕 전일자 기준 전환에 기여한 전체 채널별 비중.
- [매체별 기여도]: 최근 6개월 기여도 분석 바탕 전일자 기준 전환에 기여한 전체 광고 매체별 비중.
- [상세 결과]: 연동된 UTM 기준 애드그룹 단위까지의 정교한 기여도 비중 표시.
- [다운로드]: 각 기여도에 대한 내용은 raw data 형태로 csv 파일 다운로드 가능.

💡 운영 Tips.
- MOP는 Last Click 기준 전환 기여도 분석이 아니기 때문에 일반적인 매체 기여 설정과의 차이가 있습니다. 실제 광고 목표에 기여한 매체와 채널을 확인해보세요.
- 애드 그룹 단위까지 기여도 분석이 되기 때문에 DA, VA 세팅 단계에서 애드그룹을 타겟팅 명, 소재 주제 등으로 구분해두면 타겟팅과 주제에 대한 기여도 분석도 가능합니다.

캠페인 리포트 (Campaign Report) 란?

📍메뉴 위치: MOP 로그인> 리포트 > 캠페인

MOP와 데이터 연동이 된 모든 캠페인에 대해 통합된 데이터 리포트를 대시보드 형태로 제공합니다. 매체 별, 날짜 별로 구분하여 편리하게 이용해보세요.

🚀 Pro로 업그레이드하고 데이터를 안심하고 저장하세요!
[표: 플랜별 데이터 저장/조회 기간]
| 구분 | MOP Basic/Lite | MOP Pro |
|---|---|---|

| 데이터 조회 기간 | 최대 60일 | 최대 180일 |

### 1. 캠페인 리포트 화면 설명
기능 위치: MENU > 리포트 > 캠페인
- [조회기간]: 광고를 조회할 기간을 선택합니다.
- [비교기간]: 동기간 비교를 위한 비교기간 조회 기능. 조회기간에 맞춰 직전 동기간으로 자동 설정, 원하는 기간 설정도 가능.
- [광고유형]: 조회할 광고의 유형을 선택합니다.
- [매체]: 조회할 매체를 선택합니다.
- [캠페인, 애드그룹]: 조회할 캠페인과 애드그룹을 선택합니다.
- [지표 설정]: 요약 데이터를 조회할 항목을 선택. 전체 또는 선택 항목만 가능.
- [범례 선택]: 그래프로 조회할 두 개 지표를 선택.
- [조회 방식]: 기간 단위와 그래프 형태 변경 가능.
- [그래프]: 실선=<조회기간>, 점선=<비교기간>. 비교기간 미선택 시 실선만 표시.
- [유형 선택]: 조회한 데이터를 날짜별, 매체별로 구분하여 상세 데이터 확인 가능.
- [조회 방식] (상세): 증감률 표시, 디바이스 구분 표기 체크 조회 가능.
- [다운로드]: 조회한 데이터를 csv 형태로 다운로드 가능.
- [정렬 기능]: 날짜, 디바이스 유형, 기간에 대해 오름차순/내림차순 정렬 가능.
- [매체별 리포트]: 연동된 매체별로 해당 기간에 대한 리포트 조회 가능. 토글 확장 시 최대 애드그룹 단위까지 데이터 조회 가능. 캠페인/애드그룹 단위에서는 각 유닛에 설정한 전환툴, 전환값도 함께 확인 가능.

| 전환 지표 | CVR | 전환율(%) | 전환수/클릭수 |
| 전환 지표 | CPA | 전환당비용 | 광고비/전환수 (VAT 포함 기준) |

### 1. 최적화 리포트 화면 설명
기능 위치: MENU > 리포트 > 최적화
- [조회기간] / [비교기간]: 캠페인 리포트와 동일한 방식.
- [최적화]: 리포트로 조회할 최적화 Opt ID를 선택합니다.
- [광고유형,매체]: 최적화 입찰이 설정된 광고 유형 및 매체가 자동으로 선택됩니다.
- [제외 키워드/소재 실적]: 최적화 입찰에서 제외(Negative) 설정한 키워드/소재에 대한 데이터 포함 여부를 선택합니다.
- [지표 설정] / [범례 선택] / [조회 방식] / [그래프] / [다운로드] / [정렬 기능]: 캠페인 리포트와 동일한 방식.
- [유형 선택]: 조회한 데이터를 날짜별, 최적화별로 구분하여 상세 데이터 확인 가능.
- [최적화별 리포트]: '최적화별' 탭 클릭 시 설정된 최적화별 리포트 조회 가능. 토글 확장 시 최대 애드그룹까지 데이터 조회 가능. 캠페인/애드그룹 단위까지 확장하면 설정된 유닛 전환값도 확인 가능.

💡 최적화 리포트 활용 Tips.
- 조회기간 시작일을 최적화 알고리즘이 동작한 날짜부터 설정하면, MOP 적용 전후 데이터를 쉽게 비교해볼 수 있습니다.
- 리포트 조회 시, '제외 키워드/소재포함' 체크버튼을 해제하면 실제 MOP를 적용한 데이터로만 성과 확인이 가능합니다.

## 리포트 > 대용량 리포트

대용량 리포트 (Raw Data)

✔ 1. 캠페인 기준 혹은 2. 최적화 아이템(Opt Item) 기준으로 데이터를 관리할 수 있습니다.
※ 대용량 리포트는 하루에 최대 3개까지 생성 가능합니다.

### 1. 대용량 캠페인 리포트 생성하기
**리포트 생성하기** (기능 위치: MENU > 리포트 > 대용량)
1. 대용량 리포트 메뉴에 접속해서 [신규생성+] 버튼을 선택합니다.
2. '캠페인' 탭을 선택하여 데이터를 다운로드하고자 하는 매체/계정을 선택합니다.
   - ① [매체/계정]: MOP에 연동한 매체에 설정된 계정 정보가 보여지며, 리포트를 생성할 매체/계정 대상을 선택합니다.
   - ② [광고유형]: ※ 동일한 계정이어도 광고 유형(AD Type)별로 항목이 구분되어 있습니다. 대용량 리포트에서 지원하지 않는 매체 및 광고 유형은 MOP에 연동되어있더라도 표시되지 않습니다. ✔️ 대용량 리포트로 다운로드 할 수 있는 매체 및 광고 유형은 추후 확대될 예정입니다.
   - ③ [전환값 유형]: 계정 내 캠페인별로 유닛 등록 시 설정한 전환값이 표시됩니다.
3. 대용량 리포트로 다운로드하고자 하는 상세 설정값을 입력합니다.
   - ① [리포트명]: 생성할 대용량 리포트의 리포트명을 입력.
   - ② [데이터 기간]: 데이터를 조회할 기간 선택. 연동된 데이터 기준 최대 90일까지 설정 가능. 기간이 길수록 리포트 생성 시간 증가.
   - ③ [전환값]: 데이터를 조회할 전환값의 기준을 설정.
     [표] 유닛 전환값: 선택한 계정의 각 캠페인별로 유닛 등록 시 설정한 전환값만을 제공. / 전체 전환값: 선택한 계정별로 데이터 연동시 설정한 모든 전환값을 제공.
   - ④ [분석 기준]: 데이터를 조회할 구분 단위를 설정. 선택한 항목에 한해서만 리포트가 생성됨.
     [펼친 토글] 분석 기준별 정의:
     [표]
     | 분석기준 | 설명 |
     |---|---|
     | 날짜 / 시간 | 데이터를 일 단위로 조회할 지, 시간 단위로 조회할 지 선택. ※둘 중 하나는 필수 선택. ※시간 단위 선택 시 최대 조회 가능 데이터 기간이 90일→30일로 축소 |
     | 데이터 단위 | 데이터를 어느 단위로 구분해서 조회할지 선택. 캠페인/광고그룹/키워드 or 소재/서치키워드(SPA의 경우) 단위로 조회 가능. ※서치키워드 단위 조회 시 최대 조회 가능 기간이 90일→30일로 축소 |
     | 디바이스 | 데이터를 디바이스 단위로 조회할지 선택. PC/Mobile 구분 조회 가능 |
     목록에 표시되는 순서대로 리포트 칼럼이 생성됨(화살표 드래그로 순서 변경 가능).
   - ⑤ [광고 실적]: 조회하고자 하는 광고의 실적 데이터를 선택. 선택한 항목에 한해서만 리포트가 생성됨.
     [펼친 토글] 광고 실적 지표별 정의:
     [표]
     | 구분 | 항목 | 설명 |
     |---|---|---|
     | 광고 지표 | Cost (VAT 포함) | 기간 내 선택한 광고 유형, 매체, 캠페인, 애드그룹, 키워드/소재, 서치키워드에서 지출된 총 금액(VAT 포함). ※네이버 외 매체는 발생한 광고비에 10% 가산 |
     | 광고 지표 | Cost (VAT 제외) | 위와 동일 대상, VAT 제외 금액 |
     | 광고 지표 | Clicks (클릭수) | 선택 대상 광고가 클릭된 횟수 |
     | 광고 지표 | Impressions (노출수) | 선택 대상 광고가 노출된 횟수 |
     | 광고 지표 | Views (조회 또는 시청) | 동영상 광고 조회 수(시청 수). 매체별 광고 상품별 집계 수 따름 |
     | 전환 지표 | 전환수 | 선택 대상 광고에서 발생한 고객 행동 수(구매, 가입 등) |

     목록 순서대로 칼럼 생성(드래그로 순서 변경 가능).

   - ① [보고서 미리보기]: 설정 완료 후 클릭하면 샘플 데이터 노출. 선택한 매체/광고유형/계정ID/계정명은 기본값 제공. 변경 시 재클릭 필요.

- ① [상태]: 생성을 요청한 대용량 리포트의 상태를 나타냄.

  | 데이터만료 | 리포트 생성 후 7일 경과하여 다운로드 링크가 만료된 상태 |

- ② [다운로드]: 생성 완료 후 7일 동안 다운로드 가능. ※ 7일 경과 시 만료, 재생성 필요.

### 2. 대용량 최적화 리포트 생성하기
**리포트 생성하기** (기능 위치: MENU > 리포트 > 대용량) — 캠페인 리포트와 거의 동일한 절차, 차이점만 기술:
1. [신규생성+] → '최적화' 탭 선택 → 다운로드할 최적화명 선택.
   - ① [최적화 선택]: MOP에 등록한 최적화 목록에서 대상 선택. 최적화에 설정된 광고 유형 및 매체가 자동 선택됨.
2. 상세 설정값 입력: ①리포트명 ②데이터 기간(최대 90일) ③전환값 — **여기서는 "유닛 전환값" 옵션만 제공됨(캠페인 리포트의 "전체 전환값" 옵션 없음)** ④분석 기준(위와 동일 정의) ⑤광고 실적(위와 동일 정의)
3. 보고서 미리보기(선택한 매체/광고유형/최적화 ID/최적화명/계정ID/계정명 기본 제공) → [보고서 생성].

**리포트 다운로드하기** — 캠페인 리포트와 동일(상태 정의 동일). 추가 사항: 조회된 데이터양이 많은 경우, CSV 여러개로 나누어서 다운로드됨.

### TIP. 대용량 리포트 사용 팁

**💡 매체 데이터와 외부 전환툴 실적 데이터를 한 번에 관리하기**
MOP에 GA4가 연동 되어있을 경우, 매체 데이터에 외부 전환툴 데이터를 키워드 단위까지 매핑해 통합하여 조회할 수 있습니다. 매체 전환 데이터와 외부 전환툴 실적 데이터를 한 번에 조회하려면 [전체 전환값] 옵션을 선택 — MOP에 연동한 해당 매체의 전체 전환 데이터와 외부 전환툴 데이터를 함께 조회.
- MOP에 외부 전환툴을 연동하려면? 현재 MOP에 GA4 한 가지만 연동 가능. UTM 구조를 MOP에 등록해야 정상 적재 가능. 전환툴별 UTM 작성 가이드는 데이터 연동(Data Connect) 문서 3-2절 참조.
- ✔️ MOP가 지원하지 않는 전환툴/MMP를 이용 중이라면 mop_support@lgcns.com으로 연락.

**💡 일별, 시간대별 등 상세 분석 단위로 인사이트 발굴하기**
대용량 리포트는 분석 목적에 따라 데이터를 일자별, 시간대별로 세분화하여 조회할 수 있습니다.
- 📅 일자별 분석: 캠페인의 장기간 성과 변화를 확인하고자 할 경우, 분석 기준 항목을 '날짜'만 선택. ✔️ 특정 기간에 발생한 외부 요인(프로모션, 이벤트 등)이 성과에 미치는 영향 파악에 활용.
- 🕒 시간대별 분석: 광고 성과의 시간대별 패턴을 파악하고자 할 경우, 분석 기준 항목을 '시간'만 선택. ✔️ 특정 시간대에 전환율이 높아지는 패턴 발견하여 예산 효율 배분에 활용.
- 📅🕒 일자 및 시간대별 분석: 특정 일자와 시간대의 성과를 동시에 분석하려면 '날짜' 및 '시간' 모두 선택. ✔️ 주말/주중, 낮/밤 등 조건별 성과 차이 비교해 최적 집행 시간 결정에 활용.

**💡 쇼핑검색광고(SPA) 시간 단위, 서치키워드 단위 데이터 한 번에 관리하기**
대용량 리포트로 다차원 리포트에서는 받아볼 수 없는 [시간 단위], [서치키워드 단위]까지의 데이터를 한 번에 확인하여 분석할 수 있습니다.

### FAQ. 대용량 리포트 자주 묻는 질문

**리포트 생성 관련**
- Q. 리포트를 생성할 수 있는 계정 목록이 나타나지 않아요. → 대용량 리포트는 MOP에 연동한 후 유닛을 추가한 계정에 한해서만 생성 가능. 연동 계정이 없으면 데이터 연동하기 먼저 진행. 연동했음에도 안 나타나면 유닛 설정하기 진행. 현재 베타 버전은 MOP에 연동 가능한 매체에 한해서만 지원(지원 매체/유형은 추후 확대 예정).

- Q. 리포트 생성이 너무 오래 걸려요 / 계속 생성중이라고만 나와요. → 생성 시간은 데이터양에 비례. 조치: 필요한 조건만 효율적으로 조회 / 복수 계정은 여러 리포트로 분할 생성 / 장기간 데이터는 여러 리포트로 분할. '생성중' 상태가 몇 시간 이상 지속되면 mop_support@lgcns.com 연락.
- Q. CSV가 너무 많이 나와요. 합쳐서 볼 수 없나요? → 요청 데이터양이 물리적으로 방대할 경우 하나의 CSV로 관리·분석이 어려워 여러 CSV로 나눠서 제공.
- Q. 생성 에러가 났어요. → mop_support@lgcns.com 연락.

**데이터 관련**

- Q. 데이터 없음 에러가 발생했어요. → 조회한 기간에 요청한 광고 실적 데이터가 한 건도 없을 때 발생. 데이터 조회 기간 조정 또는 실적 데이터가 존재하는 계정 선택.

MOP 대시보드의 이해

📍메뉴 위치: MOP 로그인> 애드써클 > 대시보드

로그인 후 나타나는 애드써클은 기본적으로 최적화 운영의 세 기능(SA Opt, SPA Opt, BUDGET Opt)으로 구분되어 있습니다. 각 영역을 클릭하면 하단에 광고 현황판(=대시보드)이 노출되며, 최근 7일 간의 광고 실적 뿐만 아니라, 매체 연동 상태, 이상감지, 알고리즘 생성 및 입찰 현황에 대해 확인할 수 있습니다.

### 1. 대시보드 상세 설명

**A. 주요 메뉴 구성**
- [Smart Insight] (화면 우상단): 조회일 기준 진행 중인 광고의 라이브 이상, 광고 노출 변동, 광고 효율성 변동을 감지하여 알려주는 영역.
- [1week summary] (화면 상단): 유닛 설정된 캠페인 기준으로 지난 7일 실적과 그 전 동기간(지지난 7일) 실적을 비교. 좌측 상단 Go Report 버튼으로 상세 Report 진입 가능.
- [최적화 Cycle 현황] (화면 중앙): Daily(주황색 바), Hourly(초록색 바) 단위 모니터링 진행, 이상 징후 발생 시 붉은색 표기. (예: Flight 영역 MAX CPC 도달로 붉은색 표기)

**B. Collection 영역**
현재 수집되고 있는 광고 데이터 현황 및 URL, UTM의 이상을 감지하여 보여주는 영역.
- [Connection Status]: 매체 광고 플랫폼에 셋팅한 광고 정보와 광고 실적 데이터가 시간 단위로 잘 연동되고 있는지 확인. 조회일 기준 셋팅된 최적화 아이템 수 확인 가능.
- [Performance Data collected]: 일간 수집된 실적 데이터의 수집량 확인.
- [Anomaly Detection]: URL 이상감지(랜딩 URL 설정 오류)와 UTM 이상감지(UTM 파라미터 오류) 알림. 더보기로 상세 사유 확인, 수정 후 익일 정상화 여부 확인 가능.

**C. Projection 영역**
현재 운영되고 있는 최적화 알고리즘 현황을 보여주는 영역.
- [Prediction Model]
  - Number of ML models generated: 현재 해당 광고에 생성된 ML 모델 수.
  - Daily predictive data generation: 조회일 기준 예측 모델 생성 여부.
- [Bid Planning]
  - Planning engine in action: 조회일 기준 예산/입찰 계획 생성 여부.
  - Bid Planning Completion ratio: 조회일 기준 생성된 최적화 입찰 계획 수립률.
  - Keyword bid adjustment ratio: 조회일 기준 입찰 변경이 필요한 키워드 수와 비율.
  - Number of top keywords recommended by ML Engine: 조회일 기준 엔진에서 판단한 핵심 순위 유지 키워드 수.

**D. Flight 영역**
현재 진행 중인 예산 변경 및 입찰 현황을 보여주는 영역.
- [Bidding]: 조회일 기준 입찰 변경 Time group과 입찰 현황을 상세히 확인. 광고별 시간 그룹 및 입찰 횟수는 ML 모델에 따라 달라질 수 있음.
- [Maintenance]
  - Number of rank targeted keywords: 유저가 등록한 순위 유지 키워드 수.
  - Target rank achievement rate: 유저가 등록한 순위 타겟팅에 대한 도달률.
  - Max CPC reached: 유저가 등록한 순위 유지 키워드 중 Max CPC에 도달한 키워드 확인.
  - Number of real-time monitoring: 실시간으로 모니터링하는 순위 유지 대상 키워드 수.

💡 생성된 애드써클 기준으로 검색광고(SA)와 쇼핑검색광고(SPA) 영역에 대해 대시보드 확인이 가능하며, 쇼핑검색광고는 광고 유형별(상품형, 카테고리형) 별도 조회가 가능합니다.

## 광고 도구 > 소재 효율성

URL: https://support.mop.co.kr/creative-efficiency

소재 효율성 (Creative Efficiency) 이란?

📍메뉴 위치: MOP 로그인> 광고도구 > 소재 효율성

운영 중인 배너 광고(DA) / 비디오 광고(VA)의 소재 효율성을 분석하여, 비효율적인 소재를 즉시 OFF하여 효율을 개선할 수 있습니다. 현재 카카오, 구글, 메타의 배너/비디오 광고 소재를 대상으로 진행 가능합니다. (추후 확대 예정)

### 1. 소재 효율성 기능 설정하기
1. [신규생성+] 버튼을 누르고 분석명을 입력합니다. 메뉴에서 생성된 분석명을 클릭합니다.
2. 분석대상을 선택합니다. 분석대상은 연동된 광고 매체 기준이며, 캠페인과 애드그룹까지 선택 가능. 연동된 모든 매체를 선택할 수도 있습니다.
3. 분석 기간과 분석 지표를 선택하세요. 분석 지표는 소재의 효율성을 판단하는 기준이며, 여러 개 지표 선택 가능.
4. "Run Analysis" 버튼을 클릭합니다.

### 2. 소재 효율성 분석하기
DA / VA 운영 시, 소재 AB TEST 지원을 위해 MOP에서 제공하는 분석 기능으로, DEA 모형(자료포락분석)을 활용하여 광고 전 지표에 대한 매체별 각 소재의 상대적 효율 수치를 분석, 0부터 1까지의 값으로 표시(Efficiency 효율성 지수 컬럼).
- 0에 가까울수록 효율성이 낮은 소재이며, 광고 실적을 함께 고려하여 제외 설정할 수 있습니다.
- 효율이 좋은 소재보다 효율이 낮은 소재를 발굴하는 데 좋은 분석 방법이므로, 효율이 낮은 소재를 찾아 제외 처리하는 것을 권장합니다.
- 애드그룹/캠페인/매체 탭을 선택하여 분석 기준을 변경할 수 있습니다.
- 최근 2주간 실적이 충분하지 않은 소재는 효율성 분석이 수행되지 않을 수 있습니다.

💡 애드그룹, 캠페인, 매체 단위까지 확장해서 비교해 보세요!
소재가 포함된 애드그룹, 캠페인, 매체 단위로 확장하여 분석 대상의 단위를 다양하게 설정해서 비교하며 운영해보세요. 지표에 따라 동일한 소재라도 단위에 따라 다른 분석 결과가 나올 수 있습니다. (예: '애드그룹에서 효율적인 소재' VS '매체 내에서 가장 효율적인 소재' 비교)

**TIP. 소재 효율성 기능을 통해 라이브 중인 소재의 OFF도 가능한가요?**
가능합니다. 해당 매체의 소재 OFF 기능은 지원하지만 ON 기능은 지원하지 않습니다. 소재를 다시 ON하려면 해당 매체에서 직접 세팅 변경을 해야 합니다.

💡 소재 효율성 기능 잘 활용하기
동일한 캠페인이나 소재더라도, 분석 대상 지표(목표)를 다양하게 설정해서 비교하며 운영해보세요. 지표에 따라 동일한 소재라도 다른 분석 결과가 나올 수 있습니다. (예: '클릭 목표에 효율적인 소재' VS '전환 목표에 효율적인 소재' 비교)

### 서비스 도입 관련 FAQ

**Q. 도입 프로세스가 궁금합니다.**
회원가입 후, 원플로우를 통해 애드써클 생성부터 데이터 연동, 유닛 설정, 그리고 플랜 설정까지 한 번에 진행하실 수 있습니다.

**Q. 다른 입찰 솔루션과 차이점은 무엇인가요?**
MOP는 AI와 수리 최적화를 활용한 지능화된 광고 운영 자동 최적화 솔루션입니다. Rule-base가 아닌 자체 최적화 알고리즘에 기반해, 예산 배분 및 입찰 계획을 수립하고 운영합니다.

**Q. MOP Basic과 PRO의 차이점은 무엇인가요?**
Basic 버전 대비 성능이 업데이트되고, 다양한 기능이 추가된 MOP PRO 버전이 출시되었습니다. 입찰최적화를 포함한 주요 분석을 진행하는 MOP의 알고리즘 성능이 기존 대비 업그레이드되었으며, 프로모션 등 마케팅 플랜에 맞게 최적화 알고리즘을 컨트롤 할 수 있는 기능을 오픈했습니다.

**Q. MOP를 이용하기 위한 서비스 비용이 있나요?**
MOP 서비스는 MOP Basic과 MOP Lite/Pro로 구분됩니다. MOP Basic에서 제공되는 서비스는 모두 무료로 이용할 수 있으며, 유료 서비스인 PRO 관련 내용은 가격안내 페이지에서 확인 가능합니다.

**Q. MOP 도입 시 제한이 있는 업종이 있나요?**
매체에서 운영 가능한 업종은 제한 없이 모두 MOP 도입이 가능합니다. 모든 광고주/광고대행사/미디어렙이 이용할 수 있으며, 광고 실적 데이터는 모두 독립적으로 관리됩니다.

**Q. MOP 적용 대상이 되는 광고의 최소 광고비 및 전환 수 조건이 있나요?**
- 하루 예산 최소 1만원 이상(VAT 별도)인 광고 건에 대해서 적용 가능합니다.
- 전환 최적화의 경우 하루 기준 전환 1건 이상 발생해야 전환 최적화 알고리즘이 원활하게 작동합니다. 전환 수가 이보다 적은 경우에는 적용은 가능하나, 클릭 최적화와 유사한 방향으로 운영됩니다.
- 발생하는 데이터가 너무 적은 경우 ML 모델 생성이 어려워 최적화 효과가 떨어질 수 있습니다.

**Q. MOP에 적용할 수 있는 광고 계정 수나 데이터 양에 제한이 있나요?**
애드써클 내 생성 가능한 유닛의 광고 수와 계정 수는 구독 플랜마다 상이하며 상세 내용은 유닛설정하기 문서에서 확인 가능합니다.

**Q. 자체 개발한 전환 툴을 사용 하는데 MOP 서비스를 이용할 수 있나요?**
현재 MOP에서 선택 가능한 전환 값은 전환 값 설정 방법에서 확인할 수 있습니다. 이 외에 사용하고 계시는 별도 전환 툴은 별도 유료 서비스 API-IN 기능을 통해 MOP에 연동 가능합니다.

**Q. MOP를 사용하기 위해 별도 Script를 심어야 하나요?**
Script나 Tag 삽입 등의 기술적인 사전 작업은 없으며, 각 매체의 API 연동을 통해 바로 사용할 수 있습니다.

**Q. MOP 도입에 소요되는 시간은 어떻게 되나요?**
회원가입 및 로그인 → 데이터 연동 → 애드 써클 생성 순서로 진행됩니다. 데이터 연동 과정에서 MOP 적재까지 약 5~7 영업일 정도 소요됩니다. 성과분석 툴 연동 시 UTM 수정이 필요한 경우에는 안내 드리는 일정보다 더 소요될 수 있습니다.

**Q. MOP 데모 계정을 발급 받을 수 있나요?**
별도의 데모 계정은 없습니다. 실제 운영이 필요한 경우에 한해 MOP 계정을 등록 후 사용할 수 있습니다.

**Q. MOP 적용 후 최적화 되는데 소요되는 시간이 얼마나 되나요?**
최적화 아이템 신규 생성 후 최적화가 진행되는 데 약 1~2주 정도의 학습 기간이 필요합니다. 초기 Off는 권장하지 않으며, 학습하는 데이터의 양이 늘어날수록 점진적으로 최적화가 진행됩니다.

**Q. MOP 도입 후 온보딩을 위한 서비스가 있나요?**
계정 연동이 완료되면, 담당 컨설턴트가 셋팅 및 이용 방법에 대한 온보딩 교육을 약 2주간 진행합니다. 일정에 맞춰 화상 미팅을 통해 진행하며, 필요 시 대면 미팅도 함께 진행합니다. (*전담 어카운트 매니저 배정은 PRO에 한해 제공됩니다.)

**Q. MOP 도입 후 이용 방법에 대한 문의나 궁금한 점은 어떻게 문의하나요?**
mop_support@lgcns.com 메일 또는 홈페이지 우측 하단 채널톡을 통해 연락 주시면 신속히 처리해 드립니다.

### 솔루션 비용 관련 FAQ

**Q. MOP Pro는 월 단위로 구독하는 서비스인가요?**
MOP는 월 단위 구독 서비스로, 매월 결제가 발생합니다. 구독료와 관련한 상세 내용은 도입문의를 통해 문의해주세요.

**Q. MOP Pro는 광고 단위로 적용되나요?**
MOP Pro는 애드써클 단위로 적용됩니다. *애드써클이란 일반적으로 한 광고주가 진행하는 여러 광고매체를 하나로 모은 개념으로, 한 광고주가 한 개의 애드써클을 가지고 있는 것이 일반적입니다. 단, 광고대행사와 같이 여러 광고주의 광고를 운영하고 있다면 여러 애드써클을 가지고 있을 수 있고, 이 경우 각 애드써클별로 MOP Pro를 적용할 수 있습니다.

**Q. MOP Pro를 카드로 결제 가능한가요?**
국내카드, 카카오페이, 네이버페이 결제수단을 지원하고 있습니다.

### 계정 생성 관련 FAQ

**Q. MOP 계정은 어떻게 생성하나요?**
회원가입(MOP 메인>우측 상단>로그인)을 진행해주세요. *데모가 필요한 경우 MOP 도입문의 작성해주시면 됩니다.

**Q. 생성할 수 있는 계정 수에 제한이 있나요?**
발급할 수 있는 계정 수에 제한은 없습니다. 단, 광고별 관리자(Administrator) 권한은 반드시 1명이 존재해야 하며, 그 외 계정은 운영자(Operator) 또는 보기사용자(Viewer) 권한 중 선택하여 부여할 수 있습니다.

**Q. 관리자 계정(MCC 계정)이 있나요?**
각 서클(Circle)은 독립적으로 운영되기 때문에 관리자 계정은 별도로 존재하지 않습니다. 그러나 하나의 MOP 계정에서 전체 데이터를 연동하고 애드써클/유닛 생성을 하면 관리자 계정 형태로 활용하실 수 있습니다.

**Q. 권한을 추가, 수정, 삭제할 수 있나요?**
권한 수정/삭제는 관리자 권한으로 로그인 하신 뒤, [설정 > 애드써클 생성] 메뉴에서 애드써클 별로 설정 가능합니다.

**Q. 계정 비밀번호, 이메일 수신 설정을 변경하고 싶어요.**
프로필 수정, 비밀번호 변경, 이메일 수신 설정은 MOP 메인>우측 상단 사람 모양 아이콘>계정관리 메뉴에서 수정 가능. 비밀번호 재설정은 로그인 화면의 비밀번호 찾기를 통해 진행 가능.

### 데이터 연동 관련 FAQ

**Q. 1개의 애드 써클(Ad Circle)에 한 매체의 여러 계정과 여러 성과 분석 툴을 동시에 사용할 수 있나요?**
애드써클은 매체의 캠페인과 성과 분석 툴을 맵핑해둔 유닛(Unit)의 조합입니다. 유저의 편의에 따라 하나의 써클에 각 매체의 여러 계정과 여러 성과 분석 툴을 동시에 사용할 수 있습니다.

**Q. 유닛(Unit)을 추가/수정/삭제할 수 있나요?**
[설정 > 애드써클 생성] 메뉴에서 '유닛' 영역을 클릭하시면 추가/수정/삭제 가능합니다. 단, 유닛 수정은 기존의 유닛을 삭제하고 신규로 등록하는 개념으로, 재등록 시 변경한 기준에 맞춰 머신러닝이 다시 진행됩니다. (3~5일 소요)

**Q. UTM 설정은 왜 해야 하나요? 반드시 해야 하나요?**
MOP는 키워드 단위/소재 단위로 실적을 트래킹할 수 있는 구조의 UTM이 필요하며, 최적화에 필요한 데이터를 수집할 수 있도록 각 값들이 UTM 안에 존재하는 것이 중요합니다. GA4, 에어브릿지, 앱스플라이어를 성과 분석 툴로 설정하는 경우에만 해당하며, 매체 성과 분석 툴을 사용하는 경우 설정하지 않아도 됩니다.

**Q. 최적화 대상인 캠페인이 아닌데 유닛(Unit) 설정을 해야 하나요?**
최적화를 하지 않더라도 Budget Opt나 Report와 같은 MOP의 다른 메뉴를 이용하고 싶은 캠페인이 있다면 유닛 설정을 해야 합니다.

**Q. 유닛(Unit) 설정에 따라 리포트의 전환 값이 달라지나요?**
유닛으로 설정된 전환 값을 기준으로 모든 서비스가 제공됩니다. 각 유닛이 다른 성과 분석 툴이나 다른 전환 값을 가지고 있다면 Report에 출력되는 전환 값의 Scale이 맞지 않을 수 있습니다.

**Q. MOP를 사용하면서 수동 예산 관리나 입찰을 동시에 진행해도 되나요?**
캠페인/애드그룹 예산 제한이나, 수동 입찰 모두 권장 드리지 않습니다. 단, 일 예산 Limit이 있는 경우에는 매체 상에서 캠페인에 Cap을 설정해 주시는 것이 좋습니다. (애드그룹의 Cap은 설정하지 않는 것을 권장) 수동 입찰 관리가 필요한 키워드가 있다면 MOP에서 입찰 제외 키워드로 등록한 후 직접 관리해 주시면 됩니다.

**Q. 기존에 사용하던 입찰 솔루션이 있습니다. 동시에 사용해도 되나요?**
MOP를 적용하실 때에는 기존 운영하던 입찰 솔루션은 모두 중지해야 MOP 최적화 알고리즘의 효율성이 극대화됩니다. 특히 검색광고의 경우 순위 유지를 위한 자동화 기능은 모두 중지해주셔야 합니다.

**Q. API 정보 재확인 요청 메일이 왔어요. 어떻게 해결하나요?**
우측 상단 Setting 메뉴 선택 후 데이터 연동 메뉴를 클릭합니다. 비고란에 "API 에러"를 클릭하면 API 정보를 수정할 수 있는 팝업이 나타납니다. 해당 팝업에 올바른 엑세스라이선스 및 비밀키를 입력하고 'SAVE' 버튼을 클릭하세요.

**Q. 데이터 연동 시 이미 연동된 계정이라는 문구가 뜹니다.**
해당 데이터 연동 정보는 과거 MOP로 연동된 계정으로, <관리자 이관 동의서>를 작성 후 제출해 주시면 이관 작업 후 메일로 회신드립니다.

### 최적화 아이템 에러 메시지 발생 시

**Q. 최적화 아이템 설정 시 에러 메세지 발생 시 해결하기 (입찰 기간 중복)**
SAVE를 하면 '선택하신 캠페인/애드그룹이 다른 최적화 아이템의 입찰 기간에 중복 선택되어 있습니다.' 문구가 노출됩니다.
기존 최적화 아이템의 종료일을 당일로 선택 후 저장해 주시고, 신규 최적화 아이템의 입찰 시작일을 익일 이후로 설정해 주시면 됩니다.
1. 기존 최적화 아이템 자동입찰 OFF (토글 변경)
2. 최적화 아이템 수정 버튼 클릭
3. 수정 창에서 입찰기간의 [종료일]을 당일로 설정하고 SAVE
4. 신규 생성 버튼을 눌러 새롭게 시작하고 싶은 최적화 캠페인/그룹 선택하여 신규 아이템 생성
💡 1. 당일로 변경된 아이템 및 다음날부터 세팅된 신규 아이템을 모두 자동 입찰 ON 하면 끊김 없이 진행됩니다. 2. 최적화 아이템 복사버튼(최적화ID 옆)으로 기존 셋팅을 복사할 수 있습니다.

**Q. 검수 에러 메세지 발생 시 해결하기**
- 최근 3일간 광고 소진 비용이 없거나 광고 실적 데이터가 없는 경우 발생. 해당 최적화 아이템을 Off하고, 데이터 미발생 원인 해결 후 3일 이상 수동 운영 후 재검수하면 최적화 재진행 가능.
- 선택한 캠페인/애드그룹 내 클릭이 발생하는 키워드가 없거나 일 소진 비용이 100원 이하로 매우 적은 경우 발생.
- 선택한 캠페인/애드그룹 내 클릭 발생 키워드가 있으나, 해당 키워드가 랭크 타겟(Rank Target)에 셋팅되어 최적화 알고리즘 관리 대상이 없는 경우에도 발생 가능.

**Q. 최적화 에러 메세지 발생 시 해결하기**
최근 3일간 광고 소진 비용이 없거나 광고 실적 데이터가 없는 경우 발생. 해당하는 최적화 아이템을 Off하고, 데이터 미발생 원인 해결 후 3일 이상 수동 운영 후 재검수 시 최적화 재진행 가능.

**Q. 입찰 에러 메세지 발생 시 해결하기**
기존에는 있었으나 당일은 입찰 대상이 될 키워드/소재가 존재하지 않아 발생할 수 있음(전일 대비 삭제된 키워드/소재 확인). 삭제된 키워드/소재는 입찰이 이루어지지 않고 그 외는 입찰 진행. 반영 시점은 요금제 별로 상이:
[표: 광고 매체 데이터 업데이트 주기]
| 구분 | 업데이트 주기 |
|---|---|
| MOP Basic/Lite | 매일 |
| MOP Pro | 매시간 |
빈번히 키워드/소재 삭제가 발생하면 입찰 에러가 지속적으로 나타날 수 있음. ⚠ 빈번한 키워드/소재 변경은 머신러닝에 효과적이지 않으므로 권장하지 않습니다.

**Q. 입찰 에러 메세지 발생 시 해결하기 (API ERROR)**
연동 API 정보 변경 시 ERROR가 발생할 수 있으며, [입찰에러]로 표시됩니다.
1. Bid Opt 메뉴에서 [입찰 에러] 발생 시 [설정 > 데이터 연동] 확인.
2. 비고사항에 [API에러] 메세지 확인. (API에러란: 네이버에서 API정보가 변경되어 데이터 연동이 해제된 상태)
3. 네이버 검색광고시스템 상단 [도구] > [API 사용 관리] 접속.
4. [CUSTOMER_ID], [액세스라이선스], [비밀키] 확인.
5. [API에러] 버튼 클릭 → '엑세스라이선스', '비밀키' 입력 → SAVE로 재연동.
💡 1. [API에러] 발생 시 정상적으로 입찰이 이루어지지 않습니다. 2. 새 API 정보 입력 시 1시간 이후부터 재연동됩니다. 3. 재연동 시 기존 입찰 계획대로 입찰이 이루어지며 [입찰에러] 메세지가 표시되지 않습니다.

**Q. 예산 부족/과다 메시지 발생 시 해결하기**
적정 예산 확인을 위해 Insight > Budget sensitivity를 활용하여 원하는 목표 기준 적정 예산 적용 여부를 확인합니다.
- 예산 과다 발생 시: 예산 내 최대한의 정량(클릭, 전환 등) 확보를 위해 예산 배분·입찰 진행. 잠재 가치 있는 키워드/소재까지 예산 배분되어 기존 대비 CPC, CPA, ROAS 효율이 낮아질 수 있음. 공격적인 유입/전환 확보가 필요한 시즌에는 예산 과다 수준의 투입 권장.
- 예산 부족 발생 시: 성과가 발생하는 주요 키워드에만 예산 배분·입찰이 집중되고, 기여도 낮은 키워드는 낮은 순위로 입찰. 비용 효율 지표는 상향되나 확보 가능한 정량(클릭, 전환 등)을 놓치므로 하루 예산을 높이는 것을 권장.

### 최적화 아이템 수정,복사하기

**Q. 최적화 아이템내 특정 그룹 or 캠페인 제외,추가**
현재 운영중이던 최적화 아이템에서 특정 그룹이나 캠페인을 제외하여 자동입찰 운영을 하고 싶을 때:
1. 기존 최적화 아이템 자동입찰 OFF
2. 최적화 아이템 수정 버튼 클릭
3. 수정 창에서 입찰기간의 [종료일]을 당일로 설정하고 SAVE
4. 신규 생성 버튼으로 새 캠페인/그룹 선택하여 아이템 생성
💡 1. 당일 변경 아이템+신규 아이템 모두 자동입찰 ON 하면 끊김 없이 진행. 2. 최적화 아이템 복사버튼(최적화ID 옆)으로 기존 셋팅 복사 가능.

**Q. 최적화 아이템 복사하기**

💡 최적화 목표 및 캠페인/애드그룹을 수정, 추가할 때 사용해보세요!
1. 입찰 최적화 메뉴의 최적화 아이템에서 최적화ID 옆의 복사 아이콘을 클릭합니다.
2. 선택한 최적화 아이템의 설정 내역이 동일하게 복사됩니다.
3. 입찰기간, 캠페인/애드그룹 리스트, 최적화명, 하루예산, 최적화 목표 등을 쉽게 변경 가능.

### 예산 소진 문제 발생 시

**Q. 예산 과소진 발생 시**
- 매체에 셋팅한 캠페인/애드그룹의 하루 예산 Cap보다 MOP에 셋팅한 하루 예산이 높은지 확인. MOP는 주어진 예산 하에 가장 많은 정량을 확보하려 작동하므로, MOP 셋팅 예산이 높으면 매체 셋팅 예산보다 더 공격적으로 입찰하여 빠르게 소진될 수 있음.
- 24시간 Always-on으로 광고가 집행되고 있는지 확인. 광고비 부족으로 중간에 광고가 Off되는 현상이 반복되면 전환 발생 시점을 정확히 학습할 수 없어 예측이 어려워짐.

**Q. 예산 미소진 발생 시**
MOP에 하루 예산을 충분히 셋팅하여도, 동일한 전환량이 예상된다면 더 많은 비용을 집행하지 않습니다. MOP 알고리즘은 동일 전환을 발생시키기 위해 광고비를 강제로 더 소진할 수 없습니다.
단, 더 높은 순위와 노출량을 확보하고 싶은 경우 최적화 아이템 셋팅 화면에서 Impression Boosting 기능을 이용해 전체 키워드의 순위를 상향할 수 있습니다. 이 경우 평균 CTR이 높아져 광고비 소진 금액이 높아질 수 있으므로 하루 예산을 충분히 셋팅하고 필요한 시점에 일시적으로 사용하는 것을 권장.

### 효율 문제 발생 시

**Q. 지속적인 비용 효율 지표 하락 시**
MOP는 주어진 예산 하에 가장 많은 정량을 확보하기 위해 작동하므로, MOP에 셋팅된 예산이 높은 경우 공격적으로 입찰을 진행하여 비용 효율 지표가 하락할 수 있습니다.
- 셋팅한 하루 예산이 과다하지 않은지 확인. 최근 7일 평균 소진 비용 입력 권장, [예산 민감도] 활용해 적정 예산 확인.
- 매체 셋팅한 캠페인/애드그룹의 하루 예산 Cap보다 MOP에 셋팅한 하루 예산이 높은지 확인.

### 랭크 타겟(Rank Target) 문제 발생 시

**Q. 설정한 순위를 반드시 유지해야 하는데, 빈번하게 아래 순위에 노출되는 경우**
MOP의 Rank Target은 5분 단위로 목표 순위를 유지하지만, 모니터링 리포트는 매 시간 기준 임의의 지역에서 노출된 순위를 체크하여 보여주므로 실시간 노출 순위와 다르게 확인될 수 있습니다.
MOP의 Rank Target은 목표 순위와 한 단계 낮은 순위를 5분 단위로 움직이며 비용 효율을 확보하는 모듈입니다. (예: 2위 목표 시 2위~3위를 5분 단위로 움직임) 따라서 1순위를 반드시 유지하거나 경쟁사 대비 항상 높은 순위를 유지해야 하는 경우처럼 비용 효율과 무관하게 순위 유지가 되어야 하는 경우 MOP의 Rank Target은 적절하지 않습니다.

**Q. 설정한 랭크 타겟에 도달했는데, 계속 Max CPC에 도달하는 경우**
설정한 값에 문제가 없는지 우선 확인합니다. 특히 키워드 ID의 Device Type을 잘못 설정한 경우 실제 노출된 광고를 확인할 수 없어 Max CPC까지 입찰가를 상승시킬 수 있습니다.

**Q. Max CPC를 수정했는데, 대시보드에 계속 알람이 발생하는 경우**
최근 1시간 내 Max CPC에 도달한 이력이 있으면 알람이 발생하도록 설정되어 있습니다. 이상이 없다면 한 시간 뒤 재모니터링 시점에 사라집니다.

### 제외 키워드/소재 설정 필요 시

**Q. 쇼핑검색광고 최적화 아이템 내 소재의 입찰 제외가 필요한 경우**
입찰최적화 세팅 화면 내 입찰 제외 소재 설정(옵션)을 통해 소재 제외가 가능합니다. *제외 대상 소재명 혼동 방지를 위해 소재 ID로 검색하는 것을 권장.

**Q. 쇼핑검색광고 최적화 아이템 내 서치키워드의 입찰 제외가 필요한 경우**
PRO 플랜을 사용하실 경우 가능합니다. (※ BASIC, LITE 미제공) 세팅한 소재 단위로 노출을 원하지 않는 검색어를 제외 설정하여 광고 효율을 개선할 수 있습니다. MOP에서 제외 키워드로 설정 시, 네이버 광고 플랫폼에도 자동 반영됩니다.
⚙️ 제외 키워드 설정하기: 각 최적화 아이템 리스트 우측의 '제외 키워드' 아이콘을 클릭하여 소재 단위로 노출을 원하지 않는 키워드를 제외 가능. 키워드 효율성 분석 결과 및 Efficiency 컬럼을 확인하여 제외 설정(최근 2주 실적 기반 매일 업데이트). 검수중/검수에러 상태에서는 설정 불가. 소재 단위로 추가/제외 가능, 설정 시 자동 매체 연동.
⚠️ MOP의 제외키워드는 소재 단위로 설정하기 때문에, 최대 70개까지 설정 가능합니다. 광고그룹 기준으로 설정하려면 매체에서 진행.

**Q. 검색광고 최적화 아이템 내 키워드의 입찰 제외가 필요한 경우**
입찰최적화 세팅 화면 내 입찰 제외 키워드 설정(옵션)을 통해 키워드 제외가 가능합니다.

### 알고리즘 수행 에러

**A. 검수 에러/최적화 에러**

**A-1. 광고 집행 기간이 부족한 경우 (Bid, Budget Opt)**
✔ 광고 실적 예측을 위해서는, 최근 14일 데이터 기준으로 최근 3일을 포함하여 총 최소 11일 이상의 데이터가 존재해야 합니다.
- (1) 유닛 상태 확인: 📍설정 > 애드써클 생성 메뉴에서 애드써클명을 클릭 후 각 유닛의 검수 상태 확인. 운영 일수 부족 시 비고에 "운영 기간 부족"으로 노출.
- (2) 실적 데이터 확인: 매체 또는 MOP의 Report에서 실제 실적 발생 기간 확인. 최근 2주 내 최근 3일 데이터 포함 총 최소 11일 이상 데이터 존재 확인.
💡 운영 기간 조건이 충족되면 자동으로 모델 학습이 진행됩니다. (학습 주기는 요금제 별 상이: Basic=2주, Pro=매주) 📍설정 > 애드써클 생성 메뉴에서 유닛 별 상태 재확인 후 최적화 세팅 진행.

**A-2. 최근 3일 기준 클릭 실적이 미발생한 경우 (Bid, Budget Opt)**
✔ 14일 이상 운영된 캠페인/광고그룹이더라도 최근 3일간 클릭 실적이 발생하지 않으면 에러 발생 가능.
- (1) 실적 데이터 확인: 매체 또는 MOP 리포트에서 최근 3일간 클릭 실적 존재 여부 확인.
- ✅ 최적화 입찰 수행: 최대 3일까지는 클릭이 발생하지 않아도 기 학습된 데이터를 바탕으로 최적화 입찰 적용 가능.
- ✅ 에러 노출 상태: 클릭 실적이 발생하여 예측/최적화 알고리즘이 수행되면 에러 표시는 자동 삭제.
- ✅ 광고 중단에 따른 최적화 설정 가능 여부: 4일 이상 광고 중단 시 일정 기간 수동 운영 후 최적화 입찰 진행 가능. 중단 기간에 따라 최대 14일 수동 운영 필요할 수 있음.

**A-3. 시간/요일 타겟팅이 설정된 경우 (Bid Opt)**
시간/요일 타겟팅이 설정되어 있으면 예측 모델이 생성되지 않습니다.
- (1) 유닛 상태 확인: 📍설정 > 애드써클 생성 메뉴에서 각 유닛의 검수 상태 확인. 시간/요일 타겟팅 설정 시 "스케줄 타겟팅"으로 노출.
- (2) 적용 기준 확인: 매체의 애드그룹 단위로 타겟팅 설정 여부 확인.
  [표]
  | 타겟팅 종류 | 적용 가능 기준 |
  |---|---|
  | 시간 타겟팅 | 일 20시간 이상 운영 시 적용 가능 |
  | 요일 타겟팅 | 주말 미운영 적용 가능 (토/일/토&일) |
💡 타겟팅 기준을 맞추면 자동으로 모델 학습이 진행됩니다. (학습 주기: Basic=2주, Pro=매주) 📍설정 > 애드써클 생성 메뉴에서 유닛 별 상태 재확인 후 최적화 세팅 진행.

**최적화 설정 화면 확인**
위의 최적화 에러 사유에 해당하는 경우, Bid/Budget Opt 설정 화면에서 캠페인 또는 애드그룹명이 붉은색으로 표시됩니다.
- (1) 캠페인/애드그룹 상태: 이미 최적화에 포함되어 있는 캠페인/애드그룹이더라도 ✔ 광고 일시 중단, 타겟팅 추가 설정 등으로 운영 상태가 변경되면 붉은색으로 표시되고, 최적화 입찰이 진행되지 않을 수 있음.
- (2) Bid Opt (SA, SPA): ✔ 최적화 아이템에 여러 개의 캠페인/애드그룹이 함께 클러스터링된 경우 최적화 가능한 항목에 대해서만 입찰이 진행됩니다.

**B. 입찰 에러**

**B-1. API 연동 에러가 발생한 경우 (Bid Opt)**
매체에서 입찰가 변경 권한이 해제된 경우 발생. API 정보 변경 또는 MOP 연동 광고 계정의 권한 삭제 여부 확인 필요.
- (1) 네이버(NAVER): [펼친 토글] 📍설정 > 데이터 연동 메뉴에서 업데이트를 진행해 주세요.
- (2) 카카오(kakao): 카카오모먼트 📍광고 > 키워드광고에서 해당 계정 권한이 정상적으로 부여되어 있는지 확인.
💡 매체 연동 이슈로 인한 입찰 에러의 경우, 재연동 전까지는 전체 키워드/소재에 대한 입찰가를 변경할 수 없습니다. ✔️ 광고 계정 피이관으로 인한 연동 오류 상태라면 매체 연동 해제도 가능(📍설정 > 데이터 연동 메뉴에서 매체 별로 연동 해제 가능).

**B-2. 키워드 또는 소재가 삭제된 경우 (Bid Opt)**
키워드 또는 소재를 삭제한 경우에도 입찰에러로 표시될 수 있습니다. 삭제한 항목을 제외한 나머지 키워드/소재는 정상적으로 입찰이 진행됩니다.
- (1) 삭제 여부 확인: 각 매체의 이력 관리 메뉴에서 키워드/소재 삭제 여부 확인 가능 (NAVER / KAKAO 화면 예시).
- (2) 최적화 입찰 적용: 삭제된 키워드/소재가 있다면 이후 입찰부터 반영, 반영 시점은 요금제 별 상이. 추가 삭제가 없으면 다음 시간 그룹에 에러 표시도 사라짐.
