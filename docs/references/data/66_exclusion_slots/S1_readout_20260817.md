- ★**이것이 ⓔ 수리의 순서를 바꾼다**: `674`줄의 옛 전제를 걷어도 **상류가 0을 내면 후보는 여전히 0**이다. ref 65 S1 합격기준 ⑤(「쇼핑 제외 후보가 pending으로 ≥1건 생성」)는 674줄만 고쳐서는 달성되지 않을 수 있다 → **상류 0의 원인 규명이 ⓔ에 선행**한다.
- 좌표: `search_term_ss_lane.py:784-797`(diary 브리핑 블록) · `search_term_judge.py:180-186`(상류 grain) · DB: `ops_diary_entries`·`naver_proposals`. ~~prod 로그 `[스케줄러] naver 검색어 제외: shopping=0`~~ = **재현 실패, 미확인 좌표**.

### 3-2. 부수 발견 2 — 죽은 것은 모듈이 아니라 함수다

`hierarchical_pooling.shrink`는 `probe_cell_aggregate.py:27`에서 **실제로 소비된다.** 「모듈이 죽었다」가 아니라 **`pool_all`만** 죽었다 — ⓑ 배선의 범위가 함수 단위로 좁혀진다.
