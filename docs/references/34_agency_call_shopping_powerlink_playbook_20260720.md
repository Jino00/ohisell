- 원인 판정: **쇼핑검색 입찰 순위 밀림**. 경쟁사(크리스탈 등)가 전환 키워드(폴드7 필름·지문방지 필름) 상위 독식 + 시장 입찰가 급등(1,200~1,300원대 → 2,000~2,300원대). 네이버 애드부스트(AI 매출업, 테스트 3만원) 사용자 맞춤 노출이 1~2등 상단을 차지하는 영향도 의심.

### C. 쇼핑검색 운영 방법론 (Jino 질문 → 대리 답)
1. **순위 사이클**: 한 순위 올려보고 → 판매·ROAS 확인 → 좋으면 유지/더 상향, 목표 ROAS 미달이면 한 단계 하향 → 회복하면 재상향. *"쇼검은 그 방법밖에 없다"* (그룹입찰=유일 레버).
2. **제외키워드 = 쇼검 최적화의 본체**:
   - 판정 기준 = **검색어(키워드)별 ROAS**. **100% 미만 = 무조건 제외**(경험상 끝까지 안 좋아짐). **100~200% = 여지** — 입찰 조정해보고 변화 없으면 제외.
   - **키워드별 실효입찰 분리 기법**: 쇼검은 키워드별 입찰이 없으므로, 캠페인 내 **전용 그룹을 만들고 제외키워드(그룹당 최대 140개)로 상위 검색어를 다 막아 특정 키워드만 나가게** 함 → 그 그룹의 입찰가가 사실상 그 키워드의 입찰가(예: 전체 1,300원 대신 "지문방지 필름"만 600~700원).
   - 단점: 그룹 수 폭발·관리 복잡 + **그룹/캠페인 생성 한도** 존재(통신사 광고주들은 계정을 3~4개 돌림). 사람이 하나하나 하기엔 한계.
3. 전환 판정 창: 최근 30일 전환 키워드를 봄(하루 단위 컷 아님).

### D. 파워링크 운영 방법론
- **키워드 + 소재(문구·이미지) 싸움**. 키워드는 지속 발굴 + 네이버 **확장(확장소재) 기능이 미등록 연관 키워드를 노출**시켜줌 → 그 보고서에서 전환 신호 잡히면 키워드 등록·소재 추가로 대응(실사례: 확장소재에서 "사생활필름" 클릭 발생 → 소재 추가하기로).
- 순위 철학: **1~2등 무리 불필요** — 파워링크 클릭 후 쇼핑 가격비교로 이탈(이중클릭) 많음. **3등 안(첫 페이지)이면 전환 잘 됨**. 단 이미지형 확장소재는 사실상 1~2등에만 노출. 순위 밀리면 노출 자체 소멸 → 노출 순위 상시 체크 필수.
