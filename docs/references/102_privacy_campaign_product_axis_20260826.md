## §5. N배송 배송비 — **이미 정확히 반영돼 있다** (재확인)

### 공헌이익 산식도 정확하다
```
공헌이익 = (판매가 − 수수료 − 원가 − 물류비) ÷ 1.1        # ÷1.1 = VAT 포함가 → 공급가
```
검산: 폴드8 = (16,800 − 942 − 6,406 − 368) ÷ 1.1 = **8,257.7** ↔ 저장값 **8,257**.
★한때 「실효 수수료율이 10.5%인데 컬럼은 5.6%」로 보였던 것은 **부가세 826원을 수수료로 오독**한 것이다. 수수료율 5.61%가 맞고 **누락 없음**. 수수료도 계정 단일값이 아니라 `product_commission` SA의 상품별 실측 + N배송 프리미엄이다.
