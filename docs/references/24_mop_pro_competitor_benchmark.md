## 1. 정체 · 포지셔닝
- MOP = LG CNS의 AI 광고 운영 최적화 SaaS. "AI+알고리즘으로 광고 예산·입찰을 24시간 자동 운영".
- 연동 매체 5종: 네이버 · 카카오 · 구글 · 메타 · 크리테오.
- 핵심 3기능: ① SA 입찰최적화 ② SPA 입찰최적화 ③ Budget Opt(예산최적화) + 순위유지·인사이트·리포트·이상감지.
- **우리 네이버 SA 트랙과 정확히 같은 도메인의 직접 경쟁 제품.**

## 2. 계층 구조
```
광고주 (1:1) → 애드써클(Ad Circle) → 유닛(Unit)[N] → [매체계정 × 캠페인 × 전환툴 × 전환값]
```
- 애드써클 = 광고주 1명당 1개. 통화·권한·검수상태 경계. 상태: 유닛설정필요 → 검수중(3~5일) → 검수완료.
- 유닛 = MOP가 실제로 도는 최소 운영단위. 유닛마다 데이터적재·ML모델·최적화·리포트 생성.
- 전환값 = **최초 1회 확정, 최대 10개, 이후 변경 불가**(불변 제약).
- 권한: 관리자(써클당 1명) > 운영자 > 보기. Pro는 써클당 10명.

## 3. ★ 러닝 구조 — 4단 엔진 파이프라인 (라이브 실증)
```
① 데이터 수집 → ② 러닝 엔진(예측) → ③ 플래닝 엔진(입찰계획) → ④ 플라이트 입찰(집행)
```
라이브 증거(Basic 계정에서도 가동): "러닝 엔진 가동 중 · ML모델 40개 · 일일 예측모델 생성 · 플래닝 엔진 가동 중 · 플라이트 최근24시간 입찰/마지막·다음 입찰". Keywords 30,250 / Ad Groups 210 / Campaigns 8.
- **② 러닝**: 매일 ML 예측모델을 새로 생성해 성과 예측.
- **③ 플래닝**: 예측 → 키워드별 입찰가 계획 + ML 엔진 추천 상위 키워드.
- **④ 플라이트**: 계획을 시간대(0~20시 버킷)로 쪼개 실제 입찰 집행.

### 러닝 상세 (문서 근거)
| 항목 | 내용 |
|---|---|
| 학습 윈도우 | SPA "최근 2주 실적 → 매일 갱신". SA도 최근 14일 기반 |
| 진입 게이트 | "14일 중 80% 이상 운영 + 최근 3일 실적 + 하루 1건 이상 전환" |
| 폴백(Pro) | 게이트 미달·운영 2주 미만 → **네이버 추천 입찰가로 자동 운영** |
| 재검수 | 최근 3일 실적 없으면 에러 → OFF → 3일 이상 수동 운영 후 재검수 |
| 조정 주기(Pro) | 하루 5회+ **시간단위 주요소재 추가 조정** |
| 순위유지 주기 | 검색 5~20분, 쇼핑 2시간 (러닝 아닌 실시간 추종) |

## 4. 최적화 목표 방식
- **Target ROAS 수치 직접 입력 아님.** 방향 택1: 클릭/전환/ROAS(매출)/다중목표 극대화.
- 구조: **예산=제약, 목표=목적함수** ("예산 내 극대화"형).
- 사용자: 예산+목표방향+제외키워드만. 키워드 입찰가는 알고리즘 자동.
- 고급설정 Pro 6종: Avg CPC/CPA, Top Impression Boosting, Max CPC, Rank Boosting, Budget Boosting, CPC Rebooting.
- 순위유지(Rank Target): 별도 트랙. 목표순위+1단계를 5~20분 조정, Max CPC 상한 도달 시 순위 포기. 경쟁사 모니터링 Pro 10개.

## 5. 시장 신호 3종
| 신호 | 정의 | 방법 |
|---|---|---|
| 예산 민감도 | 증액 시 성과 상승 여부(한계효용 곡선) | 현재=100% 기준선, 우상향=여력/평탄=임계 |
| 경쟁 심화도(Pro) | 입찰경쟁·CPC 효율 | **DEA(자료포락분석) 0~1 상대효율 지수** |
| 예산 추세(Pacing) | 오늘/주/월 소진속도 | 노출·클릭·조회·전환·매출 통합예측, 영향도 3단계 |
- Budget Opt: 총예산 고정, **크로스미디어(네이버/카카오/구글/메타)+캠페인 간 재분배**. 제안·예측·시나리오 비교만(자동집행 X).

## 9. MOP Pro 강점 (우리가 겨눌 천장)
1. 완결형 4단 엔진 end-to-end 자동화(수집→러닝→플래닝→시간대별 플라이트 집행).
2. 크로스미디어 통합 예산 최적화(네이버+카카오+구글+메타 총예산 재분배).
3. 예산 민감도 한계효용 곡선 정량 제시.
4. DEA 상대효율 스코어링(경쟁심화도·소재효율).
5. 6개월 lookback non-last-click 기여도.
6. 운영 안전장치(warm-up 게이트, 3일 재검수, 과/미소진 방어).

## 10. MOP 한계 (우리 차별화 지점)
1. 최적화 리포트조차 "알고리즘이 무엇을 왜 조정했는지" 이력 미노출 — 성과 before/after만. **투명성·추적성 약함.**
2. Target ROAS 수치 직접 지정 불가 → 손익분기 RoAS 같은 정밀 타겟팅 어려움.
3. Budget Opt 등 제안만/자동집행 안 함.
4. 전환값 최초 1회 확정 후 변경 불가.
5. 구글/메타/크리테오 입찰최적화 미지원.
6. 러닝 게이트 미달 시 네이버 추천입찰가로 폴백(자체 학습 아님).
