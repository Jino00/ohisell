## 0. 종합 결론

2021~2026 constrained auto-bidding 연구는 USCB(KDD'21) 이후 **생성형(확산모델·Decision Transformer)으로 이동**했으나, 이들은 **임프레션 단위 대규모 궤적 데이터(AuctionNet 5억 건)를 전제**로 해 우리(D-1 키워드 일단위·롱테일 3만 키워드·순수 파이썬) 제약에서는 **직접 채택 불가, 개념 이식만 유효**하다.

가장 직접 적용 가능한 것은 역설적이게도 **네이버 자체 연구 GRM(KDD 2026)** — 정책 대신 **응답곡선(입찰배수→비용/가치 곡선)을 예측**하고, 예산·효율(ROAS) 제약을 **1차원 근 찾기 2번으로 해석 가능하게 동시 집행**하는 구조로, 우리 "예측→수리최적화→플라이트" 루프와 정확히 동형이다.

## 1. 검증된 논문 지도 (전 항목 3표 만장일치 통과)

### A. 생성형 auto-bidding 계보 (개념 이식만 — 직접 채택 보류)

| 논문 | 핵심 | 우리 적용 판정 |
|---|---|---|
| **AIGB/DiffBid** (Alibaba, KDD 2024, [arXiv:2405.16141](https://arxiv.org/abs/2405.16141)) | MDP 기반 RL의 마코프 가정이 장기·고랜덤 환경에서 불안정 → 조건부 확산모델로 리턴↔전체 입찰 궤적 상관을 직접 모델링(스텝별 오류 전파 회피). Alibaba 라이브 A/B GMV +2.81%, ROI +3.36% | ❌ 임프레션 단위 궤적 데이터 전제. 개념만: "스텝별 오류 전파 회피" |
| **GAS** (Kuaishou, [arXiv:2412.17018](https://arxiv.org/abs/2412.17018)) | 정책 재학습 없이 결정 시점 MCTS식 탐색+소형 크리틱으로 출력 정제. **DT/AIGB 계열의 약점 명시: 저품질 로그→조건신호와 행동가치 불일치, 다수파 선호 데이터→소수 광고주 일반화 실패** | ❌ 직접 채택 불가. **소규모 광고주 환경에 생성형이 취약하다는 근거**로 중요 |
| **GAVE** (SIGIR 2025, NeurIPS'24 AIGB 트랙 1위, [arXiv:2504.14587](https://arxiv.org/html/2504.14587v2)) | DT + CPA 페널티 점수 정렬 + 안정성 가중 탐색 + 학습형 가치함수. **정식화가 재사용 가치**: 예산=하드, CPA/ROAS=에피소드 종료 후에만 확정되므로 소프트 제약 → 점수 **S = min{(C/CPA)^γ, 1} × Σ가치** | 🔶 모델은 보류, **페널티 점수 공식은 순수 파이썬 한 줄로 이식 가능** (TOP5 ⑤) |
| **C2** (Kuaishou, [arXiv:2601.20257](https://arxiv.org/html/2601.20257v2)) | DT의 "최적·비최적 무차별 모방"을 Cross Learning Block+Constraint-aware Loss로 보완. AuctionNet에서 GAVE 대비 최대 +3.23% | ❌ 학습 데이터 5억+ 레코드·기간당 50만+ 임프레션. 이식 개념: "제약 위반 샘플에 손실 가중"뿐 |

### B. ★최우선 적용 후보 — 응답곡선 + 해석적 컨트롤러

**GRM (Generative Response Model — NAVER Corporation, KDD 2026, [arXiv:2605.27811](https://arxiv.org/html/2605.27811))**
- 정책(action)이 아니라 **환경 응답(response)을 학습**: 단일 입찰배수의 함수로 미래 트래픽량 + 호라이즌 누적 비용/가치 곡선을 예측.
- 제약 집행은 학습이 아닌 **분석적 컨트롤러**: 예산충족 배수 αB, 효율충족(CPA/ROAS) 배수 αC를 각각 **1차원 근 찾기(이분법)**로 구해 **min{αB, αC}를 집행**. 제약 위반 시 원인 추적 가능(어느 배수가 물렸는지).
- 우리 제약 4가지 전부 부합 + "예측→최적화" 2단 구조가 우리 forecast_engine→bid_simulator와 동형. **네이버 스스로 자기 플랫폼에서 검증한 방법론**이라는 점도 의미(같은 옥션 생태계).
- (주의: "순수 파이썬 구현 용이"는 논문 명시가 아닌 우리 추론 — 이분법 자체는 자명하게 가능.)

### C. 스파스 데이터(롱테일 3만 키워드) 해법

| 논문 | 핵심 | 판정 |
|---|---|---|
| **DHEB** (Adobe, AdKDD'18, [arXiv:1809.02213](https://arxiv.org/abs/1809.02213)) | 스폰서드 서치는 키워드 수준에서 극도 희소(x-희소 ~90%, y-희소 ~98%) → 계정→캠페인→광고그룹→키워드 계층에서 **경험적 베이즈 축소추정**(상위 노드에서 정보 차용, 계층은 데이터 주도 동적 결정) | ✅ **난이도 최저·즉시 적용**. 순수 통계·완전 해석가능. 우리 pooled_rpc가 이미 이 방향 — 전 지표(CTR/CVR/RPC)로 일반화. 2018년 논문이나 희소성은 시대 불변 |
| **EBaReT** (Kuaishou, WWW Companion 2025, [arXiv:2507.16186](https://arxiv.org/pdf/2507.16186)) | 희소 보상 환경에서 ①하루를 Bag(8 타임스텝)으로 나눠 총보상 재분배 ②**예산+RoS 제약 LP의 쌍대해로 이론적 최적입찰 도출: b = (1+αc·C)/(αb+αc) × v** (가치의 스칼라 배) ③전문가 궤적 PU 학습 | 🔶 학습 부분은 보류. **LP 쌍대 공식은 "예산·ROAS 제약 하 최적 입찰 = 가치 × 쌍대승수"라는 닫힌형 코어로 직접 이식** (TOP5 ③) |
| **Bayesian AdComB** (Operations Research Forum 2024, [Springer](https://link.springer.com/article/10.1007/s43069-024-00322-y)) | **키워드 단위 일별 입찰 세팅**(우리와 동일 케이던스): 입찰후보가별 전환·비용을 **분포로 예측**(베이지안 네트워크, 관측불가 검색량=잠재변수) → 예산 제약+입찰 상하한 하 전환 최대화 **정수계획**(Gurobi) | ✅ **구조적으로 우리 루프와 가장 가까운 공개 논문**. 한계: 단일목표(ROAS 제약 없음 — 우리가 추가해야), Gurobi→scipy/OR-tools 대체 필요. 난이도 낮음 |

### D. Bid landscape 예측 (판정: 우리는 필요성 낮음)

- **멀티슬롯 딥 랜드스케이프** (KDD 2023, [ACM](https://dl.acm.org/doi/10.1145/3580305.3599799)): 슬롯 간 상관 최초 모델링 — 한 키워드 옥션이 여러 순위를 채우는 네이버 SA와 개념 동형. **Transformer 랜드스케이프+콜드스타트** (IEEE Access 2024, [IEEE](https://ieeexplore.ieee.org/document/10418074/)): 비파라메트릭.
- **판정**: 둘 다 딥러닝+검열된 임프레션 데이터 전제 → 부적합. **우리는 네이버 견적 API가 실시간으로 입찰가→예상순위/클릭 곡선을 제공**하므로 "학습으로 곡선 추정"의 필요성 자체가 낮다 — **견적 API의 편향을 D-1 실적으로 보정**(estimate_calibrator가 이미 이 방향)하는 쪽이 실용적.

## 2. MOP를 뛰어넘기 위한 채택 우선순위 TOP 5 (검증 통과 권고)

| 순위 | 기법 | 난이도 | 내용 |
|---|---|---|---|
| **①** | **GRM식 응답곡선 + 분석적 min-pacing 컨트롤러** | 중 | 견적 API+D-1 실적으로 키워드/캠페인별 비용·가치 곡선 구성 → 예산 배수 αB, BEP-ROAS 배수 αC를 이분법으로 풀어 min{αB,αC} 집행. **MOP가 안 하는 "해석가능한 이중 제약 동시 집행"이 차별점** |
| **②** | **DHEB식 계층 EB 축소추정** | 하 | 3만 롱테일 키워드의 CTR/CVR/RPC를 계정→캠페인→광고그룹 계층 풀링 — keyword grain 예측의 원료 |
| **③** | **EBaReT의 LP 쌍대 최적입찰 구조** | 하 | b = 쌍대승수 × 가치 — 일별 수리최적화의 수학적 코어. 격자 전수탐색 대신 닫힌형·해석가능 |
| **④** | **Bayesian AdComB식 분포 예측 + 정수계획** (BEP-ROAS 제약 추가) | 중 | 점추정→분포로 바꿔 희소 키워드의 불확실성을 최적화에 직접 반영 |
| **⑤** | **GAVE 페널티 점수 S = min{(ROAS/BEP)^γ, 1} × 매출** | 하 | 제안 성적표·일별 목적함수로 채택 — **볼륨(매출)·효율(ROAS) 이중목표를 γ 다이얼 하나로 통일** (D-NAO-1 "한계 ROAS≥BEP×공격성"의 학술적 정식화) |

생성형(확산/DT) 계열 자체는 데이터 규모상 **채택 보류(워치리스트)** — AuctionNet(오픈소스 벤치마크)만 시뮬레이터 검증용으로 주시.

## 3. 검증 방법론 노트
- 모든 주장은 3표 적대적 검증(반박 시도)에서 **만장일치 통과한 것만** 채택. DHEB 인접 주장 1건("예측 대상 지표 목록")은 0-3 기각되어 제외.
- 성능 수치(GMV +2.81% 등)는 해당 기업 자기보고 A/B 결과임에 유의.
- arXiv 프리프린트(C2, GAS)는 피어리뷰 전 상태.
