- 판정 규약: down/pause correct = 사후 보정ROAS < BEP(계속 적자) / up correct = 사후 보정ROAS ≥ target(계속 건강). gray = BEP~target 사이. 보정계수·BEP/target은 각 as-of 시점 diagnosis 산출값.
- **핵심 비대칭: 적자 차단(down/pause) 신호는 강하고, 성장(up) 신호는 약하다.** 원인 = 소표본 ROAS 평균회귀(고ROAS 저클릭 타깃이 다음 창에서 주저앉음). starving_winners 29%가 전형.

### 1-c. 출혈 정량 (진짜 BEP 1.4758 기준 공헌이익 적자, 중복 제거)
- **유니크 적자 타깃 148개(그룹42+키워드106), 첫 flag 다음날~07-15(3~7일 창) 공헌이익 적자 합 = 502,587원**(그룹 234,437 + 키워드 268,150).
- 해석: 규칙이 지목한 자리에서 실제로 계속 새고 있던 돈. **"개입했으면 50만원 벌었다"가 아님** — down/pause는 절감과 동시에 매출도 줄이므로 회수율은 그 일부(회수율 추정은 Layer 3/카나리 몫). 신호가 허수 아님을 보여주는 규모 지표.

### 1-d. flip-flop·안정성
- down↔up 보드를 오간 타깃 36개 — 대부분 as-of 07-08(이력 4일뿐)에서 bep로 찍혔다가 이후 growth로 이동. **짧은 윈도우가 판정을 뒤집는다** → 이력 N일 미만이면 실행형 제안 억제하는 "최소 윈도우 가드" 후속 후보.
- 5일 연속 flag된 안정 타깃 463개 — 신호의 코어는 안정적.

## 3. 종합 답 (Jino 질문에 대한)
1. **적자 차단 규칙(bid_down·pause)을 과거에 실행했다면**: 신호 정밀도 61~88%(지속성 필터 시 상단), 지목 자리 실출혈 ~50만원/주 규모 — 방향은 맞고 돈이 걸려 있었다. 04 pending(840 등) 승인·카나리가 이 신호의 인과 검증 다음 스텝.
2. **성장 규칙(bid_up)을 과거에 실행했다면**: 신호 단독 정밀도 29~60%로 위험 — 현행 파이프라인이 sim/풀링/가드레일로 보수 판정하는 것이 옳았음을 실증. 성장은 "밴드 2.5~4 타깃 + 지속성 + 풀링" 3중이 필요.
3. **페이싱**: 저속 경보는 신뢰 가능(98.7%), 저소진은 실재 → 성장 여력의 근거. 과속 경보는 현재 무가치(전오탐).
4. **리플레이 인프라 자산화**: 상세 데이터가 매일 +1일 쌓임(지금 12일 → 1개월 뒤 40일). as-of 관통(코드의 kst_today 하드콜 8곳 수술)을 하면 이 채점을 매일 자동 성적표로 돌릴 수 있음(Layer 2 스프린트 후보).
