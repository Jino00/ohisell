## §0. 네 문장 요약

1. **「수요가 말라간다」는 틀렸다** — 노출은 −95.6%인데 **CTR은 오히려 올랐고**(1.73%→2.58%) **평균순위는 2.74→6.84위로 밀렸다.** 수요가 줄면 경쟁이 줄어 순위는 좋아져야 한다. 우리가 자리를 잃은 것이다.
2. **이 그룹은 캠페인에서 가장 좋은 그룹이다** — CTR 2.58%는 형제 8그룹 평균(0.77%)의 **3.3배**다. 그리고 **형제들은 안 무너졌다**(−33%). 카나리 하나만 −95.6%다.
3. **그런데 지금 입찰을 올릴 여지가 거의 없다** — 상품 단위 BEP(**1.9757**, 원장 실재)로 계산한 손익분기 CPC가 **666~1,073원**인데 현재 CPC가 **876원**이다. 8월 중순의 1,400원대는 **어느 자로 봐도 적자**였다.
4. **연료는 가격에 있다** — 광고 상품을 16,800→19,900원으로 올리면 공헌이익 8,503→**12,271원(+44.3%)**, 감당 CPC **961~1,548원**. ⚠️**단 Jino가 2026-08-30에 올린 5개 상품에 이 상품은 포함되지 않았다**(다른 상품이다).

## §2. 소재 입찰가는 원장에 «있다» — 그리고 08-24에 바뀌었다

★**이 세션의 초판 주장 「소재 입찰가는 우리 원장에 없다」는 틀렸다.** `naver_adgroup_product`에 실재한다:

```
ad_id              nad-a001-02-000000554755092
ad_bid_amt         810          ← 실제 CPC 876원과 거의 일치
use_group_bid_amt  0            ← 그룹 입찰 미사용, 소재 개별 입찰
ad_edit_tm         2026-08-24T08:56:01Z = 17:56 KST
mall_product_id    13661073010
```

`naver_entity`에는 광고그룹 1,017·캠페인 46·키워드 91,172만 있고 **소재(ad) 엔티티는 0건**이라 거기만 보면 「없다」로 읽힌다 — **테이블이 다르다.**

★**누가 08-24에 내렸는지는 모른다.** 이 그룹·이 그룹 소속 엔티티에 대한 `external_*` 변경 기록은 **0건**인데, **그 0은 「없다」가 아니라 「안 보인다」다** — 외부변경 감지가 키워드 단위인데 쇼핑엔 키워드가 원리적으로 없다(D-NAO-255, n=52 *"「외부변경 0건인 쇼핑 13캠페인」은 깨끗함의 증거가 아니라 안 보인다는 뜻일 수 있다"*). 같은 캠페인의 08-21 135건·08-25 110건 대량 입찰 변경은 **다른(파워링크 성격) 그룹 것**이다.
★어느 쪽이든 **08-28 스코프 지정 이후는 우리 관할**이다(Jino 지적).

## §3. 이익이 나는 조건 — 상품 단위 BEP로 다시 잰다

★★**계정 블렌디드 BEP(1.711)를 쓸 필요가 없었다.** `naver_product_bep`에 이 상품이 있다(계산 2026-08-30 07:30):

**진짜 손익분기 CPC** = 공헌이익 × CVR × 보정계수 (보정계수 구간 = 북극성 §3의 [0.827, 1.3318])

|---|---|
| 공헌이익 | 8,503.32원 |
| CVR (5주 실측) | 9.47% (클릭 2,365 · 전환 224) |
| **손익분기 CPC** | **666원(하한 자) ~ 1,073원(상한 자)** |

## §6. [미상] · 이 문서가 답하지 않는 것

- **08-17→08-18 노출 −67%의 원인** — 입찰로 설명 안 됨. 쇼핑은 상품 요소(가격·리뷰·재고·상품 순위)가 노출을 크게 정하는데 그건 광고 원장 밖이다.
- **08-24 소재 입찰 인하의 주체** — 쇼핑은 외부변경 감지가 원리적으로 안 닿는다.
- **입찰을 올리면 노출이 실제로 돌아오는가** — 올려 보는 것 자체가 유일한 관측 경로다.
- **CVR 9.47%가 노출 회복 후에도 유지되는가** — 손익분기 CPC 전체가 이 값에 비례한다. CVR이 절반이면 감당 CPC도 절반이다.
- 상품 BEP 원장 커버리지: **557/758건에 원가 있음**(201건 없음) — 위 폴드7·플립7 2건이 그 201에 속한다.

## §7. 이 세션이 스스로 정정한 것 (같은 함정 반복 방지)

1. **「그 그룹은 거래가 말라간다 → 다른 그룹으로 옮기자」 — 철회.** CTR이 오르고 순위가 밀린 것은 수요 감소가 아니라 자리 상실의 모양이다. 캠페인 최고 CTR 그룹을 버리는 처방이었다.
2. **「소재 입찰가는 원장에 없다」 — 틀렸다.** `naver_adgroup_product.ad_bid_amt`에 있다. `naver_entity`만 보고 판단했다.
3. **「대행사가 이 그룹을 만진 기록 0건」 — 안심의 근거가 못 된다.** 쇼핑은 외부변경 감지가 안 닿는다(이 저장소가 이미 아는 사실).
4. **손익분기 CPC를 계정 평균 BEP로 계산했다 — 후한 값이었다.** 상품 단위 BEP가 원장에 이미 있었다(1.9757 vs 1.711).
