> **목적에서 멀수록 잘 보이고, 목적에 가까울수록 볼 수단이 없다.**

### 4-2. 「원리 불가」 4개의 뿌리는 전부 하나 — 「실집행 0」

```
실집행 0건(2026-07-30~)  →  인과 추정 불가  →  정밀 한계 ROAS 산출 불가
   →  보수 프록시로 대체  →  프록시가 보수적 ⇒ 확장 억제  →  실집행 더 안 남  ─┘
```

「한계 ROAS」는 **「입찰을 올리면 매출이 얼마나 늘어나는가」**라 **인과 추정**이 필요하고, 인과 추정에는 **실제로 밀어 본 데이터**가 필요하다. 안 밀고 있으니 못 재고, 못 재니 보수적으로 굴고, 보수적이니 더 안 민다.

### 4-3. ★그리고 프록시의 오차는 랜덤이 아니다

**보수 프록시는 꼭짓점보다 «일찍» 멈춘다** 🧠 ⇒ D-NAO-59가 지목한 **「ROAS는 떨어져도 총이익이 느는 구간」을 남기고 나온다.**

**목적이 정확히 금지한 방향으로 구조가 기울어 있다.** D-NAO-85 실측(2026-07-23 ROAS +7% · 매출 −52%)과 같은 방향이며, 그때는 「브레이크가 액셀보다 많아서」로 정리됐으나 **한 층 아래에 이 프록시 편향이 있다**.
