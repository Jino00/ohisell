## 3. ★현행 브리지의 정체 — confirmed 184건 중 183건이 이름 유사도

```

confirmed | manual    | 1

```

`suggested` = `rocket_cost_map.suggest_skus()`의 difflib 이름 유사도. 교훈 #117이 금지한 그 경로가
**현재 1P 원가의 전부**다. (ref 44 §4에서 `OHI-TGLASS-IP17PRO` 하나에 12개 기종이 붙은 것이 이미 확인됐다.)

## 4. ★결정적 대체 경로가 이미 있다

```
coupang_rocket_sales_daily.sku_id
  → coupang_rocket_option_sku (option_id ↔ sku_id, 244행)
  → product_channel_mapping (channel_id=5, 388행)   ← 여기가 결정적
  → product_master.cost_price
```

`product_channel_mapping`의 로켓 행은 `coupang/product_sync._maybe_upsert_mapping`이 만드는데,
**쿠팡 `externalVendorSku`가 `product_master.internal_sku`와 정확일치할 때만** 만든다(이름 유사도 아님).
채널 5의 388행 전부 `mapping_source='auto_sync'`(= 이 정확일치 경로). 옵션 244개 중 **211개가 맞물린다**.

1. 새 원가표가 `excel_master` 행을 만들면 `product_sync`가 **덮지 않는다**(D-6/D-12 가드) — 즉
