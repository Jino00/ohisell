## §10. 이 문서가 못 하는 것 — 커버리지 자백

1. **「전수」를 주장하지 않는다.** 다섯 갈래(계약·안 하는 것·§8·합의 원칙·체인 이월)를 전부 훑었으나, 원천 자체가 소실된 것이 있다 — **결손 21항목 원본 목록은 파일로 존재하지 않고, 그중 #9·#10·#15·#19·#20 다섯 항목은 내용을 복원할 길이 없다**(§9-1 #1). 그 다섯이 «조건»이었는지조차 확인 불가다.
2. **「지금」 칸은 재측정이 아니라 인용이다.** 이 문서는 새 prod 조회를 하지 않았다. 각 값은 병기된 실측 시각의 것이고, 특히 `auto_operate` 9행(08-27 07:2x)·검색량 크론 가동(08-24)·70/70 그룹 수(15개 vs 5개 — 측정 시점·모집단이 다른 두 값이 공존)·판사 08-27 08:45 회차의 실제 실행 여부는 **이 문서 작성 시점에 재확인되지 않았다.**
3. **판정하지 않는다.** 「켜도 되는가」는 이 문서의 어느 칸에도 없다 — 게이트는 §8-① 하나이고 그 답은 Jino 몫이다. 체크 [x] 4건도 «증거 좌표 병기 주장»이지 QA 판정이 아니다.
4. **P4(지혜 id 조인)의 완주 여부를 확정하지 못했다** — 코드·표면 실재와 「P4 합격 관측 충족」 사이가 문서로 안 닫힌다(D-3에 [미상]으로 남김).
5. **적대 리뷰·QA 원 판정문의 재검증을 하지 않았다** — S1의 «변이 11종 전부 사망»·「④자동화 28세션째 0」 누적 카운트 등은 n=57 QA도 「직접 재실행 안 함」으로 보존한 값이다.
6. **하네스 부채는 범위 밖으로 남긴다**: `singleflight` 락의 프로세스 내 한정(다중 워커 배포 시 DB advisory lock 필요 — n=57 §9-5) · 체인 등록부 고아 행 n=40(과거 행 무접촉 규칙에 따라 기록만, HANDOFF n=56 이월) · 공유 메인 폴더 stale에 의한 훅 오탐 상습(n=57 §9-3).
7. **ref 66 §8의 파라미터 자백 6건은 여전히 «근거 없음»이다** — 이 문서는 그 빈칸을 채우지 않았고(새 상수 발명 금지), 좌표만 §9에 남겼다.
8. **GFA의 취급·커머스 API의 상품명 수정 지원 여부·유령 검색어 6개의 정체·「686」·「165」의 출처는 [미상] 그대로다** — 발견 0건이 아니라 확인 안 됨이다.
