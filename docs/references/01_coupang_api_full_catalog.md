## 인증 / 공통
- 인증: HMAC-SHA256. 헤더 `Authorization: CEA algorithm=HmacSHA256, access-key=..., signed-date=..., signature=...` + `X-Requested-By`(vendorId)
- 서명 = signed-date + METHOD + path + query, secret로 SHA256
- 게이트웨이: `https://api-gateway.coupang.com`
- 경로 prefix: `/v2/providers/...`
- 키 발급: 윙 [판매자정보]-[부가판매정보]-[API Key 발급] → OPEN API. 키 유효기간 최대 6개월
- **속도제한 정책 존재** (2023~2024 강화). 호출 빈도 최적화 필요
- 환경변수(우리 보유): COUPANG_ACCESS_KEY, COUPANG_SECRET_KEY, 채널별 *_VENDOR_ID

## 전체 11개 섹션 카탈로그

### 1. 카테고리 API
- 카테고리 메타정보 조회 / 목록조회 / 조회 / 유효성 검사 / 추천 / 자동매칭 동의 확인
- 용도: 상품 등록·분류 메타. 조망 우선순위 낮음

### 2. 물류센터 API
- 출고지 생성/수정/조회 · 반품지 생성/수정/단건조회/목록조회 · 택배사 코드
- 용도: 배송 설정. 조망 우선순위 낮음 (한진 1,900 고정이라 참고만)

### 3. 브랜드 API (신규 2026-05)
- 등록 브랜드 목록 / 브랜드 검색 / ID 기반 브랜드 조회
- 용도: 신규 Brand API. 상품 등록 의무 속성. 조망 직접 관련 낮음

### 4. 상품 API ★ (조망 핵심 — 상품 마스터/가격/재고/상태)
- **상품 조회 / 요약 정보 조회** ← 상품 마스터(이름·옵션·가격)
- 상품 목록 페이징 조회 / 구간 조회 / 등록현황 조회
- **상품 아이템별 수량/가격/상태 조회** ← 옵션ID(vendorItemId) 단위 가격·재고·판매상태
- 상품 아이템별 수량 변경 / 가격 변경 / 할인율 기준가격 변경 / 판매 중지 / 판매 재개
- 상품 생성 / 수정(승인필요·불필요) / 승인요청 / 삭제 / 상태변경이력 조회
- 자동생성옵션 활성/비활성 (옵션·전체 단위)
- **조망 활용**: 옵션ID ↔ 상품명·가격 매핑(광고 XLSX 옵션ID와 조인), 판매상태/재고

### 5. 배송/환불 API (주문·배송 — 일부 사용중)
- **발주서 목록 조회 (일단위 페이징 / 분단위 전체)** ← 현재 사용(ordersheets)
- 발주서 단건 조회 (orderId / shipmentBoxId)
- 배송상태 변경 히스토리 조회
- 상품준비중 처리 / **송장업로드 처리** / **송장업데이트 처리** / 이미출고 / 출고중지완료 / 장기미배송 배송완료 / 주문상품 취소 처리 (총 12개)
- **조망 활용**: 이미 주문 동기화에 사용. 배송상태는 운영용

### 6. 반품 API ★ (조망 회계 정확도 — 매출 차감)
- **반품/취소 요청 목록 조회** ← 반품·취소 = 매출에서 빼야 정확
- 반품요청 단건 조회 / 승인 처리 / 반품상품 입고확인 / 회수송장 등록
- 반품철회 이력 기간별·접수번호 조회
- **조망 활용**: 진짜 순매출 = 매출 − 반품/취소. 현재 미반영 → 매출 과대 가능

### 7. 교환 API
- 교환요청 목록조회 / 거부 처리 / 입고확인 / 송장 업로드
- 용도: 교환 운영. 회계 영향 작음 (참고)

### 8. 쿠폰/캐시백 API ★ (조망 회계 — 할인 비용)
- 즉시할인쿠폰: 생성/조회(couponId·couponItemId·vendorItemId·orderId·status)/아이템 생성·조회/파기/요청상태
- 다운로드쿠폰: 생성/단건조회/아이템 생성/요청상태/파기
- 도서 상품 캐시백: 적용/검색/삭제
- (공통) 계약서 단건·목록 조회 / 예산현황 조회
- **조망 활용**: 셀러 부담 할인쿠폰 = 실질 매출 차감/비용. 마진 정확도

### 9. CS API
- 상품별 고객문의 조회/답변 · 쿠팡 고객센터 문의 조회/단건조회/답변/확인
- 용도: CS 운영. 조망 직접 관련 낮음

### 10. 정산 API ★ (조망 회계 핵심)
- **매출내역 조회 (revenue-history)** ← 현재 사용
- **지급내역 조회** ← 미사용. 실제 지급액(정산 입금) 검증
- **조망 활용**: 지급내역으로 "실제 통장에 들어온 돈" 대사 가능

### 11. 로켓그로스 API ★★ (조망 신규 — 재고/사이즈/RG주문)
- **상품 조회 (로켓그로스/하이브리드)** ← `GET /v2/providers/seller_api/apis/api/v1/marketplace/seller-products/{sellerProductId}`
  - ✅ **응답에 사이즈 포함 확정**: `width`/`length`/`height`(mm), `weight`/`netWeight`(g) per item (예: h141·l365·w341·1042g)
  - vendorItemId(옵션ID)도 여기서 확인
- **로켓창고 재고 API** ← RG 창고 실재고 (InventoryPage 연동 가능)
- **로켓그로스 주문 API / 주문 API(목록 쿼리)** ← RG 전용 주문(현재 RG 매출 0이지만 향후)
- 상품 생성/수정/목록 페이징 (로켓그로스)
- 카테고리 메타정보 조회 / 목록 조회 (로켓그로스 운영 카테고리)
- **조망 활용**: ① 사이즈 → 보관비 원가 정확화 ② 로켓창고 재고 → 재고관리 ③ RG주문 → 향후 RG 매출

## 종합 조망 우선순위 (회계·상품·재고 정확도 기준, 추천 아님 — 사실 정리)

| 순위 | API | 무엇이 좋아지나 |
|:---:|------|------|
| 1 | 상품 조회 + 아이템별 수량/가격/상태 (상품 API) | 옵션ID↔상품·가격 매핑 → 광고 XLSX 옵션ID와 조인. 상품별 정밀 분석의 토대 |
| 2 | 반품/취소 목록 조회 (반품 API) | 진짜 순매출 (반품 차감). 현재 매출 과대 가능 |
| 3 | 로켓그로스 상품 조회 (사이즈) + 로켓창고 재고 | 보관비 원가 + 재고관리 페이지 실데이터 |
| 4 | 지급내역 조회 (정산 API) | 실제 입금액 대사 |
| 5 | 쿠폰/캐시백 | 셀러 부담 할인 비용 반영 |
