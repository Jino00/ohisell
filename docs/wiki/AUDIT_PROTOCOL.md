## 절차 (5단계)

### §1 신규 교훈 수집 → 처분
지난 감사 이후 `LESSONS_LEARNED.md`에 추가된 교훈 전건을 본다. 각각 셋 중 하나:
- **기존 패턴에 병합** — 그 파일 `sources:`에 번호 추가
- **새 패턴 신설** — frontmatter 4필드 필수
- **패턴 아님** — 일회성 사실. 처분 이유를 감사 문서에 한 줄

> ★교훈 원문은 **소급 수정 금지**. 위키는 링크·요약만.

### §2 부채 목록 출력
```bash
grep -l "^enforcement: none" docs/wiki/*.md
```
> ★`^` 앵커가 **필수다.** 앵커 없이 돌리면 그 문자열을 *언급만* 하는 이 파일과 `WISDOM.md`가
> 함께 잡혀 부채가 4건으로 부풀어 보인다(2026-08-10 셋업 검증에서 실제로 발생).
> 부채 카운트를 부풀리는 오탐은 [[green-does-not-mean-verified]]의 거울상이다 —
> 이번엔 «없는데 있다»로 보였다.
각 부채에 대해: **이번 주에 이것 때문에 손해가 났는가?** 났으면 도구화 백로그 상위로.

### §3 ★기록↔배선 대조 (이 감사의 핵심)
[[claimed-vs-wired-is-the-default-state]]의 표를 들춘다. 이번 주 작업 중:
1. **«이 기능은 있다»를 근거로 내린 결론**이 있었는가? 3단계(존재/호출/영향) 중 어디까지 확인했나?
2. 메모리·위키에 **기록된 지식** 중, 관련 코드 경로가 **읽지 않는 것**이 새로 보이는가?
3. 새로 만든 쓰기 경로가 **실효 레이어**에 닿는지 확인했는가? ([[write-to-the-binding-layer]])

발견은 표에 행으로 추가한다 — **추가 자체가 이 주의 산출물**이다.

### §4 재발 검사
```bash
grep -h "recurrence_tags" docs/wiki/*.md
```
- 같은 태그가 **4주 내 2회 이상** → 도구화 백로그
- `enforcement: principle`인데 재발 → **승격 의무 발동**([[text-rules-fail-build-tools]])

### §5 갱신 + 보고
[[WISDOM]] 표 갱신 · 산출물 작성 · **Jino 결정이 필요한 승격만** 질문으로 올림.

## 지표 (감사 문서에 매회 기록)

| 지표 | 뜻 | 이번 주 |
|---|---|---|
| **처분율** | 처분된 교훈 / 전체 교훈 | — |
| **부채 수** | `enforcement: none` 개수 | 2026-08-10 = **2** |
| **승격 대상** | `principle`인데 재발한 항목 | 2026-08-10 = **1** (부채와 **따로 센다**) |
| **재발 태그** | 4주 내 2회 이상인 태그 | 2026-08-10 = `claimed-vs-wired`(2), `rule-decay`(2), `write-path`(2) |
| **발견 주체** | 시스템 감사 / 사람 질문 | 목표: 시스템 쪽으로 이동 |
| **앵커 누락** | 지난 7일 트랙 커밋이 있는데 앵커가 없는 세션 수 | 2026-08-13 신설 |
| **미판정 앵커** | `합격:`은 있는데 `판정:`이 없는 앵커 수 | 2026-08-13 신설 |
| **부분달성 비율** | 부분달성 / 전체 판정 | 2026-08-13 신설 |

> ★**발견 주체가 이 시스템의 진짜 성적표다.** 2026-08-10 기준선 = **사람 질문 1 : 시스템 0**.
> ★**앵커 누락은 감사만 볼 수 있다** (2026-08-13 신설). 완료 QA 체계의 스위치가 «앵커 파일 존재»라
> `scope-anchor.sh`도 `completion-qa.sh`도 앵커를 안 쓴 세션은 원리적으로 못 본다 — 스위치가 안 켜지기
> 때문이다. Fable 슬롯이 통째로 비었던 것을 잡은 게 절차가 아니라 라이브 반증이었던 것과 같은 이유.
> **부분달성 비율**은 판정 어휘가 가운데 값으로 수렴하는 압력을 재는 것이다 — 올라가면 어휘가
> 무뎌지고 있다는 신호다.
>
> 세는 법:
> ```bash
> ls .claude/anchors/*.md | wc -l                                  # 전체 앵커
> grep -L '^판정:' .claude/anchors/*.md | xargs grep -l '^합격:' | wc -l   # 미판정 앵커
> grep -h '^판정:' .claude/anchors/*.md | sort | uniq -c            # 판정 분포
> ```
