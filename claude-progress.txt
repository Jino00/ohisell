## 순이익 공식 (확정)
순이익 = 매출 - 원가 - 수수료 - 광고비 - 배송비 - VAT(10/110)
* 배송비: 상품별로 포함/미포함 다름 (shipping_cost nullable)
* 로켓배송(위탁): 이익 계산 제외 (매출만 표시)
* 광고비: ad_data.db에서 option_id로 매칭 (cross-DB Python 레벨 조인)

## 쿠팡 Wing/RG 구분 방식 (확정)
- 동일 vendor_id → 동일 API 키
- `shipmentType == "THIRD_PARTY"` → Wing (판매자 직배송)
- `shipmentType != "THIRD_PARTY"` → 로켓그로스 (쿠팡 물류)
